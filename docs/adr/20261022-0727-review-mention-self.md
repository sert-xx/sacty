# レビューの投稿のメンションを、sacty の設定で PR の作者から自分に切り替えられるようにする

- 日時: 2026-10-22 07:27 UTC
- ステータス: 採用
- 関係する PR・タスク: なし
- 置き換え元: なし
- 置き換え先: なし

## 背景

レビューだけのタスクは、投稿するレビューの先頭で PR の作者に @ メンションする（PBI-111）。
AI のレビューの結果を、作者に知らせる前に自分で確かめたい、という要望があった。
一方で、AI のレビューの結果をすぐ作者に知らせる今の使い方も要る。

## 決定

- sacty の設定（すべてのプロジェクトに共通）に `reviewMentionSelf` を足す。既定は Off で、今までどおり PR の作者にメンションする。
- On なら、作者の代わりに、投稿するアカウント（プロジェクトでそのホストに選んだ gh のアカウント）にメンションする。
  そのアカウントが login の形でなければ、作者にも付けず、誰にもメンションしない。
- 画面の「Sacty の設定」の「PR のレビューの取り込み」の区画に、切り替えを置く。

## 理由

- 自分で確かめてから知らせたい人と、すぐ知らせたい人がいるので、選べるようにする。今の利用者の振る舞いを変えないよう、既定は今の挙動にする。
- メンションを付けないのではなく自分に付けるのは、要望が自分へのメンションだったため。
- 自分の login が読めないときに作者へ戻すと、作者に知らせたくないという On の意図に反するので、誰にもメンションしない。
- 誰がレビューを使うかは利用者ごとの使い方なので、プロジェクトではなく sacty の設定に置く（プロジェクトはエクスポートして共有するため、個人の設定を含めない）。

## 影響

- 自分のアカウントで投稿したレビューで自分にメンションしても、GitHub は自分には通知しないことがある（未確認）。
  作者に通知が飛ばないことが、この設定の主な効果になる。
- 作者に知らせるのは、利用者が確かめた後に、自分で PR にコメントするなどして行う。
