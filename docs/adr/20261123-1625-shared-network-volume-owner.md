# 共通ネットワークと名前付きボリュームを所有者の印で回収する

- 日時: 2026-11-23 16:25 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-498
- 置き換え元: なし
- 置き換え先: なし

## 背景

デーモンが片付け前に終了すると、共通ネットワークとコンテナの消えた後のボリュームが残る。

## 決定

共通ネットワークと名前付きボリュームにデーモンの PID と開始時刻のラベルを付け、起動時に終了済みの持ち主の資源を回収する。
ネットワークは共通ネットワークの名前の形で compose プロジェクトのラベルが無いもの、ボリュームは `sacty-svc-` プロジェクトのものに限る。
入力のネットワークとボリュームの所有ラベルは除く。

## 理由

ラベルの無い資源は sacty が作ったか確かめられないため残す。
作り方でも絞ることで compose 管理のネットワークを対象から外す。

## 影響

匿名ボリュームは対象外であり、コンテナが先に消えると残りうる。
コンテナの片付けと同じく、別マシンで Docker を共有する場合、`hidepid` などでプロセスが見えない場合、旧版と新版が共存する場合は持ち主を正しく保護できない。
sacty の名前とラベルをまねた資源は区別できず、回収される場合がある。
