# 実装の PR のレビューに実装時のサービスを渡す

- 日時: 2026-11-22 17:14 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-489
- 置き換え元: なし
- 置き換え先: なし

## 背景

レビューの子タスクでは DB などを使うテストを実行できなかった。
親の計画は再実行で変わりうるため、レビューするコードと使うサービスを対応させる必要がある。

## 決定

実装の PR のレビューは、対象の先頭を作った実装の実行のサービスの記録を使う。
共用 compose の取得元とコミットも記録し、各レビューの実行で取得する。
起動できない場合は理由を担当に伝え、サービス無しでレビューを続ける。
人による停止は従来どおり実行を止める。

同時実行数は既存のタスクの上限に含め、メモリーの予約や見積もりは行わない。

## 理由

実行の記録を使うと、親の後の再実行や設定の変更に影響されない。
起動できない場合も、サービスを必要としない範囲のレビューを行える。
容量の管理は利用者が同時実行数を調整する方針とする。

## 影響

共用 compose の旧記録に取得元がない場合や、対象の先頭に対応するプッシュがない場合は、サービス無しでレビューする。
