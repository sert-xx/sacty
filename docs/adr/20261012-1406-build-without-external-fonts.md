# 画面のビルドで npm のレジストリ以外の外部に取りに行かず、フォントは npm のパッケージから読む

- 日時: 2026-10-12 14:06 UTC
- ステータス: 採用
- 関係する PR・タスク: #45、PBI-39
- 置き換え元: なし
- 置き換え先: なし

## 背景

画面のフォント（IBM Plex Sans JP・IBM Plex Mono）を `next/font/google` で読み込んでいて、`npm run build` のときに Google Fonts に
取りに行っていた。外への通信が制限された利用者の環境では Google Fonts に届かず、ビルドが失敗していた。その環境でも npm のレジストリは使える。

## 決定

- 画面のビルドでは、npm のレジストリ以外の外部（Google Fonts など）に取りに行かない。
- 画面のフォントは、同じフォントを npm のパッケージ（`@fontsource/ibm-plex-sans-jp`・`@fontsource/ibm-plex-mono`）から読む。
  見た目（フォントと太さ）は変えない。

## 理由

- 利用者の環境からは Google Fonts に届かないが、npm は使えるため、npm のパッケージから読めば見た目を変えずにビルドが通る（PR の本文）。
- パッケージの版は、2週間以上前の版（5.3.0）を選んだ（PR の本文）。2週間以上前の版にした理由は記録に無い。

## 影響

- 画面のビルドは、npm のレジストリだけが使える環境でも通る。
- フォントを足す・変えるときも、ビルドのときに外部から取らない形（npm のパッケージなど）にする必要がある。
