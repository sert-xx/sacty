# 台帳などに記録するデーモンの文言を、文かコードと引数のどちらかで持ち、外から来た文は訳さずに引数で渡す

- 日時: 2026-10-10 14:23 UTC
- ステータス: 採用
- 関係する PR・タスク: #16、PBI-11
- 置き換え元: [画面の言語はブラウザの言語に従って日本語・英語を決め、ユーザーメニューで上書きでき、エージェントの成果物は訳さない](20261010-1048-superseded-ui-language-selection.md)（台帳などに記録するデーモンの文言を日本語のままにする部分）
- 置き換え先: なし

## 背景

#15 で、デーモンの API が返す文言をコードと引数にした。台帳などに記録する文言（失敗・一時停止の説明、中止の後片付け、コンテキストの注意など）は、
日本語の文のまま記録されていたので、英語の画面でも日本語で出ていた。すでにある台帳には日本語の文が残っている。

## 決定

- core に `DaemonText` を置く。日本語などの文か、コードと引数の文言のどちらか。台帳の次の項目をこの形で持つ。
  - 失敗の説明（`AgentRunFailed.message`・`FinalReviewFailed.message`）、一時停止の説明（`TaskPaused.message`）、ゴールガーディアンの実行の失敗・中断（`ChangeJudged.reason`）、
    中止の後片付けの結果（`TaskCancelled.cleanup[].detail`）、コンテキストの注意（`ContextResolved.warnings`）、最終レビューの理由と所見（`FinalReviewed` の reason・summary）。
- 古い台帳の日本語の文は、そのまま読み、そのまま出す。
- 台帳の外の文言（中止の確認に出す説明・GitHub Issue の取り込みのエラー・設定ファイルの誤り）もコードと引数にする。
- テストの実行の注記（時間切れ・docker を実行できない・コンテナの停止を確認できない）は、テストの出力に混ぜず、`TestsRun.note` として分けて記録する。
- デーモンの中のエラーは `MessageError` でコードと引数を持たせ、記録する側は `errorText(error)` で取り出す。`message` は日本語の文にして、ログや CLI はこれまでどおりにする。
- 外から来た文（git・GitHub・Docker のエラー、エージェントの出力）は訳さず、引数の `detail` で渡す。`detail` にはコードと引数の文言を入れ子にできる。
- エージェントの成果物や判定理由は訳さず、sacty が添える部分だけを訳す。判定を読み取れないときなどにデーモンが補う説明はコードにする。
- 秘密情報は、引数の中の文からも取り除く。コードと、決まった値の引数（列挙・数値・真偽）は変えず、自由に書ける文字列の引数と入れ子の文だけを対象にする。
- 実装のやり直しの指示と PR の本文には、日本語の文にして入れる。
- 対象外：デーモンのログ・CLI の文言・エージェントに渡す指示（プロンプト）・既定のプロジェクト名「デフォルト」（データ）。

## 理由

- 古い台帳の文をそのまま出すのは、受け入れ条件（古い台帳の日本語の文言は、そのまま表示する）による。
- 秘密情報の取り除きでコードと決まった値を変えないのは、秘密情報の値がコードの一部と一致すると（短い MCP の秘密情報も許している）、コードが伏せ字になって
  文にできなくなることが、レビューで見つかったため（レビュー）。
- 判定を読み取れないときの説明をコードにしたのは、それがエージェントの文ではなくデーモンが作る説明で、英語の画面でも日本語のまま出ることが、
  レビューで見つかったため（レビュー）。
- テストの注記を出力と分けた理由は記録に無い。

## 影響

- 台帳の上の項目は、新しい記録ではコードと引数、古い記録では日本語の文が混ざる。読む側は両方を扱う。
- デーモンで記録する文言を足すときは、core の辞書にコードを足す。
