# 共用 compose を対象リポジトリにひもづける

## 背景

共用 compose をどのリポジトリで使うかは説明文だけでは明確でなく、対象の compose と同時に選べなかった。

## 決定

共用 compose をリポジトリまたは Org の対象にひもづけ、対象のタスクでは原則使うようオーケストレーターに指示する。
対象外のものは候補から外し、未指定のものは説明から判断する。
複数の compose を共通のネットワークで起動し、サービス名と別名が重なるときは起動前に止める。

## 理由

ひもづけによって利用する場面を明確にし、共通のネットワークによって旧版の Docker でも各サービスに接続できる。

## 影響

旧版への切り戻しではひもづけと複数 compose の選択を保てない。
切り戻す前に設定をエクスポートし、複数 compose を選んだ未完了タスクを中止する。
新版に戻したらひもづけを付け直し、中止したタスクを再実行する。
