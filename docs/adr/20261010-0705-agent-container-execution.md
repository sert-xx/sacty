# エージェントはアダプターを介してタスク専用のコンテナで実行し、選んだ認証方式の秘密情報だけを渡して、台帳に書く前に取り除く

- ステータス: 採用
- 関係する PR・タスク: #2、PBI-2
- 置き換え元: なし
- 置き換え先: なし

## 背景

工程をエージェント（Claude Code・Codex）に実行させるにあたり、どこで実行するか、認証情報をどう渡し、どう守るかを決める
必要があった。

## 決定

- エージェントの呼び出しはアダプターを介し、`claude -p --output-format json` と `codex exec --json` に対応する。動作確認用のスタブも置く。
- 工程はタスク専用のコンテナで実行し、マウントはそのタスクの作業領域だけにする（Codex のサブスクリプションでは、認証ファイルの写しも）。
  イメージは `sacty image build` で作り、root 以外の利用者で動かす。
- 認証方式は AI の定義ごとに選ぶ（Claude Code：サブスクリプション・API キー・Bedrock、Codex：サブスクリプション・API キー）。
  コンテナには、選んだ認証方式の変数だけを渡す。ホストの `ANTHROPIC_API_KEY` は渡さない。値は `docker run -e NAME` で渡す。
- 秘密情報は macOS のキーチェーンに置き、設定には名前だけを書く（`sacty secret set`）。値は台帳・ログ・画面・コマンドラインに出さない。
- コンテナの中では `CLAUDE_CONFIG_DIR` を空にし、`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` にする。
- Codex のサブスクリプションでは、コンテナの中で更新された認証ファイルを、実行中にホスト側が変わっていなければホストへ書き戻す。
- 実行に渡した秘密情報（キーチェーンの値、ステージした認証ファイルの実行前と実行後の値）を、出力・エラー文・例外の文言から
  `[REDACTED]` に置き換えてから台帳に書く。8文字未満の値は対象にしない。
- デーモンを止めるときは、実行中のコンテナを止め、実行の後処理（台帳への記録・認証ファイルの書き戻し・一時ファイルの削除）が
  終わるのを待ってから終了する（上限 20 秒）。中断した実行は「デーモンの停止で中断」として記録し、一時停止にする。
  CLI が子プロセスを強制終了するまでの猶予は 30 秒にする。

## 理由

- ホストの `ANTHROPIC_API_KEY` を渡さないのは、引き継ぐとサブスクリプションより優先されて従量課金になるため（コミットのメッセージ）。
- `docker run -e NAME` で渡すのは、値をコマンドラインに出さないため（コミットのメッセージ）。
- `CLAUDE_CONFIG_DIR` を空にして組み込みのメモリーを無効にするのは、ホストの `~/.claude` を読ませないため（コミットのメッセージ）。
- 認証ファイルを書き戻すのは、トークンの更新でホストのログインが壊れるのを防ぐため（PR の本文）。
- 台帳に書く前に取り除くのは、台帳が追記専用で後から消せないため（レビューへの返信）。8文字未満を対象にしないのは、`"1"` や
  リージョン名のような短い値まで置き換えると無関係な文字が消えるため（レビューへの返信）。
- 実行後の認証ファイルの値も対象にしたのは、コンテナの中で更新されたトークンが台帳に残ることがレビューで再現されたため。
- 停止の時に後処理を待つのは、待たずに終了すると認証ファイルの書き戻しと一時ファイルの削除が終わらず、ホストの認証を保つ目的が
  果たせないため（レビューの指摘）。猶予を 30 秒にしたのは、それまでの 5 秒では後処理の途中で強制終了されうるため（レビューへの返信）。
- コンテナで実行する理由、キーチェーンを選んだ理由は、記録に無い。

## 影響

- 認証ファイルを書き戻すので、sacty がホストのファイルを書き換えることがある（PR の本文で、レビューで見てほしい点として挙げた）。
- 本物の認証情報での実行は、この時点では確かめていない（利用者の手での確認に回した）。
