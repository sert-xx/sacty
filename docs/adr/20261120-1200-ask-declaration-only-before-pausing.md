# 申告だけが欠けて止まる前に、申告だけを求める実行を1回足す

- 日時: 2026-11-20 12:00 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-416
- 置き換え元: なし
- 置き換え先: なし

## 背景

実装が終わっていて、申告（完了の申告・観点とテストの対応）だけが欠けると、未完了が続く。作業領域が変わらないので一時停止し、人が再開するまで提出されなかった（[続きの ADR](20261115-2254-continue-incomplete-implementation-in-same-session.md)の止め方）。

## 決定

- 完了と申告して観点が欠けた実行と、申告が無い・読めない実行で、作業領域が前の未完了のときと変わらないときは、止める前に、コードを変えずに申告だけを求める実行を1回足す。
- 足したことは `ImplementationIncomplete` の `declarationOnly` に記録し、投影の `incompleteRuns.declarationAsked` で、同じ止まりの中の2回目を断る。
- 未完了と申告した実行・足した後の実行・回数の上限は、今までどおり止める。
- テストで確かめようがない観点は、`tests` を空にして、理由と確かめ方を `untested` に書く（読み取りは変えない）。

## 理由

- 欠けているのが申告だけなら、コードを変えずに申告を出し直すだけで済み、人の判断は要らない。
- 記録から決まるので、デーモンを起動し直しても、2回行わず、行わずに止まらない。

## 影響

- 申告だけを求める実行は、未完了の1回に数える。止まるまでに、実行が1回増える。
