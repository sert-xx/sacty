# 再レビューの要修正を絞る

## 背景

再レビューで理論上の条件や範囲を広げる指摘が続き、修正の往復が長くなっていた。

## 決定

再レビューの要修正は、前回以降の変更が生んだ後退、未修正の前回の要修正、普通の使い方か1つの条件で起きる不適合または影響が大のもの、普通の使い方で起き影響が中のものに限る。前回の指摘には重みの見直しの規則を適用する。その他の新しい指摘は提案にする。

外部の者が意図して揃えられる条件を数えないのは、入力が信頼できないと要求要件・設計・依頼が定める場合か、秘密の値・認証・認可・権限に関わる場合だけとする。それ以外の細工した入力は条件に数える。

同じ原因が続き、レビューが示した範囲を絞る案で残る現れが再レビューの要修正に当たらないものだけなら、提案とし、人の判断を求めない。総評に範囲を絞ったことと残る現れを書く。

## 理由

実際の利用に影響する不具合と直しによる後退を優先し、範囲を広げる往復を減らすため。

## 影響

初回の重さの表と不適合の扱いは変えない。再レビューの規則は自己レビューにも当てる。
