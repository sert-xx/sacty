# 実装の残りから取り込み済みの変更と工程外の作業を分ける

- 日時: 2026-11-22 22:01 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-491
- 置き換え元: なし
- 置き換え先: なし

## 背景

ベースの取り込みによる変更の提出と、承認済みの設計で人に委ねた確認を実装の残りに数えたため、工程が停止した。

## 決定

実装の指示は、取り込んだベースブランチや PR の変更を提出に含めてよいことと、競合は両方の振る舞いを保って合わせることを伝える。
承認済みの要求要件・設計で人または工程外に委ねた作業は残りに数えず、作業履歴に人がすると書く。
人の判断が必要な未完了の申告では、残りに1つの問いを書き、工程が選べる候補があれば推奨を添える。

## 理由

取り込み済みの変更の提出と、工程外に委ねると決まった作業には、新たな人の判断が要らない。
問いと推奨を残りに書けば、一時停止の案内から判断に必要な情報を読める。

## 影響

完了申告の形式と未完了の続行回数は変えない。
実装の指示と一時停止の案内は、[仕様書](../spec/tasks-and-steps.md)に記す。
