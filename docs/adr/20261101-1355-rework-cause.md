# 差し戻しの原因を判断し、ゴールガーディアンの見逃しは原因が見逃しのときだけ記録する

- 日時: 2026-11-01 13:55 UTC
- ステータス: 採用
- 関係する PR・タスク: #270、PBI-268
- 置き換え元: [成果物チェックで人間が差し戻したら、そのとき合格だったゴールガーディアンの最終レビューを「見逃し」として記録する](20261010-0858-superseded-guardian-missed-record.md)（差し戻しのたびに見逃しを記録する部分）
- 置き換え先: なし

## 背景

合格にした最終レビュー（統合レビュー）の成果物を人が差し戻すと、理由を問わず `GuardianMissed` を記録していた。
実験（findings.md の F13）では、見逃しではない差し戻しも見逃しに数えられた。

- S13：先の PR がマージされて、ベースブランチと競合したための差し戻し。
- S9：人が後から足した要望（文書に1文足す）による差し戻し。

見逃しの回数は、ゴールガーディアンの精度を測り、改善を判断するための数字なので、誤りが判断を誤らせる。

## 決定

- 差し戻しに原因（`guardian_missed`・`new_request`・`base_changed`）を付けられるようにする。
  `ChangesRequested` と、PR の指摘の戻し先の判断 `ReworkJudged` に、省略できる `cause` を足す。
- 人は、承認の画面の「差し戻しの原因」で選ぶ。初めは「選ばない」にする。
- PR の指摘の差し戻しは、ゴールガーディアンが戻し先と一緒に原因も判断する。判断できなければ、原因を決めない。
  人が承認の画面で差し戻す流れは、戻し先を人が選ぶのでゴールガーディアンの判断を通らない。原因を選ばなければ、判断のためだけに実行を増やさず、原因が分からない差し戻しにする。
- `GuardianMissed` を記録するのは、原因が `guardian_missed` で、差し戻した成果物が合格のレビューを持っていたときだけにする。
  原因が `new_request`・`base_changed` のときと、原因を決めないときは記録しない。
- 作業履歴の差し戻しの行、PR の欄の戻し先、ダッシュボードの品質の信号に、原因を出す。
  原因が分からない差し戻し（人が選ばなかったもの・判断できなかったもの）を、「ゴールガーディアンの見逃し」の下に並べて数え、見逃しかどうか分からない数が見えるようにする。
  見逃しではないと分かっているもの（新しい要望・競合）は、原因ごとに数える。
- 原因を持たない過去の記録は、そのまま読む。記録済みの `GuardianMissed` は、見逃しのまま数える。
  集計では、原因を持たない差し戻しの直前（同じタスクの直前の記録）に `GuardianMissed` があれば見逃し、無ければ原因が分からないものに数える。

## 理由

- 見逃しかどうかは、実装の中身を見ないと決まらない。人かゴールガーディアンが、差し戻すときに判断するのが自然である。
  戻し先の判断と同じ実行で判断できるので、実行を増やさずに済む。
- 原因を決められないときに見逃しとして数えると、決めつけが残る。決めないままにして、見逃しには数えない。
  見逃しが少なく出る側に倒すことになる。人が「見逃した」を選ばなければ数えないので、数は人の判断を待つ。
  既定を「見逃した」にする案は、元の問題（決めつけ）が戻るので採らなかった。
- 競合かどうかを、コードで機械的に判定する案（ベースブランチが進んだかを調べる）は、競合の解消に伴う意味の衝突（S13）と、
  ただベースが進んだだけの差し戻しを区別できないので、採らなかった。
- 過去のイベントを書き換えずに読めるよう、`cause` は省略できる項目にした。

## 影響

- 差し戻しの API（`RequestChangesInput`）を省略すると、見逃しは記録されない。呼び出す側が見逃しとして数えたいときは、`cause` を渡す。
- 以前は差し戻すだけで増えた見逃しの数は、人かゴールガーディアンが見逃しと判断した分だけになる。ダッシュボードの数は、これまでより少なくなりうる。
  人が原因を選ばない差し戻しは、見逃しの数に入らない代わりに「原因が分からない差し戻し」に出る。見逃しの数だけを見て、見逃しが減ったと読まない。
- ダッシュボードの「ゴールガーディアンの見逃し」は `GuardianMissed` の数で、原因ごとの差し戻しの `guardian_missed` と同じとは限らない
  （合格のレビューが無い成果物を見逃しとして差し戻しても、見逃しは記録しない）。
