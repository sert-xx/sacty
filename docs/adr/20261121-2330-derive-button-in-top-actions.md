# 続きのタスクを作るボタンを、上部の操作の並びに置く

- 日時: 2026-11-21 23:30 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-463
- 置き換え元: なし
- 置き換え先: なし

## 背景

「続きのタスク」を作るボタンは、概要タブの下のほうにあり、見つけにくかった。利用者から、レビューのタスクの「再レビュー」と同じ位置がよいと言われた。

## 決定

- 完了したタスク（`canDerive`）の詳細で、「続きのタスクを作る」ボタンを、上に固定した操作の並び（再レビューと同じ所）に置く。見た目とヒントは再レビューに合わせる。
- 作ったタスクの一覧は概要の「続きのタスク」の欄に残し、ボタンは欄に置かない。
- ダイアログの中身・派生の仕様は、[派生の ADR](20261028-0054-derive-follow-up-task.md) のまま変えない。

## 理由

- 上の操作の並びは、スクロールしても見える。「再レビュー」と同じ所なので、完了したタスクで次にする操作を探しやすい。
- 比べた案：
  - 概要の「続きのタスク」の欄に置いたままにする：下のほうでスクロールが要り、見つけにくいという指摘が元なので採らない。
  - 上の並びと欄の両方に置く：同じ操作が 2 か所になり、迷う。欄は一覧だけにした。

## 影響

[詳細の上の固定](20261028-1533-task-detail-tabs-and-properties.md)の操作に、続きのタスクを作るが加わる。操作の並びは折り返すので、狭い幅でも重ならない。
