# 再開の補足で許した申し出を受け入れる

- 日時: 2026-11-22 22:39 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-490
- 置き換え元: [ゴールガーディアンの撤去](20261112-0820-superseded-remove-goal-guardian.md)（申し出はすべて人が判断する部分）、[MCP の再開](20261119-0800-superseded-mcp-pause-resume-minimal-resume.md)（再開は補足だけの部分）
- 置き換え先: なし

## 背景

再開の補足で人が方針を変えた後、その補足に合わせる申し出が人の判断を再び待っていた。

## 決定

人が補足とともに明示的に許可した場合、次の一時停止まで、補足の文を引用した申し出を受け入れる。
引用は空白をそろえて補足に含まれるか照合する。
要求要件に伴う設計の合わせ直しは、工程が必要な範囲内と `design.inScope` で申告した場合だけ反映する。
MCP からも許可を付けられる。

## 理由

補足を書いた人が同じ変更を再び承認する待ちを省く。
別の AI の判定は加えず、補足との照合と工程の申告を使う。
工程の申告に誤りが混じる可能性があるため、変更の差分を履歴と申し出の一覧に残す。

## 影響

自動で受け入れた要求要件は再承認を待たず、承認済みの設計があれば合わせ直す。
許可のない申し出は人の判断を待つ。
新しい記録を使うと以前の版には戻せない。
