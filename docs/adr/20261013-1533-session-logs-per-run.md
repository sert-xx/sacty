# エージェントの実行ごとに、秘密情報を伏せたセッションログを先頭と末尾を残して SACTY_HOME に残し、画面から見られるようにする

- 日時: 2026-10-13 15:33 UTC
- ステータス: 採用
- 関係する PR・タスク: #71、PBI-62
- 置き換え元: なし
- 置き換え先: なし

## 背景

エージェントの実行は、最後の答えと費用しか残していなかった。エラーで止まったときの原因の調査と、今後の監査（PBI-55）のために、
途中の出来事と標準エラー出力を残す必要があった。

## 決定

- execute を通る実行すべて（工程・オーケストレーター・ゴールガーディアン・トリアージ・最終レビュー・質問への答え・書き出しなど）ごとに、
  `SACTY_HOME/runs/<taskId>/<runId>.jsonl`（途中の出来事）・`.stderr.log`・`.meta.json`（実行の種類・エージェント・開始と終了・結果・切り詰め）を
  残す。失敗・途中で止めた・コンテナを起動する前に止まった実行も残す。中止の掃除では消さない。オーケストレーターなどの記録にも
  `runId`（省略できる項目）を足す。
- 秘密情報は書く前に伏せる（実行に渡した秘密情報・ゲートウェイのトークン・認証ファイルの値、JSON でエスケープされた形も）。届いた分・
  行の境目をまたぐ値も伏せる。書き始めた後に分かった値は、閉じるときにファイル全体から伏せ直す。伏せるために持っておく分の切れ目は、
  サロゲートペアの外側に寄せる。
- 大きすぎるログは、先頭と末尾を残して間を省く（途中の出来事は先頭 15MB・末尾 3MB、標準エラー出力は先頭 1MB・末尾 1MB）。伏せてから
  切り詰め、JSONL は行の切れ目で切り、間に `sacty.truncated` の行（省いた大きさ・行数）を入れる。メモリに持つのは末尾の分だけ。
- API は `GET /api/tasks/:id/runs/:runId/log` と `/files/{events|stderr}`（タスクごとの場所から読む。ほかのタスクは 404、ID の形が違えば 400）。
- 画面：作業履歴の実行の行に「ログを見る」。`/tasks/[id]/runs/[runId]` に、この実行の作業履歴・結果の概要・切り詰めの警告・生のファイルの
  ダウンロード・出来事の一覧（ツールの呼び出しと結果は畳む。知らない形の行は生の行）・標準エラー出力。ログの無い古い実行は理由を出す。

## 理由

- 残すのは、エラーで止まったときの原因の調査と、今後の監査（PBI-55）に使うため（PR の本文）。
- 切り詰めは PO の判断。先頭と末尾を残すのは、エラーで止まった原因や最後の result の行が末尾に出るため（コミット 95aaea3）。
- 伏せる分の切れ目をサロゲートペアの外側に寄せるのは、レビューで、絵文字・補助漢字が置換文字に壊れることがわかったため（レビューとその返信）。
- 保存の場所・ファイルの形を選んだ理由と、比べたほかの案は記録に無い。

## 影響

- `SACTY_HOME` の下に、実行ごとのログが溜まる（中止の掃除では消さない）。
- デーモンが強制終了すると、メモリに持っている末尾（最大 3MB・1MB）と改行の届いていない行は失われる（先頭は書いた分が残る）。
- 先頭を超えた後は、実行が終わるまで末尾がファイルに出ない（実行中にダウンロードすると先頭だけ）。
- 伏せられるのは、そのままの値と JSON でエスケープされた形だけ（base64 など別の符号化は伏せられない）。
