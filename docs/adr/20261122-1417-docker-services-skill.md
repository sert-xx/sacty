# 工程のサービスの案内を実行ごとのスキルで渡す

- 日時: 2026-11-22 14:17 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-486
- 置き換え元: なし
- 置き換え先: なし

## 背景

リポジトリの docker の手順が、工程の指示にあるサービスの接続案内より先に使われる場合があった。
サービスを起動しない工程にも、この環境での検証方法を伝える必要がある。

## 決定

各工程に実行ごとのスキルを置き、サービスの起動と接続ではリポジトリの手順より先に読むよう指示する。
起動したサービスの接続先は候補としてスキルと指示に同じデータから書く。
届かなければ別の候補を試し、確かめられなかったことを報告する。
レビューの基準は変えない。

## 理由

スキルと指示の両方で案内することで、スキルを読む前にも接続先の候補が分かる。
接続の到達性はネットワークや待受の構成に依存するため、保証しない。

## 影響

同名の層のスキルは使わず、注意を記録する。
情報収集やオーケストレーターの実行には、このスキルを置かない。
