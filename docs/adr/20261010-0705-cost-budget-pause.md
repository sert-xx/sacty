# 実行ごとの費用をトークン数と設定の単価で台帳に記録し、予算・利用上限・認証エラーでは失敗にせず一時停止する

## 背景

エージェントの実行には費用や利用枠がかかる。使いすぎを止め、止まった理由がわかり、人が判断して続けられるようにする必要があった。

## 決定

- 実行ごとにトークン数を取得し、設定の単価で費用を計算して台帳に記録する。Codex のキャッシュは入力の内数として扱い、二重に数えない。
- サブスクリプションの費用は換算値として扱い、画面でそうとわかるようにする。
- 予算はタスクごとで、既定は $1。80% で通知を台帳に記録し、上限で一時停止する（作業は残す）。
  1回の実行で上限を超えたときも、通知を記録してから止める。失敗した実行の費用でも通知を判定する。
- 利用上限と認証エラーは、失敗ではなく一時停止として扱い、理由がわかるようにする。キーチェーンに無い秘密情報は認証エラーとして止める。
- 画面に費用のメーターを出す。予算で止まったタスクは、使用済みより大きい累計の上限を入れて再開できる。

## 理由

- 失敗した実行の費用でも通知を判定するのは、そうしないと「80% で通知を記録する」という受け入れ条件を満たさないことが
  レビューで再現されたため。
- 既定を $1・通知を 80% にした理由、利用上限と認証エラーを一時停止にした理由は、記録に無い。

## 影響

- 再開するには、使用済みより大きい累計の上限が要る。使用済み以下の上限はエラーにする。
- 費用の計算は、エージェントの出力の `usage` のキー名に依存する（公式のドキュメントにもとづいて実装し、本物の出力では確かめていない）。
