# 成果物チェックで人間が差し戻したら、そのとき合格だったゴールガーディアンの最終レビューを「見逃し」として記録する

- 日時: 2026-10-10 08:58 UTC
- ステータス: 採用
- 関係する PR・タスク: #7、PBI-10
- 置き換え元: なし
- 置き換え先: なし

## 背景

#6 で、ゴールガーディアンが最終レビューで合否を判定するようにした。合格とした成果物を人間が成果物チェックで差し戻した場合を、
どう扱うかを決める必要があった。

## 決定

- 成果物チェックで差し戻すと、そのとき合格だった最終レビューを `GuardianMissed` として、差し戻しと同じ追記で記録する。
- タスクの詳細に、見逃しの件数と指摘を表示する。

## 理由

理由は記録に無い（受け入れ条件として決めた）。

## 影響

- 差し戻しのたびに、合格だった最終レビューが見逃しとして台帳に残り、タスクの詳細でその件数と指摘を見られる。
