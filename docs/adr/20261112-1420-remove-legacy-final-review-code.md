# 以前の版の最終レビューの仕組み（依存 `finalReview`）のコードを消す

- 日時: 2026-11-12 14:20 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-334
- 置き換え元: なし
- 置き換え先: なし

## 背景

[実装の最終レビュー（テストの実行）と PR の CI の待ちをやめた](20261112-0714-review-child-task-replaces-final-review-and-ci-wait.md)
とき、最終レビューの仕組み（テストの実行・CI の待ち・失敗した CI の再実行・不安定なテストの台帳への記録）は、デーモンの依存
`finalReview` を有効にしたときだけ動く形で残した（デーモンの起動では無効）。工程の流れを確かめる既存のテストの多くが最終レビューを
通る形で書かれていて、一度に書き換えると変更が大きくなるためで、[ゴールガーディアンの撤去](20261112-0820-remove-goal-guardian.md)
と合わせて、別の変更で消すことにしていた。

ゴールガーディアンを撤去した後は、この仕組みを動かす手段が利用者に無い。使われない道筋が残ると、保守のたびに両方を考える必要があり、
テストも今の流れではなく、使われない流れを確かめることになる。

## 決定

- デーモンの依存 `finalReview` と、最終レビュー・テストのコンテナでの実行・PR の CI の待ち・失敗した CI の再実行・不安定なテストの
  台帳への記録のコードを消す。実装の工程の後は、いつも今の流れ（`FinalReviewSkipped` を記録し、実装の PR をドラフトで作って
  承認待ちにし、PR のレビューの子タスクに渡す）で進む。
- 最終レビュー・CI の待ちの途中だった古いタスクを、次の実行で今の流れに乗せる移行は残す。
- 古い台帳を読めることは保つ。最終レビュー・テスト・CI の待ちの記録（`FinalReviewed`・`FinalReviewFailed`・`TestsRun`・
  PR の公開の `verifying` など）の型・投影・作業履歴と費用の表示は残し、以前の版の記録として出す。不安定なテストの台帳を読む API と、
  台帳からタスクを作る口も残す。
- 工程の流れを確かめるテストは、今の流れで同じ意図を確かめる形に書き換え、最終レビューにだけ関わるテストは消す。

## 理由

- 利用者が動かせない道筋のコードとテストを保守し続ける理由が無い。
- 今の流れを確かめるテストに寄せると、テストが実際の振る舞いを守るようになる。
- 台帳は書き換えない方針なので、古い記録を読む部分は消せない。

## 影響

- 振る舞いは変わらない（デーモンの起動では、すでに無効だった）。
- 最終レビューを前提にしたテストの多くを書き換える・消す。
