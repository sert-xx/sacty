# デスクトップ版の標準イメージ移行と通知の権限を限定する

- 日時: 2026-10-30 14:27 UTC
- ステータス: 採用
- 関係する PR・タスク: なし
- 置き換え元: なし
- 置き換え先: なし

## 背景

既存設定の標準イメージ名が以前の版に固定されていると、アプリを置き換えても同梱版を利用できない。権限の一律拒否では既存のデスクトップ通知を使えず、日本語固定の準備画面も既存の文言方針に合わない。

## 決定

過去の標準イメージだけを利用者の確認後に移行する。イメージを確認してから設定をバックアップし、名前だけを変更する。独自の名前と将来の版は変更しない。

通知だけをメイン画面の同じオリジンから許可し、通知のオン・オフは既存画面に任せる。その他の権限は拒否する。準備画面に日英辞書と選択を設け、既存の言語cookieでメイン画面と共有する。

## 理由

手動のアプリ更新を成立させつつ、独自設定と利用者の選択を守るため。既存の通知と翻訳の方針をデスクトップの入口でも維持するため。

## 影響

設定の移行確認とバックアップが増える。OSの通知許可は別途必要になる場合がある。署名・公証・自動更新は今回も範囲外とする。
