# デスクトップ版の診断出力は秘密情報を除去して容量制限付きで保持する

- 日時: 2026-10-31 10:27 UTC
- ステータス: 採用
- 関係する PR・タスク: PR #256
- 置き換え元: なし
- 置き換え先: なし

## 背景

CLIの出力が読み捨てられ、ポート競合などの起動失敗の原因を利用者が確認できない。

## 決定

起動前後の出力を最大64KiBだけメモリで保持する。行単位で認証情報・既知のキー形式・URLの認証情報とクエリを除去し、1行8KiBを超える出力は破棄する。起動失敗時の準備画面と異常終了時の案内で表示する。ディスク保存や外部送信は行わない。

## 理由

原因の確認を可能にしつつ、チャンク境界で秘密情報の除去が抜けることと、無制限の保持を防ぐため。

## 影響

大量・長大な出力のすべては残らない。再試行時には前の診断表示を消す。受信文字列はHTMLとして解釈しない。
