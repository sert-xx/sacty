# 再開の補足で決めた範囲を PR のレビューに渡す

- 日時: 2026-11-23 22:45 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-499
- 置き換え元: なし
- 置き換え先: なし

## 背景

人が再開時に範囲を決めても、レビューがその決定を知らずに同じ原因を要修正にすることがあった。

## 決定

再開の補足で特定した範囲外・受け入れ・後続対応の判断を、承認済みの要求要件・受け入れ条件より優先する。
補足が特定していない事柄の判定は変えない。
補足の後の変更でデータの破損・セキュリティ・取り消せない作用に当たるようになった場合は根拠とともに指摘する。

## 理由

人が定めた範囲をレビューにも伝え、同じ原因の指摘が繰り返されるのを防ぐため。

## 影響

全工程の PR の初回・再レビューに、伏せて切り詰めた補足をデータとして渡す。
依頼の本文に補足が入る既存の経路は変えていない。
その経路の伏せ・区切り・切り詰めの揃え方は後続の課題とする。
仕様は [承認](../spec/approval.md) を参照。
