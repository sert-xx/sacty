# マージ済みの作業履歴の書き換えを PR の CI で検出する

- 日時: 2026-11-23 16:14 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-497
- 置き換え元: なし
- 置き換え先: なし

## 背景

ほかのタスクのマージ済みの作業履歴が、main の取り込み後に書き換えられた。
レビューで検出したが、修正の往復が必要になった。

## 決定

PR の CI は、マージベースにある作業履歴への変更を検査する。
切れたリンクの修正と、同じタスクの既存行を変えない追記を許す。
同じタスクは PR の題の PBI 番号、番号が無い場合は PR 番号とファイル名で判定する。

## 理由

CI で検出するとレビュー前に記録の書き換えを直せる。
同じタスクの続きは既存の記録に追記でき、切れた参照も直せる。

## 影響

PR の題を変更したときも検査をやり直す。
題に PBI 番号が無い PR は、自分の PR 番号を持つファイルだけに追記できる。
