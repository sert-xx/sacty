# 質問欄で Ctrl + Enter と ⌘ + Enter を送信に使う

- 日時: 2026-10-24 09:14 UTC
- ステータス: 採用
- 関係する PR・タスク: なし
- 置き換え元: なし
- 置き換え先: なし

## 背景

質問欄からキーボードで送信できるようにする要求が承認された。
長文やログを入力する欄なので、通常の Enter と Shift + Enter による改行は維持する。

## 決定

質問欄だけで、Ctrl または Meta だけを修飾キーにした Enter を送信として扱う。
OS による分岐は入れず、変換中のイベントと keyCode 229 は送信しない。
既存のフォームの requestSubmit を呼び、必須入力の検証と Server Action を共有する。
送信イベントで同期的なガードを立て、送信中の再入力を防ぐ。

## 理由

承認済みの要求に従い、ボタンと同じ入力検証・成功・失敗の処理を使うため。
React が pending を描画する前にも連続入力が届くため、描画に依存しないガードが必要になる。

## 影響

ほかの複数行入力欄やデーモン API は変更しない。
画面に新しい案内文は加えず、日英のユーザードキュメントで操作を案内する。
仕様は[オーケストレーターに質問](../spec/tasks-and-steps.md#オーケストレーターに質問)に記載する。
