# タスクブランチに sacty が積んでいない変更があれば、実装を積まずに止め、人の変更を自動では取り込まない

- 日時: 2026-10-13 13:18 UTC
- ステータス: 採用
- 関係する PR・タスク: #67、PBI-57
- 置き換え元: なし
- 置き換え先: なし

## 背景

工程ごとの PR では、実装はタスクブランチの最新に積む。ただし実装の作業領域は起点のコミットのままで、引き継ぐのは要求要件・設計の
ファイルだけ。レビューで、人がタスクブランチに直接変更を積んだ（ベースブランチをマージした場合も同じ）ときに、実装の公開でその変更を
打ち消すコミットができ、そのまま push されることがわかった。

## 決定

- 実装を積む前に、sacty が最後にタスクブランチへ積んだコミット（まだ積んでいなければ起点のコミット）から、タスクブランチの最新までに
  変わったパスを確かめる。
- 要求要件・設計のファイルのほかに変更があれば、実装を積まず、PR も出さずに、変わったパスを示して一時停止する。人がその変更を取り除いて
  再開すると、実装の PR を出す。
- 人の変更を実装に自動では取り込まない。必要な変更は PR の指摘として書けば、sacty が実装に反映する。
- 出し直しのときは、sacty が積んだ実装のコミットから確かめる（sacty 自身の変更を人の変更と取り違えない）。

## 理由

- 止めるのは、人の変更を黙って取り消さないため（レビュー）。
- 自動で取り込まないのは、人の変更を取り込むと、テストで確かめていないコードが PR に混ざるため（返信）。

## 影響

- タスクブランチに人が直接変更を積むと、実装の PR の前でタスクが止まる。続けるには、その変更を取り除くか、PR の指摘として書く。
