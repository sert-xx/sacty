# タスクの作成時に複数のリポジトリを指定し、候補を絞る

- 日時: 2026-11-15 23:52 UTC
- ステータス: 採用

- 置き換え元: なし
- 置き換え先: なし

## 背景

複数のリポジトリにまたがる仕事で、作成時に対象を限定したい。
既存のリポジトリを指定しないタスクは、プロジェクトの対象全体から候補を選ぶ。

## 決定

作成 API は単数の指定に加えて一覧を受け付ける。
重複を除いて1件なら単数と同じにし、2〜10件なら一覧を記録してリポジトリの無いタスクとして進める。
オーケストレーター、人の選択、分割と情報収集は一覧に候補を限定する。
情報収集、オーケストレーター、人の選択、要求要件・設計・分割で指定先を現在の対象と照合する。
確認できないときは停止または選択を拒否し、再開時に再照合する。
選択後の分割も子ごとに一覧から選び、統合レビューは子ごとのリポジトリを使う。

## 理由

既存のリポジトリの無いタスクの進め方を使いながら、指定外への分割や選択を防ぐため。
重複を除く上限は、複数リポジトリを読む際の準備量を抑えるために設ける。

## 影響

単数の入力と古い作業履歴の意味は変わらない。
再実行やテンプレートの入力には一覧を追加しない。
詳細は [タスクと工程](../spec/tasks-and-steps.md) と [分割と統合レビュー](../spec/split-and-integrate.md) に記す。
