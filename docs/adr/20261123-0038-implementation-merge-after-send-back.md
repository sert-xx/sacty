# 前の工程へ戻した後も実装 PR のマージを承認にする

- 日時: 2026-11-23 00:38 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-494
- 置き換え元: なし
- 置き換え先: なし

## 背景

実装 PR をマージするとタスクブランチが消える場合がある。
要求要件や設計へ戻したタスクが実装 PR を見守っていないと、工程 PR の公開で消えたブランチの取得に失敗する。
PBI-276 は前の工程をやり直している間は実装 PR を見守らないと決めていた。

## 決定

前の工程をやり直している間も実装 PR を見守り、マージを実装の承認にする。
承認と成果は、記録されたタスクブランチの先頭に対応する基準に戻す。
工程 PR と実装 PR の両方が同じ確認でマージ済みなら一時停止し、再開後は実装 PR だけを承認にする。
残った工程 PR は閉じるまで再試行し、すでにマージされていれば承認にせずマージ済みと記録する。

## 理由

人のマージを承認とし、削除されたブランチの取得で作業が止まることを防ぐ。
両 PR の順序や包含は同じ確認だけでは確定できないため、人の判断を待つ。

## 影響

前の工程へ戻している間に、マージ・実装の PR の閉じた・開き直した状態・工程の PR の片付け、または一時停止中・エスカレーション中の両 PR マージによる一時停止を記録すると、前の版のデーモンは投影できない。
通常の待機状態からの両 PR マージによる一時停止が1件なら投影できるが、判断済みの PR の番号が失われる。複数の工程 PR による停止が続く場合は2件目の投影で止まるため、いずれも版を戻せない。
コミットが記録された基準と違う場合は編集済みとして進み、包含関係は保証しない。
