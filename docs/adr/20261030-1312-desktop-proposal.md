# デスクトップ試作版は既存 CLI と同梱イメージを使う

- 日時: 2026-10-30 13:12 UTC
- ステータス: 採用
- 関係する PR・タスク: なし
- 置き換え元: なし
- 置き換え先: なし

## 背景

利用者の Node.js 導入・ソースビルド・コンテナイメージ作成を省略する提案を、動くアプリで検討する。

## 決定

macOS 向けに Electron の試作を足す。既存 CLI を独立した Node.js で起動し、画面と停止処理を再利用する。既定イメージはローカルで作成したものを圧縮して同梱する。Docker と GitHub CLI は外部のものを使う。既存 CLI の利用方法は変えない。

## 理由

Electron 内蔵 Node.js とリポジトリ指定版の違いを避け、既存の認証・単一起動・停止の仕組みを再利用するため。公開レジストリの運用を決める前でも、ローカルで動作確認できるため。

## 影響

アプリは大きくなる。今回の実装は提案用で、署名・公証・自動更新には対応しない。正式な配布方法とイメージ更新方式は別途検討する。
