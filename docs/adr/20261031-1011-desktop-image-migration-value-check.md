# イメージ移行では他の設定値が変わる更新を拒否する

- 日時: 2026-10-31 10:11 UTC
- ステータス: 採用
- 関係する PR・タスク: PR #256
- 置き換え元: なし
- 置き換え先: なし

## 背景

標準イメージ名にYAMLアンカーが付いていると、値の更新が共有参照先にも及ぶ。他の設定値を保持するという移行の要件を満たさない。

## 決定

書き出すYAMLを再解釈し、最上位のイメージ名だけを変更した期待値と比較する。一致しなければ、バックアップや一時ファイルを作る前に拒否する。画面には共有参照を分けてから再試行する案内を出す。

## 理由

共有参照の書き換えを暗黙に行わず、独自イメージなどの設定値を保つため。影響を受けないアンカーやエイリアスは引き続き利用できる。

## 影響

共有参照によって他の値が変わる設定は手動で参照を分ける必要がある。元の設定ファイルは保持する。
