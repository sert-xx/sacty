# キー保存の成否は出力が閉じてから確認する

- 日時: 2026-10-31 10:17 UTC
- ステータス: 採用
- 関係する PR・タスク: PR #256
- 置き換え元: なし
- 置き換え先: なし

## 背景

キーチェーンの保存処理は終了コード0でも標準エラー出力で失敗を通知する。チャンクごとの検索やexit時点での判定では、分割された表記や遅れて届く出力を見逃す。

## 決定

標準エラー出力は最大64KiBを保持し、標準入出力が閉じるcloseイベントで終了コードとエラー表記を確認する。上限超過は失敗とする。保存エラーは固定の案内にし、受信出力を画面やログに出さない。

## 理由

すべての出力を待ち、分割されたエラー表記も判定するため。容量超過時に診断が不完全なまま成功としないため。

## 影響

終了通知だけでは保存成功を表示しない。通常でない大量出力も失敗として案内する。実キーを使わず模擬プロセスで到着順と上限を検査する。
