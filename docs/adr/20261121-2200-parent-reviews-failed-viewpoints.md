# 観点の担当が起動し直しても失敗したときは、親が代わりに見る

- 日時: 2026-11-21 22:00 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-459
- 置き換え元: なし
- 置き換え先: なし

## 背景

担当が1回起動し直しても失敗した観点は「見られなかった観点」になり、`must` が無ければ判定を書かなかった（[PBI-343 の ADR](20261114-0158-review-range-and-partial-verdict.md)）。利用者が、判定が付かない回があると報告した。

## 決定

- `pr-review` と `self-review` で、起動し直しても失敗した観点（起動できない・`failed`・時間切れ）だけ、すべての担当の結果が揃った後に、親が担当に渡すはずだった依頼文・範囲・観点の資料のとおりに代わりに見る。
- 見られたら「見られた観点」に数え、指摘は担当の指摘と同じに集約・採否にかける。見られなかったときだけ「見られなかった観点」にする。
- 範囲の外を見ていないことだけが理由の `failed` は、起動し直さず、代わりにも見ない。担当を1件も起動しない回と、結果が揃うまで親が調査しない決まりは変えない。
- 代わりに見たことは、投稿する本文・提出物の説明に書かず、集約の記録に残す。

## 理由

- 利用者の決定（2026-11-21）：代わりに見てよいのは起動し直しても失敗した観点だけ。本文には書かない。
- PBI-343 の「見ていない所に `must` が隠れているかもしれない」という判断は、代わりに見ても見られなかった観点にだけ当てはめることで保つ。
- 比べた案：Sacty 本体が判定の無い回をやり直す案は、範囲の外とした。
