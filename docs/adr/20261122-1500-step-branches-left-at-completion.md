# 完了で消せなかった工程のブランチは、やり直さず記録して画面に出す

- 日時: 2026-11-22 15:00 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-480
- 置き換え元: なし
- 置き換え先: なし

## 背景

実装の無い進め方の工程のブランチは、`settleStepBranches` の 1 か所の規則で消す（[ADR 20261121-2215](20261121-2215-step-pull-requests-to-base-branch-without-implementation.md)）。この片付けに次の不具合があった。

- 記録の無いブランチを残す知らせ（`cleanup.stepBranchUnrecorded`）を、文の部品のまま渡し、画面に `[object Object]` と出た。
- 準備に失敗した知らせと、中止の cleanup の失敗の知らせが、詳細に日本語の文を埋め込み、英語の画面に日本語が混ざった。
- 完了の片付けは、消せなかったブランチの結果を捨て、直後に作業領域と git のメタデータを消した。消せなかったブランチは、誰にも知らされずリモートに残った。
- 期待する先頭を付けた削除が `stale info` で断られた場合を扱っていなかった。

## 決定

- 知らせは、コードと引数（`DaemonText`）で持ち、画面の言語の文で出す。`cleanup.stepBranchPrepareFailed`・`cleanup.stepBranchFailed` の `detail` は入れ子の文言（`TextParam`）にする。
- 完了で消せなかったブランチは、やり直さず、新しいイベント `StepBranchesLeft`（ブランチと理由の一覧）に記録し、タスクの詳細に出す。人が GitHub で消す。
  - 記録は作業領域を消す前にする。記録に失敗しても、完了の片付けは続ける。
  - 今回の消せなかったすべてのブランチで記録する。記録済みの内容と同じなら足さない。減った・空になったときも記録し、表示を直す（起動時の片付けで、作業領域の削除が一部失敗して git のメタデータが残ったときだけ、もう一度走る）。
  - `cleanup.stepBranchNoGitDir` で終わった片付けは、判定できなかったものとして使わない。
  - 投影は最新の記録で置き換え、空なら欄を消す。工程のブランチに無いブランチは整合性のエラーにする。
- 期待する先頭を付けた削除が `stale info` で断られたら、`deleteBranch` が `git.branchLeaseRejected` を投げ、`settleStepBranch` がリモートの先頭を取得し直す。
  - リモートに無い：消せたものとする。
  - 最後の push と違う：`StepBranchKept` を記録して残す。
  - 同じ・取得に失敗：消し直さず、消せなかったものとする。

## 理由

- 完了の片付けは作業領域を用意し直せず（`prepare: false`）、直後に作業領域と git のメタデータ（認証に使うものを含む）を消す。後でやり直す元が残らない。メタデータを残してやり直す案は、残す期間と消す契機を新しく決める必要があり、記録の無いブランチはやり直しても消せない。
- `stale info` は、人が push した場合のほか、リモートのブランチが消えた場合にも出る。取得し直せば、どちらかを見分けられ、既存の「比べて違えば残す」の規則に合う。
- 先頭が同じときに消し直すと、誤検知で削除と断りを繰り返すおそれがあり、「確かめずに消さない」を一番狭く満たすため消し直さない。

## 影響

- 前の版のデーモンへ戻すと、`StepBranchesLeft` を読めず起動しない。`StepBranchKept` と同じ扱いとして許容する。書く契機は、完了の片付けと起動時の片付けで、直接の流れのタスクのブランチが消せなかったときだけである。
- 同じ `detail` を入れ子にした 2 つの文言は、前の版では形が合わず、コードだけが出る（起動は止まらない）。
- 完了で消せなかったブランチは、人が GitHub で消すまでリモートに残る。
- [ADR 20261121-2215](20261121-2215-step-pull-requests-to-base-branch-without-implementation.md) の決定は変えず、規則を足す。仕様は [承認](../spec/approval.md#実装の無い進め方の工程の-pr)・[作業履歴](../spec/event-log.md)・[タスクと工程](../spec/tasks-and-steps.md)、見え方は [タスク](../user/tasks.md#実装の無い進め方の-pr) にある。
