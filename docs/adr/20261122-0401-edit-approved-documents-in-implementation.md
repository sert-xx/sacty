# 実装の工程で承認済み文書の誤りを直す

- 日時: 2026-11-22 04:01 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-478
- 置き換え元: [最終レビューの写しに成果物を入れる](20261101-0353-superseded-include-pr-documents-in-final-review-copy.md)（決定 2・4・5）
- 置き換え先: なし

## 背景

承認済みの文書の書式の誤りが検査を落としても、実装の工程ではファイルを直せず、同じ指摘が繰り返された。

## 決定

実装の作業領域に承認済み文書を置き、承認した判断を変えない誤りを直接直せるようにする。
修正は実装の PR に含め、理由と差分を本文に記録する。
判断を変える必要がある場合は、設計の直しまたは前の工程への差し戻しで扱う。

## 理由

作業領域で検査を再現し、その場で文書を直せる。
配置した文書を実装の差分の判定から除き、修正を明示的に PR のコミットに入れる。

## 影響

文書を調べうる検証を使い回さない決定（20261106-0005）は維持する。
文書は作業領域にあるが、実装の木の ID には含まれない。
前の版に戻すと、配置済み文書が実装の変更として数えられる。
