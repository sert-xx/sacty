# 同梱イメージの読み込みを名前とCPUで限定する

- 日時: 2026-10-31 01:38 UTC
- ステータス: 採用
- 関係する PR・タスク: なし
- 置き換え元: なし
- 置き換え先: なし

## 背景

独自イメージだけが不足している場合にも標準アーカイブが読み込まれ、既存の標準タグを変更する可能性がある。

## 決定

同梱manifestの名前とCPUが一致する不足イメージだけを読み込む。独自イメージの不足では標準アーカイブに触れない。manifestが無い場合も読み込まない。準備画面の言語は既存Webと同じ1年間保存する。

## 理由

不足した独自イメージを標準アーカイブでは補えないため。不要な読み込みと既存タグへの副作用を防ぎ、再起動時の選択も保つため。

## 影響

不完全なパッケージや独自イメージの不足はエラーとして案内する。DockerとGitHub認証の失敗は原因を直して同じ画面から再試行できる。
