# PR のレビューでは文書の照合を差分の範囲に絞り、観点を見きれなくても要修正があれば判定を出す

- 日時: 2026-11-14 01:58 UTC
- ステータス: 採用
- 関係する PR・タスク: #367、PBI-343
- 置き換え元: なし
- 置き換え先: なし

## 背景

PR のレビューの子タスクが、日英のユーザードキュメントを少し直しただけの PR で、2回続けて判定を出せずに止まった。
文書の同期の観点（U-1）が、手順の「文書の中の検証できる記述を全部拾う」に従い、差分に関係しない節まで実装と照らし合わせようとして、
終えられずに `failed` を返した。`pr-review` は、起動し直しても `failed` の観点が残ると判定を書かない。前回の指摘の確認と検証は済んでいて、
新しい指摘も無かったが、人が確かめてマージするしかなかった。

## 決定

- U-1 が検証できる記述を拾うのは、依頼文の範囲の中だけにする。範囲が変更なら、差分で変えた・足した記述と、差分の変更で正しさが変わりうる記述に
  限る。対象の文書を全体で渡されたときは、今までどおり全体から拾う。範囲の外を見なかったことは、担当の `failed` の理由にしない。
- `pr-review` で、起動し直しても `failed` の観点が残ったとき、見られた観点で採用した `must` があれば判定を「修正が必要」にする。
  無ければ、今までどおり判定を書かない。sacty がレビューに渡すプロンプトの判定の指示も同じにする。

## 理由

- 指摘の基準は、もとから `pr-review` の初回では「今回の変更が持ち込んだ問題か、変更した箇所に接していて作者が直せる問題」に限っていた。
  U-1 の拾う範囲だけが文書の全体のままで、出さない指摘のために照合していた。
- 見られなかった観点があっても、`must` があれば「直すべき」という結論は変わらない。判定が無いと、作者も sacty も直すべきかを決められない。
- 見ていない所に `must` が隠れているかもしれないので、`must` が無いときに「提案あり」「指摘なし」は出さない（人の判断。2026-11-14）。
  見た範囲で判定を出し、見ていない範囲を本文に書く案は、見ていない所を残したまま「指摘なし」になりうるので採らなかった。

## 影響

- 大きな文書を少し直した PR でも、U-1 が差分の範囲で終わる。差分に関係しない節の古い記述は、PR のレビューでは見つからない。
- 判定が無い回は、`must` の無い、見きれなかった回だけになる。
