# 実装の整形対象を変更したファイルに限る

- 日時: 2026-11-22 22:59 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-493
- 置き換え元: なし
- 置き換え先: なし

## 背景

実装の差分に依頼と関係ない整形が混ざり、レビューの負担が増えている。

## 決定

実装と直しの指示で、整形を変更したファイルに限り、依頼で変えていないファイルの整形だけの変更を提出から除くよう求める。
依頼で変えたファイル内の整形は許す。
検出や自動で戻す仕組みは設けない。

## 理由

指示で範囲を伝え、リポジトリごとに異なる整形の仕組みに依存しないようにする。

## 影響

- 関係する仕様書：[タスクと工程](../spec/tasks-and-steps.md)
- 指示を見落とした場合、不要な整形が提出に残りうる。
