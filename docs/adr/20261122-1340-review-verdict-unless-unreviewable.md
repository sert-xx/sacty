# PR のレビューの判定を付ける条件

- 日時: 2026-11-22 13:40 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-485
- 置き換え元: [レビューの範囲と判定](20261114-0158-superseded-review-range-and-partial-verdict.md)（判定の部分）
- 置き換え先: なし

## 背景

CI の実行中など、確認できない所があるだけで判定が付かず、人が判断しにくかった。

## 決定

差分を読めない場合、または要求要件・設計の PR で主対象の文書を読めない場合は判定を付けない。
それ以外は未確認の所があっても指摘の重さに応じて判定する。
未確認の内容と読む人が確かめることは本文の最初に書く。

## 理由

見られた範囲の判定と未確認の内容を伝えることで、人が判断できる。
判定なしを限ることで、判定なしだけを理由とする直しを減らす。
新しい停止の仕組みは設けない。

## 影響

判定なしの回の取り込みと直し先の決め方は変えない。
判定を付けなかった回は、要求要件・設計の PR でも直しと再レビューに進む。
