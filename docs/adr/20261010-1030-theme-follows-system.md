# ライト・ダークはシステムの設定に従い、ユーザーメニューでブラウザごとに上書きできるようにする

- 日時: 2026-10-10 10:30 UTC
- ステータス: 採用
- 関係する PR・タスク: #10、PBI-4
- 置き換え元: なし
- 置き換え先: なし

## 背景

画面の共通枠（ヘッダー・サイドメニュー）を置くにあたり、ライト・ダークの見た目をどう決めるかを決める必要があった。

## 決定

- ライト・ダークは、OS（システム）の設定に従う。ユーザーメニューで「システムに従う・ライト・ダーク」を選んで上書きできる。
- 選んだ設定はブラウザに保存し、`<head>` のスクリプトで最初の描画の前に適用する。
- 「システムに従う」のときは、OS の設定の変更にもついていく。
- ヘッダーとサイドメニューは同じ面として、本文と境界線で区切る。ライトとダークで同じ作りにする。

## 理由

- 最初の描画の前に適用するのは、ちらつかないようにするため（PR の本文）。
- システムに従うことと、ブラウザに保存することの理由は記録に無い。

## 影響

- テーマの設定はブラウザごとで、サーバーやプロジェクトには残らない。
- 色を足すときは、ライトとダークの両方で同じ作りになるようにする。
