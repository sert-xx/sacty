# タスクの記録を追記専用の台帳（SQLite）に置き、タスクの状態はイベントから復元する

- 日時: 2026-10-10 06:28 UTC
- ステータス: 採用
- 関係する PR・タスク: #1、PBI-1
- 置き換え元: なし
- 置き換え先: なし

## 背景

チケットの作成や工程の決定を記録し、デーモンを再起動しても同じ状態を表示できるようにする必要があった。

## 決定

- タスクの記録は、SQLite の台帳にイベントとして追記する。UPDATE と DELETE は、データベースのトリガーで拒否する。
- 台帳に書き込むのはデーモンだけにする。
- タスクの状態は、台帳のイベントから復元する（`packages/core` の projection）。再起動の後も同じ状態になる。
- チケットを作ると、「チケットを作成」と「工程を決定」の2つのイベントを記録する。

## 理由

理由は記録に無い。

## 影響

- 記録した内容は、後から書き換えも削除もできない。台帳に書く前に、残してはいけない内容を取り除く必要がある。
- 画面に出す状態は、イベントの並びの解釈（projection）で決まる。
