# 予算の上限に達する実行で終えたレビューは、PR に投稿してから止める

- 日時: 2026-11-20 18:00 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-418
- 置き換え元: なし
- 置き換え先: なし

## 背景

2026-11-19、PR のレビューの子タスクが、6回目のレビューで予算の上限に達し、終えたレビューを投稿する前に予算で一時停止した。
人が上限を上げて再開するまでに PR が新しいコミットに進み、投稿されたレビューは古いコミットのものとして親のタスクに捨てられた。
[実行ごとの費用の台帳と予算による一時停止](20261010-0705-cost-budget-pause.md)は、1回の実行で上限を超えたときも通知を記録してから止めると決めていて、書き終えたレビューの投稿待ちも止めていた。

## 決定

- 書き終えたレビューの投稿待ちのタスクは、実行の完了の後の予算の判定で止めない。投稿は費用がかからないので、上限に達していても投稿する。
- 投稿の後は、予算に達していないときと同じに扱う。指摘なしなら完了し、そうでなければ見守る。
- 止めるのは、次の費用のかかる実行（再レビュー）の前にする。人が使った額より大きい上限を入れて再開すると、その時点の PR の先頭をレビューする。
- 上限の値・累計の数え方・80% の通知、レビュー以外の工程の判定は変えない。

## 理由

- 費用のかからない投稿を止めても、予算は守れない。止めると、結果が届かず、PR が進んで古いレビューになる害だけが出る。
- 実装の PR の作成も、費用がかからないので止めずに作る。同じ考え方に揃える。

## 影響

- 上限を超えた回のレビューには、「予算の上限で止まった」という PR への知らせが出ない。知らせは、次の再レビューの前に止まったときに出る。
- 旧版で投稿の前に予算で止まったタスクは、上限を上げて再開すると投稿する。
