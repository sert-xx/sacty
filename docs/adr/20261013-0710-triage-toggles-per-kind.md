# 自動のトリアージを種類ごとに sacty の設定で On/Off し、設定には Off にした種類だけを持つ

- 日時: 2026-10-13 07:10 UTC
- ステータス: 採用
- 関係する PR・タスク: #61、PBI-53
- 置き換え元: なし
- 置き換え先: なし

## 背景

自動のトリアージ（Issue・PR の取り込み、PR のレビューの取り込み）を止めるには、ラベルなどの設定を消すしかなかった。
ラベルなどの設定を残したまま、種類ごとに止められるようにする必要があった。

## 決定

- 「sacty の設定」に、種類ごとの On/Off を置く：「Issue を取り込む」「PR を取り込む」「自分にレビューが依頼された PR を取り込む」
  （これまでの切り替え）「レビュー用のラベルの PR を取り込む」。
- 設定には、Off にした種類の一覧（`triageOff`）だけを持つ。この項目の無い設定は、すべて On として動く。すべて On に戻したら
  項目を持たない。知らない種類は拒否する。
- Off の種類は GitHub に問い合わせない。取り込むラベルの検索は、Issue だけ Off なら `is:pr`、PR だけ Off なら `is:issue` を付け、
  両方 Off なら探さない。レビュー用のラベルを Off にすると、その検索をしない。検索の後に設定を変えても、Off の種類は取り込まない。
- 設定を変えたら、取り込みは読んだ位置を忘れて読み直す。
- プロジェクトの一覧の「取り込み」の欄に、Off にした種類を出す（Off にしたレビュー用のラベルは出さない）。
- JIRA のトリアージ（PBI-52）にも、同じ形で On/Off を足す。

## 理由

- ラベルなどの設定を残したまま止められるようにするため（PR の本文）。
- Off の一覧だけを持つ形にした理由は、明示されていない。PR の本文には、この形で、項目の無いこれまでの設定はすべて On として動き、
  何も変えなければこれまでどおり取り込む、と書かれている。
- ほかの案との比較は記録に無い。

## 影響

- 既存の設定はそのまま動く。Off にした種類のために GitHub の検索をしない。
- 後から足す取り込みの種類（JIRA など）も、同じ形で On/Off を持つ。
