# CLIの異常終了は出力の閉鎖を待たずに検知する

- 日時: 2026-10-31 12:10 UTC
- ステータス: 採用
- 関係する PR・タスク: PR #256
- 置き換え元: なし
- 置き換え先: なし

## 背景

CLIの子プロセスが標準出力を継承していると、CLIが終了してもcloseが通知されず、異常終了の案内が実行されない。

## 決定

起動後のCLIの異常終了はexitで検知する。残りの出力はcloseまで最大1秒だけ待ち、診断の案内とアプリの終了を行う。待機中に通常終了へ進んだ場合は異常終了を案内しない。

## 理由

診断の遅延出力を取り込みつつ、子がパイプを保持する場合も終了の検知を止めないため。

## 影響

待機期限より後の出力は案内に含まれない。標準入出力が閉じなければ期限で案内を続ける。
