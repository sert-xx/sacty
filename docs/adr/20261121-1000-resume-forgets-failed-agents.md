# 人が再開したら、そのタスクで失敗して使わないことにしたエージェントも忘れる

- 日時: 2026-11-21 10:00 UTC
- ステータス: 採用
- 関係する PR・タスク: PBI-437
- 置き換え元: なし
- 置き換え先: なし

## 背景

[理由を問わず代わりのエージェントでやり直す ADR](20261020-2317-agent-fallback-on-any-failure.md) は、試したエージェントを人の再開で忘れると決めたが、`auth`・`error` で失敗したエージェントの「使わない」の覚え（`failedAgents`）は決めていなかった。
選んだエージェントが利用上限の間に代わりが 1 回 `error` で失敗すると、再開しても代わりが飛ばされ、期限まで進めなかった。

## 決定

- 人が再開したら、そのタスクの `failedAgents` を忘れる。ほかのタスクの分と、利用上限の覚え（`limitedAgents`）は変えない。
- 再開していない間の振る舞いと、未完了の実装の続きの選び方（PBI-417）は変えない。

## 理由

- 利用者向けの文書は、再開すると選んだエージェントから順に試すとしている。再開は人が状況を見たうえでの合図なので、試し直す意味がある。

## 影響

- 期限の内に人が再開すると、失敗した代わりのエージェントも、もう一度試される。振る舞いは [仕様](../spec/agent-execution.md) の切り替えの節に書いた。
- 再開しない間の振る舞い、ほかのタスクの覚え、利用上限の覚えは変わらない。
