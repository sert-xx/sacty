# 同じ原因の要修正が続く場合に人の判断を求める

## 背景

同じ原因の要修正が繰り返され、人が範囲を絞る判断をするまで再レビューが続くことがある。

## 決定

2回目以降は範囲を絞る案と残る影響、満たせなくなる条件を示す。
3回目以降の PR レビューは印を付け、人の指摘が混ざっても既存の仕組みで停止する。
人の判断後にも同じ原因が続けば、同じ先頭の別のレビュー回でも再び止める。
根拠の文の先頭で同じ原因の3回目以降と示し、判断した回自体は止め直さない。
セルフレビューは停止せず、判断を求める内容を報告と画面に出す。

## 理由

案と影響を示せば人が範囲を判断できる。
PR では既存の停止と再開を使い、セルフレビューでは画面で知らせる。

## 影響

停止の条件とセルフレビューの報告に判断事項が加わる。
詳細は [レビューの規則](../spec/context.md) と [一時停止](../spec/approval.md) に書く。
