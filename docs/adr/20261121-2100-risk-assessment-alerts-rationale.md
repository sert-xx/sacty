# リスクの判断材料と人間への確認依頼を独立した Alert に分ける（理由を補った版）

- 日時: 2026-11-21 21:00 UTC
- ステータス: 採用
- 関係する PR・タスク: #500、PBI-458
- 置き換え元: [リスクの判断材料と人間への確認依頼を独立した Alert に分ける](20261121-0345-superseded-risk-assessment-alerts.md)
- 置き換え先: なし

## 背景

[置き換え元の ADR](20261121-0345-superseded-risk-assessment-alerts.md)（PR #500）は、決定と理由を書いたが、比べた案と採らなかった理由を書いていなかった。
ADR の本文は書き換えない決まりなので、決定を変えずに理由を補うため、新しい ADR を足して置き換える。

## 決定

置き換え元の決定を、そのまま引き継ぐ。

- 共通レンダラーで、低・中・高を NOTE・IMPORTANT・WARNING の GitHub Alert として描画する。1〜3 は区分番号で、点数や確率ではない。
- 根拠は低では1段落、中・高では項目に分け、レビューの深さ・合図・依存更新も同じ枠に置く。
- 人間への重点確認依頼は独立した TIP にし、無ければ省く。無い内容は補わない。
- 検証情報は自由文のまま、AI による目安の注記とともに枠外に置く。各 Alert の全行を引用し、枠の間は引用外の空行で分ける。
- 有効な相対パスと行の指定は、対象リポジトリのホストと評価記録のコミットを使ってリンクにする。不明・不正な指定はテキストにする。

## 理由

- 判断材料と人への作業依頼を分けると、何を根拠にどこを確認するかが読み取れる。
- 評価したコミットへの固定リンクで、後から先頭が変わっても同じ対象を確認できる。
- 自由文の検証情報を機械的に分割しないことで、記録の意味を変えずに表示できる。
- 比べたほかの案と、採らなかった理由：PR #500 の本文・ADR・レビューには、比べた案が書かれていない。比べたかどうかも、わからない（推測では書かない）。

## 影響

置き換え元の影響と同じ。指摘なしのレビューコメントと、残った提案をすべて対応しないとした回の専用コメントに適用する。
[仕様書](../spec/risk-assessment.md)に表示とリンクの条件を記載する。
