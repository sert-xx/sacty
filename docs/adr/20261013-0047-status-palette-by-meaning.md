# タスクの状態を意味の種類で色分けし、完了と中止は色だけでなく印の形でも見分けられるようにする

- 日時: 2026-10-13 00:47 UTC
- ステータス: 採用
- 関係する PR・タスク: #50、PBI-42
- 置き換え元: なし
- 置き換え先: なし

## 背景

タスクの状態の表示で、完了と中止がどちらも灰色だった。#47 で完了を緑（既存の `--ok` の色）にしたが、ほかの状態との並びを考えずに決めていた。

## 決定

状態を、意味で次の5つの種類に分けて表示する（一覧・詳細・子タスクの一覧で同じ）。

| 種類 | 状態 | 色・印 |
| --- | --- | --- |
| 進めている | 実行中・子タスクの完了待ち・テストの実行中・最終レビュー中・ゴールガーディアンの判定中 | 青の点 |
| 待っている | 実行待ち・依存の完了待ち | 灰の点 |
| 人の出番 | 承認待ち・判断待ち・一時停止 | 橙の点 |
| 完了 | 完了 | 緑のチェック |
| 中止 | 中止 | 灰の輪（中を抜いた丸） |

- 完了していない idle（テストの実行中・最終レビュー中など）は「進めている」にする。
- 承認待ちのうち、ゴールガーディアンが PR の指摘を判断している間は「進めている」にする。

## 理由

- 完了していない idle は、sacty が進めているので青にした（PR の本文）。
- ゴールガーディアンが PR の指摘を判断している間は、人の出番ではないので青にした（PR の本文）。
- 完了（緑）と人の出番（橙）は、色覚によっては見分けにくいので、完了はチェックの印にした。中止は、実行待ち（灰の点）と見分けられるよう輪にした（PR の本文）。

## 影響

- 状態を足すときは、5つの種類のどれに当たるかを決める。
- 完了と中止は、色を見分けられなくても印の形で見分けられる。
