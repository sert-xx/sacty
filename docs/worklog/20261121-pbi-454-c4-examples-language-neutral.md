## 目的

既定のコンテキストは、あらゆる言語の対象リポジトリのレビューに配られる。C-4 の NG 例4・例7 が特定の言語・ランタイムの API・用語に寄っていたので、言語に依らない擬似コードと言葉の説明にする。伝える中身は変えない。

## したこと

- `apps/daemon/default-context/skills/review/review-execution/references/C-4.md` の例4・例7 の見出しを「（任意）」にし、コードを擬似コードに、説明を言語・ランタイム固有の語の無い文にした。
- 例4・例7 以外の文と、ほかの観点の references は変えていない。
- 方針の変更ではないので、ADR は足していない。

## 確かめたこと

- `npm run lint`（biome）を実行し、通った。ただし biome は Markdown を検査しないので、この変更（Markdown だけ）は lint の検査対象になっていない。
- `npx vitest run tests/docs` を実行し、3 ファイル 93 件が通った（作業履歴のファイル名・リンクの規則を含む）。
- コードのテスト（`npm test` 全体）・typecheck・ビルドは、文書だけの変更なので実行していない。
- 例4・例7 に、言語名・ランタイム名・固有の API・用語が残っていないことを、差分で読んで確かめた。
