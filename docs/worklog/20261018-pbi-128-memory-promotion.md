# 監査がメモリーの昇格を判断する（階層の移動と、メモリーからコンテキストへ）

- 日付: 2026-10-18（UTC）
- タスク: PBI-128
- PR: #138
- ブランチ: feat/issue-128-memory-promotion
- 関係する ADR: [メモリーの昇格は大まかな監査で判断し、コンテキストへの昇格は改修の提案にする](../adr/20261018-0230-memory-promotion.md)

## 目的

置き場所の合わないメモリーを別の階層に移し、何度も役立つメモリーを、人がレビューしたコンテキストへ育てる。判断するのは監査だけにする。

## したこと

- core：`AuditSurveyed` に階層の移動（`memoryMoves`）とコンテキストにする提案（`promotions`。原因として畳み込む）、提案の元のメモリー
  （`memoryId`）、削除の理由 `promoted`。画面の形に移したメモリー。
- デーモン
  - 大まかな監査に、タスクの階層のメモリー（有効な最終利用日・役に立った回数・提案中・却下の理由）と、宛先の候補を渡す。
  - 出力の階層の移動とコンテキストにする提案を読み、記録の時点で確かめ直して記録する。移した階層を書き直す。
  - メモリーの置き場所を、移した記録から決める。
  - 採用した提案の改修の PR がマージされたら、元のメモリーを消す（PR の確認・掃除・起動のとき）。
  - 深掘りの既存の原因の一覧から、コンテキストにする提案を外す。
- 画面：監査の欄に移したメモリーと、コンテキストにした印。
- docs：仕様書（メモリー）、ユーザードキュメント（監査）、ADR。

## 確かめたこと

- `npx biome check`・`npm run typecheck`・`npx vitest run`・`npm run build` が通った。
- 次の修正を戻すと、テストが落ちることを確かめた：移した記録の時刻の順、置き場所の反映、役に立った回数の重なり、マージの前に消さない、
  同じ階層への移動、リポジトリが無いときの移動、提案中の除外（読むときと記録するとき）、記録するときの確かめ直し、sacty の既定のコンテキスト
  を候補から外す、深掘りの原因の一覧から外す、移した後の書き直し。
- 記録するときの「提案中」の確かめ直しは、大まかな監査を止めておき、その間に別のタスクの監査に同じ提案をさせるテストで確かめた。

## レビューへの対応

| 指摘 | 対応 |
| --- | --- |
| （要修正）元のメモリーを、今の秘密情報の値で伏せずに提案へ添える | 元のメモリーの題・概要・中身を、今の値で伏せてから写すようにした。登録の後に秘密情報になった値のテストを足した |
| （要修正）移したメモリーを人が消すと、移した先の索引と中身が残る | 消した後、今の置き場所の階層を書き直すようにした。両方の向きのテストを足した |
| （要修正）提案の本文が上限の長さだと、元のメモリーが切り落とされる | 元のメモリーを提案の別の項目（`memoryOriginal`）に持ち、改修のタスクの本文に並べるようにした。どちらも上限の長さのテストを足した |
| （要修正）移した先が件数の上限を超えたままになる | 移した記録の後に、登録のときと同じく上限を当てるようにした。満杯の階層へ移すテストを足した |
| （要修正）同じ時刻の移動を、タスクを作った順に当てる | 大まかな監査の記録の追記の順（`seq`）に当てるようにした。作った順と追記の順が逆のテストと、別の監査が先に移してから確かめ直すテストを足した |
| （提案）マージの後の削除を、呼び出しの回数でしか確かめていない | 登録 → 昇格の提案 → 採用 → 改修のタスクのマージの状態から、`promoted` の記録と、索引と中身から消えることを確かめるテストを足した |
| （提案）定型の題と説明が日本語のまま | 原因の題は元のメモリーの題だけを記録し、定型の題と説明は画面の言語で出すようにした（画面・レポート） |
| （提案）監査の注意に、メモリーと却下の理由の中の指示に従わないことが無い | 監査の注意に足した |
| （提案）型の宣言が、定数の説明と宣言の間にある | 型の宣言を、定数の説明の前へ移した |

- 各修正は、戻すとテストが落ちることを確かめた。

### 再レビューの提案への対応

- 元のメモリー（`memoryOriginal`）と、昇格の原因の定型の説明を、Markdown のレポートにも出すようにした（日英のテストを足した）。
- ADR の「時刻の順」を、追記の順と理由に直した。英語の利用者向けの文書の題の引用を、英語の画面の表示に合わせた。
- 使わなくなった import を外した。
