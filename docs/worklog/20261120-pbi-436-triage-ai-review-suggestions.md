# AI のレビューの提案に対応するかどうかを、直しに入る前に、PR の範囲を考えて AI が判断する

## 目的

sacty が作った実装の PR で、AI のレビューの提案だけの往復（直し・push・再レビュー）が続き、時間と費用がかかっていた。
直しに入る前に、AI が PR の範囲を考えて提案ごとに対応するかを決め、対応しない提案のためには往復を起こさないようにする。

受け入れ条件の要点は次のとおり。

- 提案（`[提案]`）だけを選り分ける。要修正と人の指摘は選り分けずに直す。
- 対応しない判断は AI で終え、理由を PR に返信する。人は PR に要対応とコメントして覆せる。
- 判断できなかった提案は、対応する側にして直す。
- 直す指摘が残らなければ直しに入らず、同じ先頭を 1 回だけ判定し直させる。その回も提案がすべて対応しないなら、一時停止して人が選ぶ。
- 再レビューは、対応しないとした提案を未対応に数えず、蒸し返さない。
