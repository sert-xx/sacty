# 親タスクの統合レビュー

- 日付: 2026-10-12（UTC）
- タスク: PBI-31
- PR: #37
- ブランチ: feat/issue-31-integration-review
- 関係する ADR: [子タスクがすべて片付いた親は、ゴールガーディアンの統合レビューを通り、人間が承認してから完了にする](../adr/20261012-0718-parent-integration-review.md)

## 目的

構想の、親の完了条件（すべての子が完了し、親の統合の観点による最終レビューを通ったとき）を実装する。タスク分割の組み合わせに
統合レビューの工程を足す。受け入れ条件の要点：子がすべて片付くと親は統合レビューへ進む、ゴールガーディアンがベースブランチの最新の
コードを読み取り専用で読んで判定し読んだコミットを記録する、合格なら人間の承認で完了、不合格なら修正の子タスクを追加して
やり直す、続けて3回不合格なら不合格のまま承認待ち、差し戻しで修正の子タスクを追加し合格の差し戻しは見逃しとして記録、
実行できなければ理由を記録して止め費用は親の予算に入れる、画面に結果と修正の子タスクの印、日本語・英語。

## したこと

- core（`packages/core/src/events.ts`・`packages/core/src/projection.ts`）：工程 `integrate`、イベント `IntegrationReviewed`、不合格でタスク分割に戻す・
  上限で承認待ちにする作業履歴の適用、2回目以降の分割は子タスクを追加する。
- daemon（`apps/daemon/src/service.ts`・`apps/daemon/src/prompts.ts`・`apps/daemon/src/repository.ts`）：統合レビューの実行（ベースブランチの
  最新を取得して書き出し、ゴールガーディアンに読ませる）、修正の子タスクの追加の指示（統合レビューの結果・これまでの子タスク・
  人間の指摘）、`fetchBranch`。
- web（`apps/web/src/components/integration.tsx`・`apps/web/src/app/tasks/[id]/page.tsx`・`apps/web/src/app/tasks/[id]/review/page.tsx` など）：
  統合レビューの結果のカード（タスク詳細・承認の画面）、修正の子タスクの印、状態・作業履歴の表示。
- この変更より前に分割したタスクは、これまでどおり子の完了で完了する。

## 確かめたこと

- `npm test`（342 件）・`npm run lint`・`npm run typecheck` が通った。
- 合格・不合格 → 修正の子タスク → 再レビュー・3回の上限と差し戻し・見逃しの記録・ベースブランチの取得の失敗と再開・この変更より前の
  分割を、デーモンのテストで確かめた。
- 不合格でタスク分割に戻す・上限で承認待ちにする・子の完了で統合レビューへ進む・見逃しの記録・修正の子タスクの1件・差し戻しで回数を
  数え直す・足りないことがあれば不合格・指摘への対応の記録について、それぞれ修正を戻すとテストが失敗することを確かめた。
- レビューでも、`npm test`（24 ファイル・342 件）・lint・typecheck の成功を確かめた（最新のブランチの取得には、ローカルの Git リポジトリを
  使うテストも含む）。実際の AI・実際の Docker での一連の動作と、ブラウザでの画面の操作は確かめていない。
