# フォーム本文によるメソッド上書きを拒否する

- 日付: 2026-11-13（UTC）
- タスク: なし
- PR: #364
- ブランチ: sacty/task-dcf4eb65
- 関係する ADR: なし

## 目的

フォーム本文のメソッド上書きによって、組織内 PF の許可リストを越える操作を防ぐ。

## したこと

URL エンコード形式と multipart 形式のフォームを検査し、メソッド上書きの名前があるフォーム、`identity` 以外の `Content-Encoding` を指定したフォーム、パートのヘッダーが 16 KiB を超えるか解析できない multipart、名前にバックスラッシュ、Content-Disposition に `name*` 属性、または同じパートに重複した名前属性や Content-Disposition を含む multipart を転送せず拒否する。

## 確かめたこと

`npm run lint`、`npm run typecheck`、`npm run build`、`npx vitest run --no-file-parallelism` が通った。
回帰テストは修正前のコードで `_method=DELETE` が転送されて失敗することを確かめた。

## レビューの指摘と対応

multipart の境界とヘッダーだけを順に検査し、値やファイルの内容を誤って拒否せず、全項目の展開によるメモリー増幅を防いだ。重複した境界、単独の LF に続く境界や境界直後の LF、単独の CR・LF を含むヘッダーと閉じ境界後の境界を拒否し、空フォームは転送する。preamble の境界候補は接尾辞を確認し、開始・中間・最終境界の空白を受け入れる。境界候補と項目数を 10,000 に制限し、空項目も数える。URL エンコード形式は値を展開せず名前だけを検査し、名前を 16 KiB に制限する。パーセントエンコードされた名前も検査する。VT・FF・余分な CR 付き境界、引用符が曖昧な名前、別の属性に境界指定を含む Content-Type を拒否する。

## 残したこと
全展開によるメモリー増幅そのものを測定して検出するテストはない。
