# 既定のレビューに、既存の実装との調和を見る観点 C-18 を足す

- 日付: 2026-11-19（UTC）
- タスク: PBI-405
- PR: #449
- ブランチ: feat/issue-405-review-harmony-with-existing-code
- 関係する ADR: [既定のレビューに、既存の実装との調和を見る観点 C-18 を足す](../adr/20261119-1605-review-viewpoint-for-harmony-with-existing-code.md)

## 目的

既存のコードベースに変更を足す PR のレビューで、文書に書かれていないが、リポジトリを読み解けば分かる決まり（命名の方針・技術の使い方の方針・業務のロジックの置き場所の意図）への準拠を見られるようにする。
これまでは C-5（保守性・設計）の一部で、慣習を導く手順が無く、段階も `entry` だった。

## したこと

- 観点カタログ（`review-dispatch/references/viewpoints.md`）のコードの必須観点に C-18（既存の実装との調和）を足した。段階は `standard`。
- 担当の資料 `review-execution/references/C-18.md` を足した。
    - 慣習を導く手順（差分の外の同じ種類のコードを読む・慣習を書き出す・そろっているかを判定する・迷えば検索して数える）。
    - チェックポイント（命名の方針・置き場所・業務のロジックの置き場所・層の飛び越し・データアクセスの方法・共通の仕組みの迂回など）。
    - 重要度の決め方と、指摘にしないもの（割れている・例が少ない・理由が書かれている外れ）。
    - NG 例は 6 つの言語で書き、指摘にしない例を 2 つ入れた。特定のリポジトリには寄せていない。
- C-5 から、既存の規約・構成との整合を外した（カタログの行と `C-5.md`）。C-5 は、言語の一般的な慣習とリポジトリの書き方が食い違うとき、リポジトリの書き方に合っているものを指摘しない。
- 隣の観点の「見ないもの」に C-18 を書いた（C-15・C-17・X-3。カタログと各資料）。
- 明文の決まりとの照合を X-3 に任せる分担を、C-5 から C-18 に移した（`repo-guidance.md` の 5、`X-3.md` の例、`review-execution/SKILL.md`）。
- `self-review.md` の報告の例と、`review-execution/SKILL.md` の資料の範囲（C-1〜C-18）を直した。
- 仕様書（`docs/spec/context.md`・英語の版）に C-18 を書き、X-3 との分担の記述を直した。

起動の規則（再レビューの絞り方・軽い依頼の自己レビュー）と、ほかの観点の段階は変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通った。
- `npx vitest run tests/docs apps/daemon/src/default-skills.test.ts apps/daemon/src/prompts.test.ts`：449 件が通った。
- スキルの変更（`apps/daemon/default-context`）を戻すと、足した 4 件のうち 2 件と、直した 3 件が落ちることを確かめた（残りの 2 件は `C-18.md` の中身だけを見るテストで、ファイルを消せば落ちる）。
- `npx vitest run --no-file-parallelism`：271 ファイル・5,430 件が通った（スキップ 1 件）。
- 画面の変更が無いので、画面の動作確認はしていない。足した観点が、エージェントのレビューを実際にどう変えるか（慣習を導けるか・指摘が増えすぎないか）は、エージェントを動かして確かめていない。
