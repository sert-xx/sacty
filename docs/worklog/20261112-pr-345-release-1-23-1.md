# 版を 1.23.1 に上げる

- 日付: 2026-11-12（UTC）
- タスク: なし
- PR: #345
- ブランチ: feat/release-1-23-1
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.23.0 の後に入った変更（PR #342〜#344）をリリースする。セキュリティの修正・Node.js の下限の引き上げ・CI の追加だけで、機能の追加は無いので PATCH を上げる。

## 1.23.0 からの変更

- ゲートウェイでメソッドを上書きするクエリを断り、scp の形のコンテキストをデーモンのカレントディレクトリから取得しないようにし、脆弱性の報告の窓口を直した（PR #342）。
- Node.js の下限を、2026-11 のセキュリティリリースの修正版 26.13.1 に上げた（PR #343）。
- PR と main への push で、lint・型検査・テストを実行する CI を足した（PR #344）。利用者に見える変化は無い。

## 互換性の判断

- 設定ファイルの形・コマンドの引数に、互換性の無い変更は無い。新しい種類のイベントは足していない。
- `engines.node` が `>=26.13.1` になった（PR #343）。同じ 26.x の中のセキュリティの修正版への引き上げなので PATCH とし、リリースの説明の更新の後にすることに書く。
- ゲートウェイは、メソッドを上書きするクエリ（`_method` など）を 400 で断るようになった（PR #342）。これまで通っていた要求が断られうるので、リリースの説明の注意に書く。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.23.1` にし、`package-lock.json` の版の行を直した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.23.1` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.23.0 の版上げ（PR #341）と同じ範囲（`Dockerfile` を除く）。
  置き換えは前後に数字・`.` が無い `1.23.0` だけにし、テストの例の値が変わらないようにした。置き換えの対象から外し忘れた過去の作業履歴（PR #341）は戻した。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` は、`Dockerfile` に固定したもの（`sha256:5df79989…`）と同じだったので変えていない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通過。
- `npx vitest run`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- ADR・作業履歴のほかに `1.23.0` が残っていないこと、差分に版の置き換えしか無いことを確かめた。
