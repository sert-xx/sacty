# 人が再開したら、そのタスクで失敗して使わないことにしたエージェントも忘れる

- 日付: 2026-11-21（UTC）
- タスク: PBI-437
- PR: なし
- ブランチ: なし
- 関係する ADR: [20261121-1000-resume-forgets-failed-agents.md](../adr/20261121-1000-resume-forgets-failed-agents.md)

## 目的

選んだエージェントが利用上限の間に代わりが失敗して止まったタスクを、期限の内に再開しても、代わりが試されない問題を直す。

## したこと

- `apps/daemon/src/service.ts` の `resume()`：`fallbackTried` を忘れる所で、そのタスクの `failedAgents` も忘れる。
- `apps/daemon/src/daemon-steps.test.ts`：期限の内の再開で代わりが再び実行されること、利用上限の覚えが無いときの切り替えの記録、両方が利用上限のときの `usage_limit`、ほかのタスクの覚えが残ることを確かめるテストを足した（ほかのタスクは、試した記録を成功で忘れた形にして、使わない覚えだけで元を飛ばすことを確かめる）。修正を戻すと、前の 3 つが落ちる。
- 仕様・利用者向けの文書（日英）に、再開で忘れるものを書いた。

## 確かめたこと

- `npx vitest run apps/daemon/src/daemon-steps.test.ts -t 代わり`：17 件が通る。修正を戻すと 3 件が落ちる。
- `npm run lint`：通る（739 ファイル）。`npm run typecheck`：通る。`npx vitest run`：294 ファイル、5960 件が通り、14 件はスキップ。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 条件 3 のテストが、ほかのタスクの覚えを確かめていない | 試した記録を成功で忘れた形に直し、使わない覚えだけで元を飛ばすことを確かめる |
| 条件 2 のテストが、再開後に代わりが実行されたことを確かめていない | 3 回目が代わりであることの確認を足した |
| ADR・作業履歴にひな形の節が無い | ADR に `## 影響`、作業履歴に `## 残したこと` を足した |
