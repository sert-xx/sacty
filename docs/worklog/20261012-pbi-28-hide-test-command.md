# 実装をしないタスクには「テストのコマンド」を出さない

- 日付: 2026-10-12（UTC）
- タスク: PBI-28
- PR: #34
- ブランチ: feat/issue-28-hide-test-command
- 関係する ADR: なし

## 目的

調査だけ・レビューだけ・タスク分割の親など、工程に実装が無いタスクにも「テストのコマンド：（決められませんでした）」と出て
紛らわしかった。テストのコマンドは、工程に実装があるタスクだけに出す。ベースブランチはこれまでどおりすべてのタスクに出し、
実装のあるタスクで決められなかったときは、これまでどおり「（決められませんでした）」と出す。

## したこと

- タスクの詳細の工程の欄（`apps/web/src/app/tasks/[id]/page.tsx`）で、テストのコマンドは工程に実装があるときだけ出すようにした。
  判定は `apps/web/src/lib/labels.ts` の `usesTestCommand`。
- ベースブランチは、調査・レビュー・分割もベースブランチのコードを読むので、これまでどおりすべてのタスクに出す。

## 確かめたこと

- `npx vitest run`：319 件すべて成功。lint・typecheck も通った。
- 判定を常に「出す」に戻すと、テストが失敗することを確かめた。
- ビルドしたアプリ（スタブの AI）で、分割の親・調査だけの子には出ず、標準の工程のタスクには出ることを確かめた（動画あり）。
- レビューでは、関係するテスト（`labels.test.ts`）17 件・lint・typecheck が通ることを確かめた。全テスト・ブラウザの操作・ビルドは、
  レビューでは行っていない。
