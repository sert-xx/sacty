# 版を 1.5.0 に上げ、GitHub Release を作る

- 日付: 2026-10-21（JST）
- タスク: なし
- PR: #177
- ブランチ: chore/release-1-5-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.4.0 の後に、監査の改修の提案を、改善案に補足するか人の案に差し替えて採用できるようにする機能（PR #176）が入った。
機能の追加があるので MINOR を上げ、1.5.0 をリリースする。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.5.0` にし、`package-lock.json` の版の行も同じにした。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.5.0` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント
  （`config`・`images`）の日英と、イメージの名前を書いているテスト・コメントを同じ版にした。ゲートウェイの MCP クライアントの版の文字列も
  `1.5.0` にした。
- 更新の知らせのテスト（`update-check.test.ts`）の `1.4.0` は、版の比較のための値なので変えない。`apps/web` の `tw-animate-css` の
  `^1.4.0` は外部の依存の版なので変えない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`・`npm run build`：通過（`apps/daemon/dist/config.js` の `DEFAULT_IMAGE` が `sacty-agent:1.5.0`）。
- `npx vitest run`：123 ファイル・2408 件が通過。
- イメージの作り直しは、リリースの後に運用の環境で確かめる。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 一括置換で `tw-animate-css` の依存の版まで `^1.5.0` になっていた（セルフレビュー） | `^1.4.0` に戻した |
