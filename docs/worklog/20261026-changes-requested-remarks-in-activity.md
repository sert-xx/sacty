# タスクの詳細の作業履歴で、差し戻しの指摘の本文を読めるようにする

## 目的

人が差し戻しで書いた指摘の本文は、承認の画面の「指摘の履歴」にしか出ない。
承認の画面は承認待ち・エスカレーションの間しか中身を出さないので、承認した後や完了・中止した後には、過去の指摘を画面から読み返せなかった。
タスクの詳細の作業履歴では、差し戻しの行は件数（「指摘2件」）だけだった。
作業履歴の差し戻しの行から、その回の指摘の本文を読めるようにする。

## したこと

- `apps/web/src/lib/labels.ts` の `describeEventParts` で、`ChangesRequested` の行に詳細（`detail`）を持たせた。
  - 1行目は今までどおり（件数・戻し先・誰が）。
  - 詳細は、指摘の ID と本文を1件ずつ1行にしたもの。
  - 既存の「詳細」の展開（コンテキストの用意の行と同じ仕組み）を使う。
- 文言 `changesRemark` を日英の辞書（`apps/web/src/i18n/messages/labels.ts`）に足した。
- `apps/web/src/components/task-detail.tsx` の `EventText` の詳細に `whitespace-pre-line` を付け、詳細の改行を改行として出す。
  コンテキストの用意の行の詳細（層のサブエージェントと外部 PF を改行でつないでいる）も、改行して出るようになる。
- 仕様書（`docs/spec/ui-wording.md`・`approval.md` と英語の版）と、ユーザードキュメント（`docs/user/tasks.md` の「画面の補足」と英語の版）に書いた。

## 確かめたこと

- `npx vitest run apps/web`：514 件が通った（2 件はスキップ）。
  `apps/web/src/lib/labels.test.ts` に、差し戻しの行の詳細を日英で確かめるテストを足した。
  差し戻しの行の1行目を確かめていた既存のテストは、`describeEventParts` の `text` を確かめるようにした。
- `npm run lint`・`npm run typecheck`：通った。
- `npx vitest run tests/docs`：通った。
- 画面：スクリーンショットの仕組み（`scripts/docs-screenshots/`）の架空のデータに、一時的に差し戻しを足して撮り、作業履歴の差し戻しの行に「詳細」が出て、開くと指摘が1件ずつ改行して出ることを日英で確かめた（足した変更は戻した。ユーザードキュメントのスクリーンショットには差し戻しの行が写っていないので、撮り直していない）。
