## 目的

複数のリポジトリを指定したタスクの一覧と詳細が、作業先の選択前後に指定を表示することを日英で確かめる。

## したこと

- 一覧と詳細のテストを派生ダイアログのテストから、それぞれの表示用テストに移した。
- 作成と作業先の選択のイベントからタスクを投影し、一覧は `loadTaskList` を通して描画する。
- 指定が名前と URL の両方の場合について、選択後の作業先と指定一覧を日英で確かめる。
- リポジトリ無しの印に一覧でも `data-testid` を付け、指定のあるタスクで印が出ないことと、指定のないタスクで印が出ることを確かめる。

## 確かめたこと

- `npm run lint`、`npm run typecheck`、`npx vitest run --no-file-parallelism`、`npm run build` が成功した。
- 全テストは 4,560 件成功、14 件スキップだった。
  実行環境の Git が対応していないオプションを使うテストもスキップされた。
- lint はサイズ上限を超える既存の `daemon.test.ts` を警告して除外した。

| 指摘 | 対応 |

| 作業先の中身と URL 形式の指定を確認していない | 一覧と詳細で日英の選択後の作業先と URL 形式の指定を確かめた。 |
