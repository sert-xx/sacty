## 目的

複数のリポジトリを指定したタスクの一覧と詳細が、作業先の選択前後に指定を表示することを日英で確かめる。

## したこと

- 一覧と詳細のテストを派生ダイアログのテストから、それぞれの表示用テストに移した。
- 作成と作業先の選択のイベントからタスクを投影し、一覧は `loadTaskList` を通して描画する。
- リポジトリ無しの印に一覧でも `data-testid` を付け、指定のあるタスクで印が出ないことと、指定のないタスクで印が出ることを確かめる。

## 確かめたこと

- 前回の実装時に `npm run lint`、`npm run typecheck`、`npx vitest run`、`npm run build` が成功した。
- 全テストは 4,552 件成功、14 件スキップだった。実行環境の Git が対応していないオプションを使うテストもスキップされた。
