# 差分と無関係な不安定な失敗で、実装に戻さない

- 日付: 2026-11-06（UTC）
- タスク: PBI-310
- PR: #316
- ブランチ: feat/issue-310-flaky-classification
- 関係する ADR: [差分と無関係で実行し直すと結果が変わる失敗を、実装に戻さない](../adr/20261106-1130-accept-flaky-failures-unrelated-to-diff.md)

## 目的

不安定なテストの失敗には、環境による失敗の条件が当てはまらず、実装に戻すしかなかった。差分と無関係と確かめられたものは、人の確認に回して先へ進める。

## したこと

- `tests.flakyFailures`・`rejectedFlakyFailures` を足し、最終レビューの指示に実行し直しの手順を書いた。
- `checkFlakyFailures` で申告を機械的に確かめる。差分のファイルは申告があるときだけ読む。
- 認めた失敗を PR の本文・人が確かめること・画面の説明に出す。認めなかった理由はやり直しの指示に渡す。
- 既定のスキル（`verification-run`・`X-2`）を同じ考えにした。
- 仕様書・ユーザードキュメント（日英）、ADR。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通った。
- `npx vitest run --no-file-parallelism`：208 ファイル、4207 件が通った（3 件は既存のスキップ）。
- 修正を戻して確かめた：差分のファイルの確認を外すと「テストのファイルが差分に含まれたら認めない」が失敗する。
