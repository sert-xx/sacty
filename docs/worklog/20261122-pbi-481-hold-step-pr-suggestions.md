# 要求要件・設計の PR の提案だけの往復を止める

- 日付: 2026-11-22（UTC）
- タスク: PBI-481
- PR: なし
- ブランチ: main
- 関係する ADR: [要求要件・設計の PR の提案だけの往復を止める](../adr/20261122-1154-hold-step-pr-suggestions.md)

## 目的

提案だけの直しと再レビューが続くときに、人の承認を待つ。

## したこと

連続する提案だけの判定を記録し、承認待ちの画面と作業履歴に知らせる。
人が足した先頭は同じ子タスクで再レビューする。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 通過 |
| `npm run typecheck` | 通過 |
| `npm run build` | 通過 |
| `npm test -- --maxWorkers=2` | 344 ファイル、7,076 件が通過、14 件をスキップ |

初回と連続する提案、人の指摘・コミット、要修正、届かなかった回、再起動、日英の画面と履歴をテストした。
画面テストには Playwright 1.61.1 の Chromium Headless Shell 149.0.7827.55 と FFmpeg を検証用ツール置き場に導入した。
スキップは、Git が必要な `merge-tree` オプションに対応していないテスト 13 件と、明示的に有効化した場合に実行する AI 評価 1 件。
承認画面とタスク概要の知らせが、日英ともに 375 px と 1280 px の画面幅に収まることをブラウザで確かめた。

## レビューの指摘と対応

### 要求要件と設計の PR

作業履歴の知らせに残った提案と直させる方法を含め、人のコミット後の再レビューを実装した。

### この PR のレビュー

再レビューの繰り返しが終わる条件を、ユーザー文書の日英で明確にした。

## 残したこと

なし。
