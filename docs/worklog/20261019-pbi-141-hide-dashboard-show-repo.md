# サイドバーのダッシュボードを隠し、タスク一覧にリポジトリ名を出す

- 日付: 2026-10-19（UTC）
- タスク: PBI-141
- PR: #153
- ブランチ: feat/issue-141-hide-dashboard-show-repo
- 関係する ADR: なし

## 目的

サイドバーの「ダッシュボード」は使っていないので出さない。タスク一覧では、題だけだとどのリポジトリの作業かがわからないので、
リポジトリの名前（`org/repo` の `repo` だけ）を出す（ステークホルダーの要望）。

## したこと

- 画面：サイドバーから「ダッシュボード」を外した（プロジェクトの画面・すべてのプロジェクトの画面とも）。ダッシュボードの画面は残し、
  ロゴとプロジェクトの切り替えの「すべてのプロジェクト」から開ける。使わなくなったサイドバーの名称の文言を消した。
- 画面：タスク一覧の各行の題の下に、作業するリポジトリの名前を出す（`repoNameOf`）。リポジトリは、選んだ・決めたリポジトリ、
  無ければ Issue・PR の取り込み元、無ければ準備したリポジトリ。まだ決まっていなければ出さない。開始地点の下の取り込み元は、
  リポジトリの URL を省いて番号（`#7`）だけにした。子タスクのリポジトリの URL の行は、題の下のリポジトリ名に置き換えた。
- docs：仕様書（構成）と利用者向けの説明（タスク）。

## 確かめたこと

- `npx biome check`・`npm run typecheck`・`npx vitest run`・`npm run build` が通った。
- サイドバーにダッシュボードが無いこと（どちらの画面でも）、ダッシュボードの画面ではどれも強調しないこと、リポジトリ名の決め方（repo だけ・
  優先の順・決まっていなければ出さない）、一覧の行での出し方（取り込み元は番号だけ）をテストにした。
- 次の修正を戻すと、テストが落ちることを確かめた：サイドバーにダッシュボードを戻す、org/repo を出す、取り込み元を優先する、
  準備したリポジトリを見ない、取り込み元を URL ごと出す、リポジトリ名を出さない。
- デモの環境で、表示を動画で確かめた。
