# 版を 1.4.0 に上げ、GitHub Release を作る

- 日付: 2026-10-20（UTC）
- タスク: なし
- PR: #175
- ブランチ: claude/loving-curie-6szn42
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.3.0 の後に、オーケストレーターへの質問で実行中の工程のログも読ませる機能（PR #171）、利用制限のときに代わりのエージェントへ自動で
切り替える機能（PR #172）、中止したタスクを詳細の「再実行」からやり直せるようにする機能（PR #173）と、オンプレの GitHub Enterprise Server
のアカウントがプロジェクトの設定に出ない問題の修正（PR #174）が入った。機能の追加があるので MINOR を上げ、1.4.0 をリリースする。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.4.0` にし、`package-lock.json` の版の行も同じにした。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.4.0` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント
  （`config`・`images`）の日英と、イメージの名前を書いているテスト・コメントを同じ版にした。ゲートウェイの MCP クライアントの版の文字列も
  `1.4.0` にした。
- 更新の知らせのテスト（`update-check.test.ts`・`update-notice-live.test.ts`）の `1.3.0` は、版の比較のための値なので変えない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`・`npm run build`：通過（`apps/daemon/dist/config.js` の `DEFAULT_IMAGE` が `sacty-agent:1.4.0`）。
- `npx vitest run`：123 ファイル・2396 件が通過。`agent-sessions.test.ts`・`context-mcp.test.ts`・`host-mcp-processes.test.ts` の 8 件は
  失敗したが、版を上げる前の main でも同じ 8 件が同じように失敗する（この環境は root で動くコンテナ。この変更とは無関係）。
- イメージの作り直しは、リリースの後に運用の環境で確かめる。
