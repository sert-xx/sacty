# UI の製品名を Sacty に統一する

- 日付: 2026-10-19（UTC）
- タスク: なし
- PR: なし
- ブランチ: feat/ui-sacty-capitalization
- 関係する ADR: なし

## 目的

画面で表示する製品名の先頭を大文字にし、日本語・英語ともに Sacty にそろえる。

## したこと

- ヘッダー、ブラウザーのタイトル、認証の入り口、アイコンのタイトル、日英辞書の製品名を変更した。
- 画面にも出す core の共有エラーメッセージを変更した。この共有文言は CLI や通知にも反映される。
- コマンド、設定キー、イベントの値、Cookie、ラベル・パスなどの識別子は維持した。
- 既存の文言テストの期待値と、仕様・利用者向け文書の画面名を合わせた。

## 確かめたこと

- `npm run typecheck` は成功した。
- `npm run lint` は既存の入れ子の作業ツリーの Biome 設定を検出して終了したため、`npx biome check apps packages tests` でソースを指定して確認し、成功した。
- `npm test -- --reporter=dot` で2,308件を実行した。共有文言の変更に伴う期待値を更新し、失敗したテストと関連テストを再実行してすべて確認した。
- 日英の利用者文書で、設定画面の名前が実際の表示と一致することを読み比べた。

## レビューの指摘と対応

- 利用開始ガイドに引用した更新通知の日英の製品名が旧表記だったため、画面の Sacty 表記に合わせた。

## 残したこと

なし。
