# TypeScript を 6.0.3 から 7.0.2 に上げる

- 日付: 2026-10-28（UTC）
- タスク: なし
- PR: #246
- ブランチ: ccr-edc66277-0gkkqv
- 関係する ADR: なし

## 目的

TypeScript 7.0（Go で書き直した版）に上げられるかを試し、上げられるなら上げる。

## したこと

- ルートの `package.json` と `apps/web/package.json` の `typescript` を `^6.0.3` から `^7.0.2` にし、Node v26.12.1 の `npm install` で `package-lock.json` を作り直した。
- tsconfig・コードは変えていない。

## 確かめたこと

Node v26.12.1 で：

- `npx tsc -b --force packages/core apps/daemon packages/cli` と `apps/web` の `tsc --noEmit`（`tsconfig.tsbuildinfo` を消してから）：エラーなし。
- `npm run build`：通った。7.0 には従来の JS API（`ts.createProgram` など）が無いが、Next.js 16.4.2 の型検査は動いている。`apps/web/src/app/page.tsx` に型エラーを一時的に足すと、`error TS2322` で `next build` が止まることを確かめた（確かめた後に元に戻した）。
- リポジトリのコード・スクリプトに、`typescript` の API を直接使う所は無い（`grep` で確かめた）。
- `npm run lint`：指摘なし。
- `npm test`：2925 件が通り、8 件が落ちた。落ちた 8 件は、6.0.3 のときと同じく、この作業用の環境（root で動く・Playwright のブラウザの版が合わない）によるもの（[Node.js を 26.x に上げたときの作業履歴](20261028-pr-245-node-26-lts.md)）。
- 6.0.3 と 7.0.2 で `tsc -b --force` の出力を比べた：`.js` は同じ。違いは `.d.ts` の中の並び順とソースマップだけ。
- かかった時間（`--force` で作り直し）：core・daemon・cli は約 13 秒から約 4.7 秒、`apps/web` の `tsc --noEmit` は約 13.4 秒から約 3.4 秒。

## 残したこと

- `apps/web/tsconfig.json` の `next` プラグイン（エディタ用）が、7.0 の言語サービスで効くかは確かめていない（ビルドと型検査には関係しない）。
