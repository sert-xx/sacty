# オーケストレーターへの質問を、画面右の AI のアイコンから開くサイドパネルのチャットにする

- 日付: 2026-10-13（UTC）
- タスク: PBI-61
- PR: #68
- ブランチ: feat/issue-61-chat-panel
- 関係する ADR: [オーケストレーターへの質問は、画面右下の AI のアイコンから開く、モーダルにしないサイドパネルのチャットにする](../adr/20261013-1337-chat-side-panel.md)

## 目的

「オーケストレーターに質問」（PBI-54）を、タスク詳細の本文の中の欄から、画面右の AI のアイコンで開くサイドパネルのチャットにする。
あわせて、タスク詳細の「中止…」のボタンの「…」を外す。受け入れ条件の要点は次のとおり。

- 右側の AI のアイコンをクリックするとサイドパネルのチャットが開き、閉じるボタンと Esc で閉じる。
- パネルで質問・答えの一覧・送信・質問できない理由が使え、答え待ちはパネルを閉じていてもアイコンで分かる。
- 本文の中の欄が無くなり、「中止…」が「中止」になる。狭い画面でも使える。

## したこと

- `apps/web/src/components/chat-panel.tsx`：右下に固定のアイコンと、Base UI の Dialog をモーダルにしない形で使うサイドパネル。広い画面では
  ヘッダーの下の右側に 440px、狭い画面では全幅。フォーカスの移動、最新までの送り、答え待ちの印とボタンの名前。
- `apps/web/src/components/task-chat.tsx`・`apps/web/src/components/question-form.tsx`：中身はいままでのものを使い、入力をパネルの下に固定。
  閉じても書きかけが残る。入力欄と入力の領域に高さの上限と中のスクロール。
- `apps/web/src/app/tasks/[id]/page.tsx`：本文の中の欄を削除。
- `apps/web/src/i18n/messages/parts.ts`・`apps/web/src/i18n/messages/task.ts`：「中止…」→「中止」（英語は「Cancel…」→「Cancel」）ほか。
  `apps/web/src/i18n/task-detail-wording.test.ts` を足した。

## 確かめたこと

- `npm run lint`・`npm run typecheck`・`npx vitest run`（639 件）・`npm run build` が通った。
- ブラウザ（デスクトップの幅と 375px）で、開閉・Esc・フォーカスの戻り・外を押しても閉じない・質問 0 件／12 件／長い答え（はみ出し無し）・
  開いたままの自動の更新・閉じたときの答え待ちの印を確かめた。
- レビューの対応の後：約 2,000 文字・100 行近いログを貼り付けたときに「質問する」のボタンが画面の中に収まることを、1280×900・1280×600・
  1280×480・375×667・375×560 で測って確かめた（最初の修正では 1280×600 で下端から少しはみ出したので、上限を画面の高さに合わせて直した）。
- レビューは静的なもので、ブラウザでの実測は未実施と書かれている。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 固定の高さのパネルに移したのに、入力欄（内容に合わせて伸びる）と入力の領域に高さの上限もスクロールも無いので、長い質問で送信のボタンがパネルの下端からはみ出す | 入力欄に高さの上限（12rem と画面の高さの 25% の小さいほう）と中のスクロールを付け、入力の領域にもパネルの 6 割までの上限と中のスクロールを付けた |

## 残したこと

- パネルの開閉・フォーカスの部品のテストは無い（テストの環境が DOM を使わないため。ブラウザでの確認で代えた）。
- 375px でパネルの端までスクロールすると、後ろの本文もスクロールすることがある（操作に支障は無い）。
