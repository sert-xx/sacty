## 目的

作業の履歴と申し出の一覧で、再開日時と設計・テスト観点の差分を読みやすくする。

## したこと

履歴の日時を地域の時刻で表示し、両画面で記録済みの差分を解析して表示する部品を追加した。
解析できない行も表示する。

## レビューの指摘と対応

### 設計のレビュー

履歴の画面を描画し、申し出の一覧と日時を比べるテストを追加した。

### 実装のレビュー

明暗両テーマで読める色に直し、履歴と申し出の両方で色のコントラストを確かめるブラウザテストを足した。
複数の観点の削除群と追加群を入力し、同じ ID のカードが隣に並ぶことを確かめる。

## 残したこと

マージ前に実際の Sacty の画面を日英で確認し、動画を PR に残す。
