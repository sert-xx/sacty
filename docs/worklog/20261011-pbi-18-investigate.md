# 「調査」の工程を足し、Issue から取り込んだ調査の結果を Issue に返す

- 日付: 2026-10-11（UTC）
- タスク: PBI-18
- PR: #24
- ブランチ: feat/issue-18-investigate
- 関係する ADR: [「調査」の工程を足し、結果は人間が承認して完了にし、Issue から取り込んだタスクは結果を Issue にコメントで返す](../adr/20261011-0204-superseded-investigate-step.md)

## 目的

コードを調べて報告するだけの「調査」の工程を足す。オーケストレーターはタスクが調査を求めているとき調査だけを選べる。調査のエージェントは起点のコードを読み取り専用で読み、結果を Markdown で書く。人間が承認して完了にし、差し戻しもできる。Issue から取り込んだタスクは、完了したら結果を Issue にコメントで返し、返せなければ理由を記録する。結果は画面で読める。

## したこと

- 工程と候補：工程の種類に `investigate` を足し、`STEP_PLANS` に `investigate: ["investigate"]` を足した。オーケストレーターへの指示に、変更ではなく情報を求めているときに選ぶよう書いた（`apps/daemon/src/prompts.ts`）。
- 調査のエージェント：起点のコードを読み取り専用で渡し、結論・根拠・影響範囲・確認したいことを書かせ、推測と事実を区別させる。
- 承認ゲート：調査を `GATED_STEPS`・`REWORK_STEPS` に入れた。差し戻しの指摘は累積し、前回の結果とともに渡す。
- Issue へのコメント（`apps/daemon/src/service.ts`・`apps/daemon/src/github.ts`）：完了の次の実行で、人間が承認した結果をコメントする（`IssueCommented`、URL つき）。長すぎる結果は省略する。返せなければ `IssueCommentFailed`（トークンは取り除く）を記録し、何度も返そうとしない。
- 画面：タスク詳細に「調査」の成果物を出し、承認済みなら折りたたむ。要求要件の成果物は、その工程があるタスクだけに出す。
- レビューの対応：コメントにタスクごとの目印 `<!-- sacty-investigation:{タスクID} -->` を入れ、投稿の前に Issue のコメントを全ページ読んで目印を探す（`findIssueComment`）。あれば投稿せずにその URL を記録する。ほかのタスクの目印は使わない。照合に失敗したら投稿せず `IssueCommentFailed` を記録する。

## 確かめたこと

- `npm test`：256件が通った（5件追加、オーケストレーターの出力のテストを更新）。起点のコードを読み取り専用で読んで調査し、差し戻しで指摘と前回の結果を渡して調べ直し、承認で完了すること、Issue からのタスクはプロジェクトのアカウントで一度だけコメントすること、返せないとき理由（トークンなし）を記録して何度も返そうとしないこと、コメントの API、作業履歴・表示を確かめた。Issue に返すのをやめるとテストが失敗することを確かめた。
- 画面で確かめた（スタブの AI の環境で、オーケストレーターが「調査だけ」を選ぶよう一時的に設定）：工程が「調査」だけになり選んだ理由が出た。結果が Markdown（表を含む）で表示され、承認すると完了した。
- レビューの対応の後、`IssueCommented` の記録だけを1回失敗させても次の実行で投稿が増えず、最初の投稿の URL が記録される回帰テストを足し、修正を戻すと失敗することを確かめた。
- 再レビューで、`npm test`（258件）・`npm run lint`・`npm run typecheck` が通った。
- 実際の AI での調査と、実際の Issue へのコメントは確かめていない。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| GitHub への投稿が成功した後、`IssueCommented` を記録する前に止まる・記録に失敗すると、次の実行で同じ結果を再投稿する | コメントにタスクごとの目印を入れ、投稿の前に既存のコメントを目印で探して、あればその URL を記録するようにした。照合に失敗したら投稿しない。回帰テストと `findIssueComment` のテスト（ページをたどる・見つからない・失敗）を足した |

## 残したこと

- 実際の AI での調査と、実際の Issue へのコメントは確かめていない。
