# 再レビューの要修正を絞る

- 日付: 2026-11-23（UTC）
- タスク: PBI-500
- PR: なし
- ブランチ: main
- 関係する ADR: [再レビューの要修正を絞る](../adr/20261123-2239-rereview-findings.md)

## 目的

実際の利用に影響する不具合と直しによる後退を優先し、再レビューでの修正の往復を減らす。

## したこと

既定のレビューのスキル、レビューの指示、日英の仕様を揃えた。
背景の集計は PR #570〜#609 のレビュー 143 回中 96 回が要修正で、要修正が続いた 12 件の回の移り変わりは、もぐら叩き約 24、厳しい理論上の入力・環境約 16、直しが生んだ不具合約 11、変わっていない箇所の新しい指摘約 9 だった。
3回目以降の要修正約 48 件は、実際の利用で起こりうるもの・不適合が約 35%、理論上の入力・競合や範囲を広げる求めが約 65% だった。
この数は依頼の背景から引用し、数え直していない。

## 確かめたこと

`npx vitest run apps/daemon/src/prompts.test.ts apps/daemon/src/default-skills.test.ts tests/docs` で、レビュー指示とスキル、文書を検査した。
スキルと指示の規則を写しから1文ずつ除き、22箇所すべてで対応するテストが失敗することを確かめた。

## レビューの指摘と対応

### 要求要件の PR

旧 ADR の一部を置き換えるときも置き換え関係を記録する指摘を受け、2件の旧 ADR と新しい ADR の関係を記録した。

### この PR のレビュー

後退の例外、承認の仕様、コード参照とテストの条件を修正した。
PR の共通指示から後退の例外を再レビュー専用の指示へ移し、前回のレビューの有無と回数の組み合わせを検査した。
自己レビューの共通指示から再レビューの規則の本文を除き、回数から各回の指示を生成するスクリプトを加えた。初回は出力せず、2回目以降は再レビューの規則を出力する。直しの最初のレビューを再レビューとして扱う場合は、回数を 1 としたまま指定を加えて規則を出力する。
