## 目的

実際の利用に影響する不具合と直しによる後退を優先し、再レビューでの修正の往復を減らす。

## したこと

既定のレビューのスキル、レビューの指示、日英の仕様を揃えた。
背景の集計は PR #570〜#609 のレビュー 143 回中 96 回が要修正で、要修正が続いた 12 件の回の移り変わりは、もぐら叩き約 24、厳しい理論上の入力・環境約 16、直しが生んだ不具合約 11、変わっていない箇所の新しい指摘約 9 だった。
3回目以降の要修正約 48 件は、実際の利用で起こりうるもの・不適合が約 35%、理論上の入力・競合や範囲を広げる求めが約 65% だった。
この数は依頼の背景から引用し、数え直していない。

## 確かめたこと

`npm run lint`・`npm run typecheck`・`npm run build` は通過した。
`npm test` は 7,300 件が通過し、14 件がスキップされた（Git の `merge-tree --merge-base` 非対応が 13 件、AI 評価が 1 件）。
`npx vitest run apps/daemon/src/prompts.test.ts apps/daemon/src/default-skills.test.ts tests/docs` は 506 件通過した。
規則の文を一つずつ除く検査では、スキルの各3ファイルの要修正と提案の境界・範囲を絞る例外、条件の数え方、および PR・自己レビューの指示の各文をそれぞれ除くと、対応するテストが失敗した（16回）。
