# docs の図を定義から作る SVG に置き換え、ユーザードキュメントにスクリーンショットを入れる

- 関係する ADR: [仕様書とユーザードキュメントの図を、定義から作る SVG にし、ユーザードキュメントに画面のスクリーンショットを入れる](../adr/20261022-1732-docs-svg-diagrams-and-screenshots.md)

## 目的

PR #202 で入れた Mermaid の図を、色・アイコン・配置を整えたリッチな図にする。
ユーザードキュメントの画面に関する所に、スクリーンショットを入れる。

## したこと

- 図の生成器（`scripts/docs-diagrams/`）
  - `lib.mjs`：カード・枠・矢印・シーケンス・ブランチの線などの定義から、日英の SVG を作る。
    色は種類ごとの少しの色で、SVG の中の `prefers-color-scheme` でライトとダークを切り替える。
    アイコンは線で自分で描いたものだけ。
    文言の幅を見積もり、はみ出しそうなら警告する。
  - `diagrams/`：図の定義（22 種類。仕様書とユーザードキュメントで同じ PR のブランチの図は 1 つの定義から両方に出す）。
  - `build.mjs`：`npm run docs:diagrams` で作り直す。`--check` で一致だけを確かめる。
- docs の Mermaid の図 23 枚を、生成した SVG の画像に置き換えた（日英）。
- スクリーンショット（`scripts/docs-screenshots/`）
  - `seed.mjs`：架空のプロジェクト 2 つとタスク 7 つ（承認待ち・一時停止・監視中・完了など）を、作業履歴に直接入れる。
    入れた後に、デーモンと同じ投影で読めることを確かめる。
  - `capture.mjs`：一時の `SACTY_HOME` で `sacty up` を起動し、Playwright で日英の画面を撮る。
    Docker・gh・キーチェーン（`security`）は、決まった答えを返す代わりのスクリプトにした。
  - `shots.mjs`：撮る画面の一覧（ダッシュボード・タスクの一覧・タスクの作成・PR の承認待ち・一時停止・プロジェクトの設定・コンテキストのプレビュー・監査）。
  - ユーザードキュメントの該当する節に、日英で入れた。
- テスト：`tests/docs/diagrams.test.ts` を足し、SVG が定義と一致すること・図の名前が重ならないこと・日英の画像がそろうこと・使われていない画像が無いことを確かめる。
  `tests/docs/docs.test.ts` の日英の突き合わせで、`x.svg`・`x.png` を `x.en.svg`・`x.en.png` と対応づけた。
- 方針：`docs/README.md` の図の規則を書き直し、スキルを直し、Mermaid の ADR を置き換えた。

## 確かめたこと

- `npx vitest run tests/docs`：3 ファイル・93 件がすべて通った。
- `npx biome check scripts tests/docs package.json`：誤りなし。
- `node scripts/docs-diagrams/build.mjs --check`：すべて定義と一致（幅の警告は、英語の題 2 つがカードの幅ぎりぎりのもので、描画して収まることを確かめた）。
- 図は日英・ライトとダークで Chromium で描画し、目で確かめた。重なっていた文言・矢印は配置を直した。
- スクリーンショットは `npm run build` の後に `node scripts/docs-screenshots/capture.mjs ja en` で撮り、16 枚を目で確かめた。
- GitHub の上での表示（SVG の中のダークの切り替えを含む）は確かめていない。

## 残したこと

- 監査の画面のスクリーンショットは、監査のモックのデータで撮っている（「モック」の印が写る）。
  実際の監査の記録を架空のデータに入れれば、印の無い画面にできる。
- スクリーンショットが古くなったことは、テストでは見つけない。
