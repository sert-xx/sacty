# 版を 1.27.0 に上げる

- 日付: 2026-11-18（UTC）
- タスク: なし
- PR: #429
- ブランチ: feat/release-1-27-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.26.0 の後に入った変更（PR #377・#383〜#428 の 47 件）をリリースする。複数のリポジトリを指定したタスク、PR のリスク評価、後続に回す指摘の人の決定、レビューの指摘の重みの決め方、軽い依頼の自己レビュー、ビルドキャッシュの片付けなど、機能の追加なので MINOR を上げる。

## 1.26.0 からの主な変更

- タスクの作成で複数のリポジトリを指定でき、候補をそのリポジトリに絞る（PR #377・#386〜#391）。
- PR のリスク評価を出し、PR の説明とレビューのコメントに載せる。段階は合図の重さと依存の版の更新の上げ幅で決める（PR #393・#408・#409・#421）。
- 実装が指摘を「後続に回したい」と申告でき、人が承認の画面で決め、扱い（後続のタスク・Issue・何もしない）を選ぶ（PR #406・#411・#419・#422）。
- レビューの指摘の重みを影響と起きやすさで決め、自己レビューは要修正だけを修正に戻す（PR #401）。再レビューの規則（PR #416・#426）、判定が無い回の伝え方（PR #413）、担当を起動しなかったレビューのやり直し（PR #420）、担当の結果の受け取り方（PR #399）。
- 依頼が軽いときに自己レビューの観点を絞る。子タスクに分けるタスクは通常の深さにする（PR #407・#423）。
- AI のレビューの指摘への対応を、指摘ごとに PR に返信する。すべて断ったときの扱い、レート制限の後のやり直し（PR #385・#400・#402）。
- 分割の子タスクの PR に範囲を明記する（PR #384）。統合レビューの人の確認（PR #396・#417）。
- 指摘なしの後の CI の失敗をタスクの詳細と一覧に出す（PR #404・#405・#410・#418）。
- PR の本文から作業領域へのリンクを外す（PR #403・#424・#427）。
- デーモンが、使っていないビルドキャッシュも片付ける（PR #425・#428）。
- Next.js を 16.4.5 に上げて既知の脆弱性を直し、hono を上げた（PR #394・#383）。
- そのほか：実装の出し直しの検証・調査の工程の写し（PR #395）、一時停止の案内（PR #397・#398）、テストの書き方とファイルの分け方（PR #392・#412・#414・#415）。

## 互換性の判断

- 設定ファイル：プロジェクトの設定に、省略できる `deferralHandling` を足した。形を変えた項目は無い。1.26.0 のプロジェクトの定義は知らない項目を読み飛ばすので、1.26.0 に戻しても読める（その設定は使われない）。
- 台帳：新しい種類のイベント（`PullRequestRiskAssessed`・`DeferralsDecided`・`DeferralHandled`・`PullRequestCiFailed`・`SelfReviewDepthChanged` など）と、既存のイベントの省略できる項目・列挙の値を足した。形を変えたものは無いので MAJOR にはしない。これらを記録した後に 1.26.0 に戻すと作業履歴を読めないので、リリースの説明の注意に書く。
- ビルドキャッシュの片付けが、期間を絞らずに使っていないビルドキャッシュを消す（sacty 以外のビルドのキャッシュも消える）ことを、リリースの説明の注意に書く。
- 既定のコンテキストのスキル（`review`）と工程の指示が変わることを、リリースの説明の注意に書く。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.27.0` にし、`package-lock.json` の版の行を直した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.27.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.26.0 の版上げ（PR #382）と同じ範囲（`daemon.test.ts` は PR #392 で分けた `daemon-api-settings.test.ts` に替わった）。置き換えは前後に数字・`.` が無い `1.26.0` だけにし、ADR・作業履歴は対象から外した。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` は、`Dockerfile` に固定したもの（`sha256:5df79989…`）と同じだったので変えていない。1.26.0 の後に `packages/cli/docker` の変更は無い。
