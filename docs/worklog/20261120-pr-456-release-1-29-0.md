# 版を 1.29.0 に上げる

- 日付: 2026-11-20（UTC）
- タスク: なし
- PR: #456
- ブランチ: feat/release-1-29-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.28.0 の後に入った変更（PR #434〜#453 の 17 件）をリリースする。`sacty mcp` のツールの追加（PR #434〜#446・#448・#451）、レビューのタスクの見守り（PR #452）、既定のレビューの観点 C-18（PR #449）など、機能の追加なので MINOR を上げる。

## 1.28.0 からの変更

- `sacty mcp` に、タスクの作成・成果物と実行の一覧・承認・差し戻し・待つ・一時停止と再開・中止・再実行・エラーレポート・続きの作成・題の変更のツールを足し、`get_task` に人に確かめたいことと人の判断待ちの理由を、`list_tasks` に人の対応を待っているタスクの絞り込みを足した（PR #434・#437・#439〜#446・#448・#451）。
- PR のレビューのタスクを、指摘なしになるまで完了にせず、PR の変化を見守って再レビューする（PR #452）。
- 既定のレビューに、既存の実装との調和を見る観点 C-18 を足した（PR #449）。
- 対応を求めていない PR のコメント（「承知しました」など）で、作り直さない（PR #447）。
- 最初の工程が始まる前の処理中を「実行待ち」と見せない（PR #450）。
- PR から取り込んだレビュー・コメントの本文が 2000 文字で切れるのを直した（PR #453）。

## 互換性の判断

- 設定ファイル：設定の形を決めるコードに差分は無い。
- 台帳：新しい種類のイベント `ReviewWatchEnded` と、既存のイベントの省略できる項目（`PullRequestReviewPosted` の `watch` など）・列挙の値（`ReviewRestarted` の `reason` の `pushed`・`replied`）を足した。形を変えたものは無いので MAJOR にはしない。これらを記録した後に 1.28.0 に戻すと作業履歴を読めないので、リリースの説明の注意に書く。
- レビューのタスクが指摘なしになるまで完了しないことと、既定のスキル `review` が変わることを、リリースの説明の注意に書く。
- `packages/cli/docker` の変更は無い。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.29.0` にし、`package-lock.json` の版の行を直した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.29.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.28.0 の版上げ（PR #433）と同じ範囲。置き換えは前後に数字・`.` が無い `1.28.0` だけにし、ADR・作業履歴は対象から外した。
  置き換えで `docs/spec/mcp-server`（日英）の「前の版のデーモン〔1.28.0 まで〕」も変わったが、これは過去の版を指す記述なので戻した。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` は、`Dockerfile` に固定したもの（`sha256:5df79989…`）と同じだったので変えていない。
