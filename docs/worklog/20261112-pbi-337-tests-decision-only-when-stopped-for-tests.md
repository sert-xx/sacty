# 再開の画面の「テストの扱い」を、テストが決まらずに止まったタスクだけに出す

- 日付: 2026-11-12（UTC）
- タスク: PBI-337
- PR: #357
- ブランチ: feat/issue-337-tests-decision-only-when-stopped-for-tests
- 関係する ADR: なし（既存の方針どおりの不具合の修正）

## 目的

テストのコマンドもテストなしの理由も無いタスクなら、止まった理由を見ずに、再開の画面に「テストの扱い」が出ていた
（予算・ほかのエラー・人の一時停止で止まったタスクでも）のを、テストが決まらないことを理由に止まったタスクだけにする。

## したこと

- core：`canDecideTests` は、テストが決まっていないタスク（`testsUndecided`）のうち、一時停止の理由が `error` で、止まった理由の
  コードがテストが決まらないこと（`orchestrator.noTests*`・`orchestrator.bugfixNeedsTests`・`orchestrator.testCommandUnknown`。
  `TESTS_UNDECIDED_STOP_CODES`。今の版では止まらないので、以前の版で止まったタスクだけ）のときだけ真にした。ツールが無くて
  止まったタスク・文書だけの判断と差分が食い違って止まったタスクは今までどおり。画面の「テストの扱い」と、デーモンの再開の入力
  `tests` の確かめは、この関数を使う。
- 台帳の読み込みでは、`TestsDecided`・`TaskResumed` の `rechooseSteps` を、以前の版と同じ広さ（止まった理由を見ない）で確かめる
  （`testsDecisionRecordable`）。以前の版が、ほかの理由で止まったタスクに記録した `TestsDecided` も読み込める。
- docs：仕様書（タスクと工程）・ユーザードキュメント（タスク）を日英で、今の動きに直した。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：エラーなし。
- `npx vitest run`：全体が通った。
- 新しいテスト：
  - 予算・ほかのエラー・人の一時停止で止まったタスクは、テストが決まっていなくても決められない。以前の版のその記録は読み込める。
    テストが決まらないことを理由に止まったタスクは決められる（投影）。修正を戻すと落ちることを確かめた。
  - 人が止めただけのタスクは、再開の `tests` を断る。以前の版でテストが決まらずに止まった記録があれば、テストなしと決めて再開でき、
    実装の指示と PR の本文に人が決めた理由が出る。テストのコマンドの指定・不具合の修正でテストなしにできないことも、以前の版で止まったタスクで確かめる（デーモン）。
