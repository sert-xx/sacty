# 版を 1.24.0 に上げる

- 日付: 2026-11-13（UTC）
- タスク: なし
- PR: #359
- ブランチ: feat/release-1-24-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.23.1 の後に入った変更（PR #346〜#358）をリリースする。PR のレビューを子タスクで回す変更（PR #347・#348・#350）、ゴールガーディアンの撤去（PR #351）、人が手を入れた PR の取り込み（PR #354）は機能の追加なので MINOR を上げる。

## 1.23.1 からの変更

- sacty が作る PR のレビューを、PR を作ったタスクの子タスクで回す（PR #347）。実装の PR はドラフトで作り、最終レビューと CI の待ちをやめる（PR #348）。PR の指摘の戻し先は子タスクが示す（PR #350）。
- ゴールガーディアンを撤去した（PR #351）。以前の版の最終レビューの仕組みのコードを消した（PR #355）。
- 人が sacty の PR に足したコミットを取り込み、人が直した PR の本文を3方向でマージする（PR #354）。
- エージェントのイメージのビルドで、層のキャッシュが外れにくくし、BuildKit の cache マウントを使う（PR #353）。
- operation の指示の書き込みの回数の上限をなくした（PR #352）、中止したタスクのメモリーの削除でデーモンが落ちるのを直した（PR #356）、再開の画面の「テストの扱い」の出し方を直した（PR #357）、`SECURITY.md` を直した（PR #346）。
- `@hono/node-server` を 2.1.8 に上げた（PR #358）。

## 互換性の判断

- 設定ファイル：`guardian_agent` は読み捨てて警告にしている（設定の読み込みは失敗しない）。`audit_agent` の既定が `default_agent` に変わった。形は変わっていないので MAJOR にはしない。リリースの説明の注意と更新の後にすることに書く。
- 台帳：以前の版の作業履歴は読める（途中だったタスクは起動のときに移す）。新しい種類のイベント（`ReviewTaskCreated`・`FinalReviewSkipped`・`PullRequestMarkedReady`・`PullRequestHeadMerged` など）を足したので、1.23.1 に戻すと 1.24.0 で記録した作業履歴を読めない。リリースの説明の注意に書く。
- レビューの進め方（ラベルを付けない・ドラフトで作る・sacty がテストを実行しない）が変わったことも、注意に書く。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.24.0` にし、`package-lock.json` の版の行を直した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.24.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.23.1 の版上げ（PR #345）と同じ範囲。置き換えは前後に数字・`.` が無い `1.23.1` だけにし、ADR・作業履歴は対象から外した。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` は、`Dockerfile` に固定したもの（`sha256:5df79989…`）と同じだったので変えていない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通過。
- `npx vitest run`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- 足した行がイメージの名前・パッケージの版・ゲートウェイの版の文字列だけであることを確かめた。
- PR #353 で `Dockerfile` が変わり、その PR では Debian を元にした既定のイメージを作っていなかったので、既定のイメージを `docker build` で作れることを確かめた（結果は PR の本文に書く）。

- 作ったイメージで、Node.js v26.13.1・Claude Code 2.1.318・Codex 0.167.0 が動き、ビルドのキャッシュの場所（`/var/cache/sacty-build`）と `APT_CONFIG` が残っていないことを確かめた。
- 同じイメージで `drawio --version` が `libgbm.so.1` が無いために失敗した。draw.io 32.4.1 のパッケージの `Depends` に `libgbm1` が無く、`--no-install-recommends` で入れているため。v1.23.1 の `Dockerfile` で作ったイメージでも同じだったので、PR #353 による後退ではない。リリースの説明の既知の問題に書き、直すのは別の PR にする。
- 全体の `npx vitest run` で、画面のテスト（`question-form.browser.test.ts`）の2件が負荷で時間切れになった。そのファイルだけを流し直すと通った。
