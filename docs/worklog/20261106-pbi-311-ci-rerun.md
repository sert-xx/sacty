# 実装の PR の CI の失敗ジョブを、できるときに1回だけ再実行する

- 日付: 2026-11-06（UTC）
- タスク: PBI-311
- PR: なし
- ブランチ: feat/issue-311-ci-rerun
- 関係する ADR: [実装の PR の CI の失敗ジョブを、できるときにコミットごとに1回だけ再実行する](../adr/20261106-1100-rerun-failed-pull-request-ci-once-when-possible.md)

## 目的

たまたま落ちた CI のジョブのせいで、変更と無関係な失敗のまま最終レビューに進むことを減らす。再実行できないときは、今までどおり進む。

## したこと

- `PullRequestCiRerunRequested` を足し、頼む前に記録する。`Task.pullRequestCiRerunCommits` でコミットごとに1回に限る。
- `CiStatusReader.rerunFailedJobs` を足し、`failedRuns` に試行の回数を持たせて、頼む前の試行の失敗を結果にしない（`rerunNotStarted`）。
- 待つ時間を再実行の時刻から数え直す。
- 頼めなければ `rerunSkipped` を付けて元の `failed` のまま進み、理由を伏せてから切り詰めてデーモンのログに出す。
- 最終レビューの指示に、元の失敗と、再実行で通ったときの確かめ方を足す。`checkFlakyFailures` は変えない。
- 作業履歴の文言、仕様書・ユーザードキュメント（日英）、図、ADR。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通った。
- `npx vitest run --no-file-parallelism`：208 ファイル、4239 件が通った（3 件は既存のスキップ）。
- 修正を戻して確かめた：古い試行の確認を外す・時間を PR の時刻から数える・コミットごとの記録を見ない・再実行の時刻の確認を外す・切り詰めてから伏せる・Actions の実行が無いときの確認を外す・頼んだ後に記録する、のそれぞれで、対応するテストが失敗した。
- 実際の GitHub への再実行は確かめていない（偽の CI と偽の fetch で確かめた）。
