# 版を 1.2.0 に上げ、GitHub Release を作る

- 日付: 2026-10-20（UTC）
- タスク: なし
- PR: なし
- ブランチ: chore/release-1.2.0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.1.0 の後に、起動時にエージェントのイメージを確かめて作るコマンドを知らせる機能（PR #166、PBI-148）と、エージェントへの指示を標準入力で渡して
大きな指示で `argument list too long` にしない修正（PR #167、PBI-149）が入った。機能の追加があるので MINOR を上げ、1.2.0 をリリースする。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.2.0` にし、`package-lock.json` を `npm install --package-lock-only` で更新した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.2.0` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント（`config`・`images`）の日英と、
  イメージの名前を書いているテスト・コメント（イメージの確かめの例を含む）を同じ版にした。ゲートウェイの MCP クライアントの版の文字列も `1.2.0` にした。

## 確かめたこと

- `npm run lint`・`npm run typecheck`・`npm run build`：通過（`apps/daemon/dist/config.js` の `DEFAULT_IMAGE` が `sacty-agent:1.2.0`）。
- `npx vitest run`：120 ファイル・2354 件が通過。
- イメージの作り直しと、更新した後の起動の案内・止まっていたタスクの再開は、リリースの後に運用の環境で確かめる。
