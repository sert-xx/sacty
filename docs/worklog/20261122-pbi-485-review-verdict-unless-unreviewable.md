# PR のレビューの判定なしをレビューできない場合に限る

- 日付: 2026-11-22（UTC）
- タスク: PBI-485
- PR: なし
- ブランチ: main
- 関係する ADR: [PR のレビューの判定を付ける条件](../adr/20261122-1340-review-verdict-unless-unreviewable.md)

## 目的

未確認の所があっても、読めた範囲に応じた判定を伝える。

## したこと

レビューの指示と既定のスキル、日英の仕様とユーザー文書をそろえた。
判定なしの回の取り込みと直しは変えていない。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm test` | 346 ファイル、7,090 件成功、14 件スキップ |
| `npm run build` | 成功 |

Git の機能、実行権限、明示的な有効化が必要な AI 評価の条件により、14 件をスキップした。
明示的に有効化する AI 評価は実行していない。

## レビューの指摘と対応

### 設計のレビュー

判定なしの回に停止の仕組みを設けない方針により、指摘を停止で失う懸念は当たらなくなった。
差分と主対象の文書を読めない場合の条件を入力確認から判定までそろえた。

### この PR の最初の提出

検証失敗の原因を確定できない場合の判定を明確にした。
日英の仕様の旧記述と追加文の配置を直した。

### 今回の直し

差分を読めないときはレビューの範囲を推定せず、判定を付けない方針に合わせた。
要求要件・設計の PR で主対象の文書を読めない場合も判定を付けない。
読めない入力の取得を再試行する担当を起動し、レビュー不能の結果を投稿できるようにした。
設計の条件表も人の追加方針に合わせた。

## 残したこと

なし。
