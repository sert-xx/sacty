# ゴールガーディアンの判断文を、作り直しの実行に渡す

- 日付: 2026-11-03（UTC）
- タスク: PBI-300
- PR: #299
- ブランチ: feat/issue-300-guardian-judgment-to-run
- 関係する ADR: [ゴールガーディアンの判断文を、その判断で始まった作り直しの実行に渡す](../adr/20261103-1530-pass-guardian-judgment-to-rework-run.md)

## 目的

実験（F45。S14 の4回目）で、ゴールガーディアンが人の指摘の取り込みで出した判断文（戻し先と、指摘の読み方）が作り直しの実行に渡らず、実行が自力で読み直して一部食い違った。戻し先を判断できなかった回では、実行が理由を知らずにコードを変えず、最終レビューの不合格でもう1回やり直した。
判断文を、その判断で始まった作り直しの実行（要求要件・設計・実装）に、ゴールガーディアンの解釈であることを示して渡す。判断できなかったときは理由を渡し、推測で大きく変えさせない。

## したこと

- 投影（`packages/core/src/projection.ts`）：PR の指摘の差し戻しを残す `prRework` に、差し戻しの回 `round` と指摘の ID `remarkIds` を足した。
- 指示（`apps/daemon/src/prompts.ts`）：`guardianJudgmentLines` を足し、`remarkLines` の指摘の節の後ろに置いた。工程の今回の指摘（最新の回で、まだ提出に渡していないもの）が、判断で差し戻した回と一致するときだけ渡す。判断文は秘密情報を伏せ、3,000文字で切り、1行の JSON のデータにする。判断できなかったときは、理由と、推測で大きく変えない・変更が要らないと結論する条件・読み取れなかった点を対応に書く指示を添える。理由が sacty の文言のとき（実行の失敗・出力を読めない）は渡さない。
- 仕様書（`docs/spec/approval.md` と英語の版）、ユーザードキュメント（`docs/user/tasks.md` と英語の版）、ADR を直した。

## 判断したこと

- 渡す対象は「その回の指摘で始まった実行」にした。提出済みの指摘だけが残る再実行（最終レビューの不合格など）には渡さない（受け入れ条件の「判断文が無い実行は今と変わらない」）。S14 の台本3 の2回目の実行（変更なしで終わった実行）は、最終レビューの不合格の前なので、この実行に判断文が届く。
- 原因（`cause`）は渡さない。受け入れ条件にあるのは戻し先と読み方の理由だけで、`guardian_missed` などが実行の直し方を偏らせうるため。

## 確かめたこと

作業は、リポジトリの外の worktree（`sacty-wt-pbi-300`）で行った。

- `apps/daemon/src/prompts.test.ts` に 8 件（判断が決まった／判断できなかった×3工程、順序、判断が無い実行、回の境界、sacty の文言、外の文字列の扱い、AI のレビューだけの回）、`apps/daemon/src/daemon.test.ts` に 3 件（要求要件に戻す、判断できない、実行の失敗）、`packages/core/src/projection.test.ts` に回の確認を足した。
- 修正を戻す確認：`prompts.ts` を戻すと prompts の追加 6 件が落ち、`projection.ts` を戻すと daemon の追加 2 件と projection の 1 件が落ちる。
- 境界：指摘が無い・提出済み・別の回・別の工程の判断・判断が無い・無効にした指摘だけ、のどれも指示を足さない（判断を外した指示と一致）。

## レビュー対応（Sacty のレビュー）

- 判断した後に、同じ回の指摘のうち1件だけを無効にすると、残りの指摘の回が一致して、無効にした指摘を解釈した判断文が渡っていた。`prRework` に判断した指摘の ID（`remarkIds`）を残し、今回の指摘（無効でないもの）が判断した集合と一致するときだけ渡すようにした。1件でも無効にしていれば渡さない。境界のテスト（複数件のうち1件を無効・全件を無効・同じ回で指摘が増えた）を足した。
- 切り詰めのテストで、判断文が上限（3,000文字）ちょうどに収まることを直接確かめるようにした。
- `round` の説明が「以前の作業履歴には無い」となっていたのを直した（作業履歴の差し戻しの記録から投影するので、読み直したときも設定される）。回を持たない判断を渡さないという記述（仕様書・作業履歴）と、そのテストの項目を除いた。
