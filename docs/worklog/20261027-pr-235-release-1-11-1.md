# 版を 1.11.1 に上げる

- 日付: 2026-10-27（UTC）
- タスク: なし
- PR: #235
- ブランチ: ccr-53784160-fdng3i
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.11.0 の後に、スキルを作るタスクが進まない問題の修正（PR #234）が入った。機能の追加と、設定ファイルの形・台帳・コマンドの引数の
互換性の無い変更は無いので PATCH を上げ、1.11.1 をリリースする。

## 1.11.0 からの変更

- スキル（SKILL.md）・AGENTS.md などエージェント向けの指示の文書を、テストを書かずに差分で確かめるようにした（PR #234）。
  - オーケストレーターは、その文書を足す・直すタスクを、ふつう `direct` か `skip-design` で進める。
  - 要求要件・設計は、エージェントの振る舞いではなく、文書に何が書かれているべきかで書く。
  - 実装とゴールガーディアンは、エージェントを起動して確かめることを求めない（テストの仕組みが無いリポジトリでも同じ）。
- 更新の後にすること：`npm ci` で依存を入れ直し、既定のイメージの名前が `sacty-agent:1.11.1` に変わったので、
  `npx sacty image build` で作り直す。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.11.1` にし、`package-lock.json` の版の行も同じにした（1.11.0 のときと同じく、版の行だけを直した）。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.11.1` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント
  （`config`・`images`）の日英と、イメージの名前を書いているテスト・コメントを同じ版にした。ゲートウェイの MCP クライアントの版の文字列も
  `1.11.1` にした。

## 確かめたこと

- `npm ci`・`npm run lint`・`npm run typecheck`・`npm run build`：通過。
- `npx vitest run`：下の環境による失敗のほかは通過。`agent-sessions.test.ts`・`context-mcp.test.ts`・`host-mcp-processes.test.ts` の 8 件と
  `question-form.browser.test.ts` は、1.11.0 のときと同じく、この作業の環境（クラウドのコンテナ）によるもので、版の文字列とは関係が無い。
- `git grep 1.11.0` で、ADR・作業履歴のほかに `1.11.0` が残っていないことを確かめた。
