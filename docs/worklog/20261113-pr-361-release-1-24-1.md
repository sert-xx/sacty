# 版を 1.24.1 に上げる

- 日付: 2026-11-13（UTC）
- タスク: なし

- ブランチ: feat/release-1-24-1
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.24.0 の後に入った変更（PR #360）をリリースする。修正だけなので PATCH を上げる。

## 1.24.0 からの変更

- 既定のイメージで draw.io の CLI が `libgbm.so.1` が無いために動かなかったのを直した（PR #360。1.24.0 のリリースの説明の既知の問題）。

## 互換性の判断

- 設定ファイルの形・コマンドの引数・台帳に変更は無い。1.24.0 に戻しても作業履歴は読める。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.24.1` にし、`package-lock.json` の版の行を直した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.24.1` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.24.0 の版上げ（PR #359）と同じ範囲。置き換えは前後に数字・`.` が無い `1.24.0` だけにし、ADR・作業履歴は対象から外した。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` は、`Dockerfile` に固定したもの（`sha256:5df79989…`）と同じだったので変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通過。
- `npx vitest run`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- 消した行と足した行を比べ、版の違いのほかに差分が無いことを確かめた。
- 既定のイメージを `docker build` で作り、`drawio --version` が動くことを確かめた（結果は PR の本文に書く）。
