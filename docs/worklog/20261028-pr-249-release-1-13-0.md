# 版を 1.13.0 に上げる

- 日付: 2026-10-28（UTC）
- タスク: なし
- PR: #249
- ブランチ: feat/release-1-13-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.12.1 の後に、機能の追加（PR #248）が入った。設定ファイルの形・台帳・コマンドの引数に互換性の無い変更は無い
（差し戻しの入力に任意の項目を足しただけ）ので MINOR を上げ、1.13.0 をリリースする。

## 1.12.1 からの変更

- 承認ゲートで差し戻すときに、やり直す工程から後ろの工程のイメージ・エージェントを一緒に変えられるようにした（PR #248）。
- 更新の後にすること：`npm ci` で依存を入れ直し、既定のイメージの名前が `sacty-agent:1.13.0` に変わったので、
  `npx sacty image build` で作り直す。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.13.0` にし、`package-lock.json` の版の行も同じにした（これまでと同じく、版の行だけを直した）。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.13.0` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント
  （`config`・`images`）の日英と、イメージの名前を書いているテスト・コメントを同じ版にした。ゲートウェイの MCP クライアントの版の文字列も
  `1.13.0` にした。

## 確かめたこと

- Node v26.12.1 で、`npm ci`・`npm run lint`・`npm run typecheck`・`npm run build`：通過（`npm ci` の後に `package-lock.json` の差分は版の行だけ）。
- `npx vitest run`（`tests/docs` を含む）：158 ファイルが通過、1 ファイルが失敗。失敗は `install-security-tools.test.ts` の 2 件（macOS の作業環境で
  道具を置けない）で、1.12.1 のときと同じく、版を上げる前の状態でも失敗する（このテストと、テストが試すスクリプトは 1.12.1 から変わっていない）。
- `git grep 1.12.1` で、ADR・作業履歴のほかに `1.12.1` が残っていないことを確かめた。
