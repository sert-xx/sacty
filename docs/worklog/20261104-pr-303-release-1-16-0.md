# 版を 1.16.0 に上げる

- 日付: 2026-11-04（UTC）
- タスク: なし
- PR: #303
- ブランチ: feat/release-1-16-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.15.1 の後に、機能の追加と修正が入った（PR #275〜#302）。設定ファイルの形・台帳・コマンドの引数を壊す変更は無く、機能の追加があるので MINOR を上げ、1.16.0 をリリースする。

## 1.15.1 からの変更

- 止まる・無駄に動く問題の修正：最終レビュー・監査の出力の JSON の崩れを直して読む、判定を読めないときの出し直し、空の最後の結果の扱い、
  作業領域に入れたツールでの写しの失敗、実装の PR のマージによる作り直しの停止、時間切れで止めた実行を続きから再開する、など。
- 工程の見直し：文書だけの依頼でコードの検証を省く、受け入れ条件が詳しい依頼で要求要件を省く、セルフレビューの再レビューで観点を絞る、など。
- AI のレビューの扱い：sacty 自身の AI のレビューの指摘を人の指摘と区別する、古い head へのレビューを捨てて人に届ける、
  レビューが止まったことを PR にコメントで知らせる、など。
- 設定・費用：プロジェクトの設定の同時保存を併合する、実行の費用を CLI の報告額にする、雛形の単価の例を実態に合わせる（PR #302）。
- 互換性：既存のイベントに足した項目はすべて任意で、1.15.1 の作業履歴はそのまま読める。新しい種類のイベントが記録された後で 1.15.1 に戻すと、作業履歴を読めない。
  起動のときに `project_revisions` の表が足される。
- 更新の後にすること：`npm ci` で依存を入れ直し、既定のイメージの名前が `sacty-agent:1.16.0` に変わったので、`npx sacty image build` で作り直す。

## したこと

- 5 つのパッケージ（`@sacty/core`・`@sacty/daemon`・`@sacty/web`・`@sacty/cli`・`apps/desktop`）とワークスペースの依存の版を `1.16.0` にし、
  `package-lock.json` の版の行も同じにした。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.16.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.15.1 の版上げ（PR #274）と同じ範囲。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest`（インデックス）が、`packages/cli/docker/Dockerfile` の
  `BASE_IMAGE`・`NODE_IMAGE` のダイジェストと同じだった（`sha256:bc0a2afd…`）ので、更新していない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は上げていない。

## 確かめたこと

- `npm ci`・`npm run lint`・`npm run typecheck`：通過（`npm ci` の後の `package-lock.json` の差分は版の行だけ）。
- `npx vitest run`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- `git grep -F 1.15.1` で、ADR・作業履歴のほかに `1.15.1` が残っていないことを確かめた。
