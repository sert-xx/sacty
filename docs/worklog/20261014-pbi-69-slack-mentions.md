# Slack の通知に、メンションする相手と通知の種類の設定を足す

- 日付: 2026-10-14（UTC）
- タスク: PBI-69
- PR: #76
- ブランチ: feat/issue-69-slack-mentions
- 関係する ADR: [Slack の通知先に、メンションする相手と通知の種類の設定（mention）を足し、既定は人の出番の通知だけにする](../adr/20261014-0032-slack-mentions.md)

## 目的

Slack の通知で、相手（複数）と通知の種類を設定してメンションできるようにする。形が違えば理由を出し、選んだ種類の通知の本文の先頭にだけ
メンションを付ける。Slack API・Webhook のどちらでも効き、設定しなければこれまでどおり。エクスポート・インポートで引き継ぎ、過去の設定もそのまま読める。

## したこと

- 設定：`packages/core/src/projects.ts` で、通知先に任意の `mention`（`targets`・`kinds`）を足し、相手の形を確かめる（空白の除去・重複の除去・理由つきの拒否）。
- 本文：`apps/daemon/src/notifier.ts` で、選んだ種類の通知とテストの通知の本文の先頭にメンションを付ける。
- エクスポート・インポートにメンションを含めた。
- 画面：`apps/web/src/components/project-editor.tsx` に「メンション（任意）」の欄、`apps/web/src/i18n/messages/projects.ts` に文言（ja・en）。
- `README.md`：メンションの説明。
- この PR は #74 の上に重ね、#74 のマージの後に向き先を main に変える前提で作った。

  エクスポートとインポート・英語・狭い画面を確かめた。
