# 画面の日本語・英語を切り替えられるようにする

- 日付: 2026-10-10（UTC）
- タスク: PBI-4
- PR: #11
- ブランチ: feat/issue-4b-i18n
- 関係する ADR: [画面の言語はブラウザの言語に従って日本語・英語を決め、ユーザーメニューで上書きでき、エージェントの成果物は訳さない](../adr/20261010-1048-superseded-ui-language-selection.md)

## 目的

PBI-4 の後半（PBI-4b、受け入れ条件5〜6）。前半の PBI-4a は #10 で行った。

- 日本語・英語はシステムの設定に従い、ユーザーメニューで上書きできる。エージェントの成果物は、画面の言語に引きずられない。
- 英語の用語は、構想ドキュメントの用語集に従う。

## したこと

- 言語の決め方：`apps/web/src/i18n/locale.ts`（`pickLocale`）。サーバーでは `apps/web/src/i18n/server.ts`（`getMessages()`）、
  クライアントでは `apps/web/src/i18n/client.tsx`（`useMessages()`）で辞書を引く。
- 辞書：`apps/web/src/i18n/messages/` に領域ごとに置いた。用語集は `apps/web/src/i18n/messages/labels.ts`。
- 状態・台帳の文言の関数（`apps/web/src/lib/labels.ts`）が、辞書を引数に取るようにした。入力の検査の文言（タイトルが空など）も画面の言語で出す。
- ユーザーメニュー（`apps/web/src/components/shell/menus.tsx`）に言語の選択を足し、cookie（`sacty-lang`）に保存する。成果物は書かれた言語のまま出ることもメニューに書いた。
- 各画面とコンポーネントの文言を辞書に移した。台帳のパスや英語のバッジが幅からはみ出していたので、折り返すようにした。
- レビューの対応で、デーモンにつながらないときのヘッダー（`apps/web/src/components/shell/header.tsx` の `HeaderFallback`）に、保存済みの言語の設定を渡すようにした。

## 確かめたこと

- `npm test`：146件が通った（5件追加）。言語の決め方（選んだ言語・ブラウザの言語の優先順・q 値）と、状態・台帳の英語が用語集どおりであることを確かめた。
  レビューの対応の後は147件が通った。
- 画面で次のことを確かめた。
  - システムの言語（日本語）で日本語になる。
  - ユーザーメニューで English を選ぶと、ヘッダー・一覧・タスクの詳細（台帳を含む）・成果物チェック・プロジェクトが英語になり、成果物は日本語のまま。
  - 「システムに従う」に戻すと日本語に戻る。
  - 幅375pxで、一覧・タスクの詳細・成果物チェック・プロジェクトに横スクロールが出ない。
- レビューでは `npm test`・`npm run lint`・`npm run typecheck` が通ったことを確かめた。ブラウザでの切り替えとスマホの幅の操作は、レビューでは確かめていない。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| デーモンにつながらないときもヘッダーの仮表示を使うので、English などを選んでいてもメニューは常に「システムに従う」を選んだ表示になる（P3） | 読み込み中の仮表示と、つながらないときの表示を分け、後者には保存済みの設定（`languagePreference()`）を渡すようにした。回帰テスト（`apps/web/src/components/shell/header.test.ts`）を足し、修正前は失敗することを確かめた |

## 残したこと

- デーモンが作る文言（409 の理由・一時停止の説明・取り込みのエラー・既定のプロジェクト名「デフォルト」・台帳に記録済みのエラー文）は日本語のまま。
  訳すにはデーモンが文言をコードと引数で返す形に変える必要があるため、別の PBI（PBI-11）にした。
