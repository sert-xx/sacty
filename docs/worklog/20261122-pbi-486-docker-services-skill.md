# 工程のサービスの案内をスキルで渡す

- 日付: 2026-11-22（UTC）
- タスク: PBI-486
- PR: なし
- ブランチ: main
- 関係する ADR: [工程のサービスの案内を実行ごとのスキルで渡す](../adr/20261122-1417-docker-services-skill.md)

## 目的

工程の担当に docker とサービスの使い方をリポジトリの手順より先に伝える。

## したこと

実行ごとのスキルを生成し、サービスの接続先を候補として案内する。
接続先はスキルと工程の指示に同じデータから書くと決めた。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm run build` | 成功 |
| `npx vitest run tests/docs --no-file-parallelism` | 99 件成功 |
| `npm test` | 346 ファイル、7,085 件成功、14 件スキップ |

変更途中の全件テストでは 5 件失敗した。
コンテキストの追加に伴う期待値を直し、関連するテスト 15 件の成功を確かめてから全件を再実行した。

## レビューの指摘と対応

到達性の保証とネットワーク構成ごとの接続先の確保は対象外とし、接続先を候補として案内する。
届かなければ別の候補を試し、それでも届かなければ報告する。

## 残したこと

PR のレビュー工程でのサービス起動と、サービスを選ぶ判断は対象外。
