# 共通ネットワークとボリュームの残りを回収する

- 日付: 2026-11-23（UTC）
- タスク: PBI-498
- PR: なし
- ブランチ: main
- 関係する ADR: [共通ネットワークと名前付きボリュームを所有者の印で回収する](../adr/20261123-1625-shared-network-volume-owner.md)

## 目的

異常終了後に残る共通ネットワークと名前付きボリュームを回収する。

## したこと

所有ラベルを付け、起動時に持ち主と資源の種類を確認して回収する。
仕様の日英を合わせた。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 通過 |
| `npm run typecheck` | 通過 |
| `npm run build` | 通過 |
| `npx vitest run tests/docs` | 99 件通過 |
| `npx vitest run apps/daemon/src/services.test.ts` | 59 件通過 |
| `npm test` | 348 ファイル、7269 件通過、14 件スキップ（追加テストの前） |

回収を無効にすると終了済み資源のテストが失敗することを確認した。
スキップのうち13件は環境の Git が `merge-tree --merge-base` に対応しないため、1件は実際の AI を使う任意の評価である。
実際の Docker での確認は依頼者がマージ前に行うため、この工程では実行していない。

## レビューの指摘と対応

### 設計のレビュー

プロセス表をプロジェクトの判定前と資源の一覧取得後に読む。
入力の資源に書かれた所有ラベルを除き、回収対象を作り方でも絞る。
別マシン、`hidepid`、新旧版の共存、匿名ボリュームとイメージ取得は依頼者の判断で対象外とした。

### この PR の最初の提出

まだ無い（最初の提出）。

## 残したこと

依頼者がマージ前に Docker のあるホストでデーモンを強制終了し、コンテナを削除して再起動した後、共通ネットワークと名前付きボリュームが消えたことを確認し、手順と出力を記録する。
