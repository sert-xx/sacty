# マージ済みの作業履歴を PR の書き換えから守る

- 日付: 2026-11-23（UTC）
- タスク: PBI-497
- PR: なし
- ブランチ: main
- 関係する ADR: [マージ済みの作業履歴の書き換えを PR の CI で検出する](../adr/20261123-1614-fail-prs-rewriting-merged-worklogs.md)

## 目的

ほかのタスクの記録を保護し、許可された追記と切れたリンクの修正を通す。

## したこと

PR のマージベースとの差分を検査するスクリプトとワークフローを追加し、規則と正本を揃えた。
有効な UTF-8 でない内容、NUL を含む内容、Git がバイナリと判定する変更を拒否し、生存を確認できないリンクの付け替えを許さない。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm run build` | 成功 |
| `npx vitest run tests/docs` | 99 件成功 |
| `npm test` | 成功 |

検査を無効化すると、書き換え・有効なリンクの付け替え・既存行の削除を確かめる3件が失敗した。

## レビューの指摘と対応

### 設計のレビュー

既存行の保護、リンクの生存確認、題の変更での再実行、リンク修正の順序を設計に反映した。

### この PR のレビュー（1回目）

バイナリ差分の書き換えと、文書内アンカーや外部リンクの付け替えを検出するようにした。
### この PR のレビュー（2回目）

変更前後のバイト列と Git のバイナリ判定を確認し、行差分を解釈できない変更を拒否するようにした。

### この PR のレビュー（3回目）

大きな履歴と差分を Git から読み取り、Unicode を含むリンクの修正を判定できるようにした。
不正なバイト同士の変更とリンク修正を組み合わせた場合も検査した。

### この PR のレビュー（4回目）

コード内のリンク風文字列を除外し、修正先の種類と Git のエラーを確認する。
不正な内容を含むファイルの削除も一律に違反とする。
同じタスクの識別条件を文書に明記し、復元コマンドのパスを引用する。

### この PR のレビュー（5回目）

文書全体のコード領域を判定し、複数行のインラインコード、引用内のフェンス、字下げコード内の変更を拒否する。
パーセントデコード後の NUL を含む行き先は不存在として扱う。

## 残したこと

実際の PR で違反の失敗、新しいファイルの成功、題の変更による再実行を人が確認する。
