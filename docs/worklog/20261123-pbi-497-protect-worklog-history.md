# マージ済みの作業履歴を PR の書き換えから守る

- 日付: 2026-11-23（UTC）
- タスク: PBI-497
- PR: なし
- ブランチ: main
- 関係する ADR: [マージ済みの作業履歴の書き換えを PR の CI で検出する](../adr/20261123-1614-fail-prs-rewriting-merged-worklogs.md)

## 目的

ほかのタスクの記録を保護し、許可された追記と切れたリンクの修正を通す。

## したこと

PR のマージベースとの差分を検査するスクリプトとワークフローを追加し、規則と正本を揃えた。
バイナリと判定される差分も行単位で検査し、生存を確認できないリンクの付け替えを許さない。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm run build` | 成功 |
| `npx vitest run tests/docs` | 成功 |
| `npm test` | 成功 |

違反を常に空にすると、書き換え・有効なリンクの付け替え・既存行の削除を確かめる3件が失敗した。

## レビューの指摘と対応

### 設計のレビュー

既存行の保護、リンクの生存確認、題の変更での再実行、リンク修正の順序を設計に反映した。

### この PR の最初の提出

バイナリ差分の書き換えと、文書内アンカーや外部リンクの付け替えを検出するようにした。

## 残したこと

実際の PR で違反の失敗、新しいファイルの成功、題の変更による再実行を人が確認する。
