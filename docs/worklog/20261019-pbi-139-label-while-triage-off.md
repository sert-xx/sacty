# レビュー用のラベルの自動トリアージを Off にしていても、sacty の PR にラベルを付ける

- 日付: 2026-10-19（UTC）
- タスク: PBI-139
- PR: #151
- ブランチ: feat/issue-139-label-while-triage-off
- 関係する ADR: なし

## 目的

sacty は、自分で作った PR（要求要件・設計の PR、実装の PR）にレビュー用のラベルを付けるが、そのトリアージを Off にしていると
付けなかった。ステークホルダーは一時的に Off にすることがあり、その間に作った PR は、On に戻しても取り込まれなかった（1つの PR に
付けるのは1回だけで、後から付け直さないため）。

## したこと

- デーモン：レビュー用のラベルを設定していれば、トリアージの On・Off によらず付ける（`labelForPullRequests`）。公開の直後と、
  付ける前に止まった PR の再開（PR の確認ごと）の両方に効く。Off の間に取り込まないことは今までどおり。
- 画面：sacty の設定のレビュー用のラベルの補足を、取り込みが Off の間も付けると直した。
- docs：仕様書（承認と PR）と利用者向けの説明（取り込み）。

## 確かめたこと

- `npx biome check`・`npm run typecheck`・`npx vitest run`・`npm run build` が通った。
- Off でも要求要件・設計の PR と実装の PR に付けること、Off の間は取り込まず On に戻したらレビューだけのタスクとして取り込むこと、
  付ける前に止まった PR を Off のまま再起動しても付けること、レビュー用のラベルを設定していなければ付けないことをテストにした。
- 付ける条件に Off を戻すと、公開の直後と再開の両方のテストが落ちることを確かめた。
