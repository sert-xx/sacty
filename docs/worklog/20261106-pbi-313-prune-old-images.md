# 古い版のエージェントのイメージが溜まらないようにする

- 日付: 2026-11-06（UTC）
- タスク: PBI-313
- PR: #319
- ブランチ: feat/issue-313-prune-old-images
- 関係する ADR: [`sacty image build` の後に、古い版のイメージと使っていないビルドキャッシュを片付ける](../adr/20261106-1440-prune-old-images-after-build.md)

## 目的

版を上げるたびに古いイメージが溜まり、Docker の仮想ディスクが満杯になって、エージェントが `ENOSPC` で止まった。`sacty image build` の後に片付くようにする。

## したこと

- `staleImages`：`repository:tag` の一覧から、消してよい古い版を決める。
- `pruneOldImages`：古い版を消し、使っていないビルドキャッシュを消す。失敗は結果で返す。
- `sacty image build`：すべて作れたら片付けて、消したもの・消せなかったものを出力する。
- 仕様書（`agent-execution`）とユーザードキュメント（`cli`・`troubleshooting`）の日英、ADR を足した。

## 確かめたこと

- `apps/daemon/src/image.test.ts`：版の数値の比較、版が 0・1・2 個、設定が指すものの保護、対象外の名前・タグ、消せないものがあるとき、一覧とキャッシュの失敗。
- 実際の CLI と Docker（`docker build` だけ差し替え、使い捨てのイメージ `sacty-agent-verify313`）：
  - ビルドに失敗すると何も消さない。
  - 成功すると `1.11.0`・`1.12.0` を残して古い版を消し、`keepme` のタグは残す。
  - コンテナが使っている版は消せなかったものとして出し、コンテナを消した次の回に消える。
  - 消すものが無ければ何も出さない。
  - 他のイメージの一覧は前後で変わらない。
- 実装を壊してテストが落ちることも確かめた：保護の無効化、名前の絞りを外す、版のタグの絞りを緩める、版の文字列での比較、残す数の変更、一覧の失敗の無視、キャッシュの期間の変更。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 名前の絞りを外してもテストが通る（他のプロジェクトのイメージの例が1版ずつで、消す対象にならなかった） | 3版ある例のテストを足した |
| 一覧の失敗を無視してもテストが通る（失敗の例の標準出力が空だった） | 標準出力のある失敗の例にした |

## 残したこと

- 自動で消すこと・残す数を2にすることは、PR で人に確かめる。
