# API が返す文言を、コードと引数にして画面の言語で表示する

- 日付: 2026-10-10（UTC）
- タスク: PBI-11
- PR: #15
- ブランチ: feat/issue-11-daemon-messages
- 関係する ADR: [デーモンの API が返す利用者向けの文言を、文言のコードと引数にし、辞書を core に置いて画面の言語で文にする](../adr/20261010-1306-api-messages-as-codes.md)

## 目的

PBI-11（デーモンが作る文言の多言語化）は範囲が広いため2つに分け、このタスク（PBI-11a）では仕組みと API が返す文言（409 の理由・400 の入力の検査・
プロジェクトの重複）を扱う。台帳などに記録する文言は PBI-11b（#16）で扱う。

- デーモンは利用者向けの文言を、コードと引数で返す。
- 画面は、コードと引数を画面の言語の文にして出す。
- エージェントが書いた文は訳さない。

## したこと

- 文言の辞書と描画：`packages/core/src/messages.ts`（コードごとの引数の形・日本語と英語の辞書・`renderMessage`）、`packages/core/src/message-code.ts`。
- 入力の検査（チケット・差し戻しの指摘・プロジェクトの定義・エクスポートのファイル）の文言を、コード（例 `input.invalidRepo`）にした（`packages/core/src/events.ts`・`packages/core/src/projects.ts`）。
- API：`apps/daemon/src/server.ts`・`apps/daemon/src/service.ts` で、409 と 400 をコードと引数で返す。
- 画面：`apps/web/src/lib/daemon.ts` で画面の言語の文にする。古いデーモンの日本語の `message` もそのまま出す。
- レビューの対応で、zod の標準の検査の誤りもコードと引数にし（core の `issueMessage`）、画面は場所を添えて出すようにした。引数をコードごとの形で確かめてから文にするようにした。

## 確かめたこと

- `npm test`：193件が通った（3件追加、6件を更新）。コードの文言（日本語・英語）、コードでない文・知らないコード・プロトタイプの名前・引数の欠けの扱い、
  日本語と英語でコードが揃っていること、API の 409・400 がコードを返すことを確かめた。返す形を元に戻すとテストが失敗することも確かめた。
  レビューの対応の後は194件が通った。
- 画面で、プロジェクトの設定にほかのプロジェクトの Org を登録したとき（409）と、リポジトリ名の形の誤り（400）を見た。
  英語では「The Org "acme" is already registered in the project "決済".」「Enter the repository as owner/name.」、日本語では「Org「acme」は、プロジェクト「決済」に登録されています。」と出た。
- レビューの対応の後、画面でベースブランチを空にして保存すると「入力してください。（repositories.0.baseBranch）」と出ることを確かめた。
- レビューでは `npm test`・`npm run lint`・`npm run typecheck`・`git diff --check` が通ったことを確かめた。ブラウザの操作は、レビューでは確かめていない。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| P2：コードを指定していない zod の標準の検査（`.min`・`.max`・型・`.strict()`）の誤りが、日本語の画面でも英語のまま出る（空のベースブランチ・201文字の ref・知らない項目を含むエクスポート） | 400 で、すべての誤りをコードと引数（`{ path, message: { code, params } }`）にして返すようにした。標準の検査は誤りの種類ごとのコードにする。指摘の3件と数値の範囲・型の誤りの回帰テストと、API の 400 のテストを足し、返す形を戻すと失敗することを確かめた |
| P3：引数が一部欠けても検出できず、`undefined` が文に埋め込まれる | コードごとに引数の形（zod のスキーマ）を持ち、表示の前に確かめて、合わなければコードを出すようにした。空の引数・一部だけの引数・知らない scope・文字列の金額の回帰テストを足した |

## 残したこと

- 台帳などに記録する文言（一時停止・失敗の説明、中止の後片付け、取り込みのエラー、コンテキストの誤りなど）は、PBI-11b（#16）で行う。古い台帳の日本語はそのまま出す。
