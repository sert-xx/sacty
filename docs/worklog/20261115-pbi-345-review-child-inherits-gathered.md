# PR のレビューの子タスクが、親タスクの集めた情報を引き継ぎ、情報収集をし直さないようにする

- 日付: 2026-11-15（UTC）
- タスク: PBI-345
- PR: #373
- ブランチ: feat/issue-345-review-child-inherits-gathered
- 関係する ADR: [PR のレビューの子タスクは、親タスクが開始時に集めた情報を引き継ぎ、情報収集をし直さない](../adr/20261115-0230-review-child-task-inherits-gathered-information.md)

## 目的

sacty が作った PR をレビューする子タスクは、開始時に情報収集のエージェントを実行していた。
親タスクが同じ依頼について集めたまとめがあるので、人から、子タスクはそれを引き継ぎ、追加で調べなくてよいと指示された。

受け入れ条件の要点は次のとおり。

- 親にまとめがある子タスクは、情報収集を実行せずにレビューの工程へ進む。
- 引き継いだまとめがレビューの工程の指示とタスクの詳細に出て、親から引き継いだものだと分かる。
- 引き継ぎが作業履歴に残り、費用は増えない。
- 親にまとめが無い子タスクと、子タスクではないレビューのタスクは、今までどおり集める。
- すでに作られていて、まだ集めていない子タスクにも効く。

## したこと

- `packages/core/src/events.ts`：イベント `GatheredInherited`（親タスクの ID・まとめ・情報源）を足した。
- `packages/core/src/projection.ts`：`GatheredInherited` で、まとめをタスクの `gathered` に入れ、親タスクの ID を `inheritedFrom` に持たせた。
  工程を選んだ後・集めた後・レビューの子タスクでないタスク・別の親からの引き継ぎは、記録の不整合として扱う。
- `apps/daemon/src/service.ts`（`gatherInformation`）：最初に、`reviewOf` の親タスクのまとめを確かめ、あれば引き継ぎを記録して、情報収集のエージェントを実行しない。
- `apps/daemon/src/prompts.ts`（`gatheredLines`）：引き継いだまとめには、親タスクが集めたものであることと、PR を作る前の情報であることを添える。
- `apps/web`：タスクの詳細の「集めた情報」の件数の横と説明に、親タスクから引き継いだことを出す。作業履歴の1行の文を足した（日本語・英語）。
- 仕様書（タスクと工程・承認）、ユーザードキュメント（タスク）、ADR を直した。
- `scripts/docs-screenshots/seed-lib.mjs`：スクリーンショットのデータで、レビューの子タスクが親のまとめを引き継ぐようにした（今の実装の流れに合わせる）。
  子タスクの情報収集の費用が無くなり、ダッシュボードの費用の合計が変わるので、`docs/user/images/dashboard.png`・`dashboard.en.png` を撮り直した。
  ほかの画像は、写る内容が変わらないので撮り直していない。

別のイベントにした理由などの判断は、ADR に書いた。

- `npx vitest run tests/docs`：通った。
- 足したテスト

  - `apps/daemon/src/daemon.test.ts`：子タスクで情報収集が呼ばれないこと、親のまとめと情報源を持つこと、次の実行でレビューの工程に決まること、再起動で復元すること。親にまとめが無いときは子タスクが集めること。
  - `apps/daemon/src/prompts.test.ts`：引き継いだまとめだけに、引き継いだことの文が添えられること。
  - `apps/web/src/lib/labels.test.ts`：作業履歴の文（日本語・英語）。
- `service.ts` の変更だけを戻すと、デーモンのテスト（子タスクで情報収集が呼ばれないこと）が失敗することを確かめた。
- `node scripts/docs-screenshots/capture.mjs`（日本語はすべての場面、英語は `docs`）：直したデータで、撮る間にデーモンが作業履歴に書き足さずに撮れた。
- 画面：ビルドしたアプリを一時の環境で起動し、子タスクの「集めた情報」に「情報源 3 件・親タスクから引き継ぎ」と出ること、作業履歴に引き継ぎの行が出て情報収集の行が無いことを確かめた。
- 確かめられなかったこと：実際のエージェントでレビューの子タスクを最後まで動かすこと（テストの差し替えで確かめた）。
