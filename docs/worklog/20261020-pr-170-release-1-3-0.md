# 版を 1.3.0 に上げ、GitHub Release を作る

- 日付: 2026-10-20（UTC）
- タスク: なし
- PR: #170
- ブランチ: chore/release-1.3.0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.2.0 の後に、エージェントの実行とテストの実行の上限を `config.yaml` の `run_timeout` で設定できるようにする機能（PR #169、PBI-150）が入った。
設定の項目の追加なので MINOR を上げ、1.3.0 をリリースする。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.3.0` にし、`package-lock.json` を `npm install --package-lock-only` で更新した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.3.0` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント（`config`・`images`）の日英と、
  イメージの名前を書いているテスト・コメントを同じ版にした。ゲートウェイの MCP クライアントの版の文字列も `1.3.0` にした。

## 確かめたこと

- `npm run lint`・`npm run typecheck`・`npm run build`：通過（`apps/daemon/dist/config.js` の `DEFAULT_IMAGE` が `sacty-agent:1.3.0`）。
- `npx vitest run`：121 ファイル・2367 件が通過。
- イメージの作り直しと、`run_timeout` を書いて長い工程が続くことは、リリースの後に運用の環境で確かめる。
