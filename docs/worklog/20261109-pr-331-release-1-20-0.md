# 版を 1.20.0 に上げる

- 日付: 2026-11-09（UTC）
- タスク: なし
- PR: #331
- ブランチ: feat/release-1-20-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.19.0 の後に入った変更（PR #328〜#330）をリリースする。タスクの題の変更（PR #330）は機能の追加なので MINOR を上げる。

## 1.19.0 からの変更

- タスクの題を、タスクの途中で人がタスクの詳細から変えられる（PR #330）。
- ヘッダーのメニューが、タスク詳細の見出しの下に隠れないようにした（PR #328）。
- PR の本文の、前の工程の成果物へのリンクを、ファイルを開けるリンクにした（PR #329）。

## 互換性の判断

- 設定ファイルの形・コマンドの引数に、互換性の無い変更は無い。古い作業履歴はそのまま読める。
- 台帳：新しいイベント `TaskRenamed` を足したので（PR #330）、題を変えた後に 1.19.0 に戻すと、1.19.0 は知らない種類のイベントを読めず止まる。リリースの説明の注意に書く。
- HTTP API：`POST /api/tasks/:id/title` を足しただけで、既存の API は変えていない。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.20.0` にし、`package-lock.json` を `npm install --package-lock-only` で作り直した（差分は版の行だけ）。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.20.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.19.0 の版上げ（PR #327）と同じ範囲。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` が `Dockerfile` の値（`sha256:add5c17c…`）と同じだったので、変えていない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通過。
- `npx vitest run --no-file-parallelism`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- `git grep -F 1.19.0` で、ADR・作業履歴のほかに `1.19.0` が残っていないことを確かめた。
- `Dockerfile`・`agent-cli` は変えていないので、イメージのビルドはやり直していない。

## レビューの指摘と対応

- なし。

## 残したこと

- PR をマージした後の、タグ `v1.20.0` と GitHub Release の作成。
