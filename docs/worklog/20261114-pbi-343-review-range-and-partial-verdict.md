# PR のレビューが、大きな文書を丸ごと照合して判定を出せずに止まるのを直す

- 日付: 2026-11-14（UTC）

## 目的

PR #365 の再レビューが2回続けて判定「読み取れませんでした」になった。文書の同期の観点（U-1）が、差分に関係しない節まで含めて日英のユーザー
ドキュメントを丸ごと実装と照らし合わせようとして、終えられずに `failed` を返したため。照合の範囲を差分に絞り、観点を見きれなかったときも
要修正があれば判定を出させる。

## したこと

- 既定のレビュー（`apps/daemon/default-context/skills/review`）
  - U-1：検証できる記述・責務の記述を拾うのを依頼文の範囲の中に限った。範囲が変更なら、差分で変えた・足した記述と、差分の変更で正しさが
    変わりうる記述だけ。対象の文書を全体で渡されたときは全体。
  - 担当の規則：範囲の外を見なかったことを `failed` の理由にしない。
  - `pr-review` の「完了できないとき」：起動し直しても `failed` の観点が残ったとき、採用した `must` があれば判定「修正が必要」、無ければ判定を
    書かない。集約の記録の `verdict` の説明も合わせた。
- sacty がレビューに渡すプロンプト（`buildPrompt` のレビューの判定の指示）を同じにした。
- docs：仕様書（既定のコンテキスト・タスクと工程）・ユーザードキュメント（取り込み）を日英で直し、ADR を足した。
