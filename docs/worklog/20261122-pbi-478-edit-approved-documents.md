# 実装の工程で承認済み文書の誤りを直す

- 日付: 2026-11-22（UTC）
- タスク: PBI-478
- PR: #565
- ブランチ: main
- 関係する ADR: [実装から承認済み文書を直す](../adr/20261122-0401-edit-approved-documents-in-implementation.md)

## 目的

承認済み文書の書式やリンクの誤りを実装の工程で直し、レビューの繰り返しを防ぐ。

## したこと

文書を実装の作業領域に配置し、判断を変えない修正を実装の PR に含める。
修正の理由と差分を伏せた上で記録し、PR の本文に載せる。
作業領域とタスクブランチで同じ文書を別々に変更した場合は公開を止める。

## 確かめたこと

実装の公開、競合、再開、文書の配置、秘密情報の伏せを対象にテストを追加した。
Git 2.48.1 を使った `npx vitest run --no-file-parallelism`、`npm run lint`、`npm run typecheck`、`npm run build` は通った。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 再実行で文書の修正が消える | 控えと異なる修正を置き直さず、続きの実行で確かめる |
| 複数行の秘密情報が差分に残る | 差分を作る前に文書の全文を伏せる |
| 利用者の Git 設定で文書差分の生成が失敗する | Git の設定と環境変数を分離し、公開のテストで確かめる |
| 相対の一時ディレクトリで差分に変更行が載らない | 一時ディレクトリを絶対パスにし、Git のエラーを差分と区別する |

## 残したこと

実行後に秘密の値が変更・削除され、公開時に sacty が知らない値は伏せられない。
