# 続きのタスクを作るボタンを上部の操作の並びに移す

- 日付: 2026-11-21（UTC）
- タスク: PBI-463
- PR: なし
- ブランチ: なし
- 関係する ADR: [続きのタスクを作るボタンを、上部の操作の並びに置く](../adr/20261121-2330-derive-button-in-top-actions.md)

## 目的

完了したタスクの「続きのタスクを作る」操作を、レビューのタスクの「再レビュー」と同じ上部の操作の並びに出す。ダイアログの中身・セキュリティの進め方の制限・作れる条件は変えず、作ったタスクの一覧は概要で読めるままにする。

## したこと

- `DeriveButton` を足し、`canDerive` のタスクの上部の操作の並びに、再レビューと同じ見た目・ヒントで出した。
- 概要の「続きのタスク」の欄は一覧だけにした。
- 日英の仕様書・ユーザー文書を直した。
- 概要の欄の補足・空の文言と、ボタンの横のヒントを、ボタンの移動後の欄に合わせて直した（英語は "Overview" に揃えた）。
- 仕様書の上部の操作の列挙・派生の節の先頭・「コード:」を直した（日英）。
- テストは、日英で、ボタンが上部の操作の並びの直下の枠の中にあり、outline・`min-h-10` と横のヒントが出ることを確かめる。

## 確かめたこと

- 実行したコマンドと結果は、PR の本文の「どう確かめたか」に書いた（`npm run lint`・型チェック・`npm test`）。
- 狭い幅の見た目は、実ブラウザで見ていない（折り返す作りに頼っている）。
- スクリーンショットは撮り直していない（`task-detail` の画像は承認待ちのタスクで、このボタンが写らない）。

## 残したこと

- 狭い幅の実ブラウザでの確認（人が行う）。
