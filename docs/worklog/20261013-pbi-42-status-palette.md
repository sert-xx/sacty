# タスクの状態を意味で色分けし、完了と中止は印の形も変える

- 日付: 2026-10-13（UTC）
- タスク: PBI-42
- PR: #50
- ブランチ: feat/issue-42-status-palette
- 関係する ADR: [タスクの状態を意味の種類で色分けし、完了と中止は色だけでなく印の形でも見分けられるようにする](../adr/20261013-0047-status-palette-by-meaning.md)

## 目的

#47 で完了を緑にしたが、ほかの状態との並びを考えずに決めていた。状態の色を意味で整理し直す（PBI-42 の続き）。

## したこと

- `apps/web/src/lib/labels.ts`・`apps/web/src/components/task-bits.tsx`：状態を次の種類に分け、色と印を決めた。
  - 進めている（実行中・子タスクの完了待ち・テストの実行中・最終レビュー中・ゴールガーディアンの判定中）：青の点
  - 待っている（実行待ち・依存の完了待ち）：灰の点
  - 人の出番（承認待ち・判断待ち・一時停止）：橙の点
  - 完了：緑のチェック
  - 中止：灰の輪（中を抜いた丸）
- これまで灰色だった「テストの実行中」「最終レビュー中」など（完了していない idle）は、sacty が進めているので青にした。
- 承認待ちのうち、ゴールガーディアンが PR の指摘を判断している間は、人の出番ではないので青にした。

## 確かめたこと

- `apps/web/src/lib/labels.test.ts`：各状態の種類を確かめた。判定を戻すとテストが失敗することを確かめた。
- ライト・ダークの両方で表示を確かめた（動画。デモの環境はタスクを動かさないために設定ファイルをわざと不正にしているので、上部に設定の警告が出ている）。
- レビューで、全455テスト・lint・型チェックが通った。ブラウザでの実際の描画の確認は、レビューでは未実施。
