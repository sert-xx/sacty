# タスクの状態で、完了を中止と見分けられる色にする

- 日付: 2026-10-13（UTC）
- タスク: PBI-42
- PR: #47
- ブランチ: feat/issue-42-status-colors
- 関係する ADR: なし

## 目的

タスク一覧・タスクの詳細の状態の表示で、完了と中止がどちらも灰色で見分けられなかった。完了と中止の点・文字の色を変え、
詳細・子タスクの一覧でも同じ色にし、ライト・ダークで読めるようにする。ほかの状態の色は変えない。

## したこと

- `apps/web/src/lib/labels.ts` に `statusTone(task)` を足し、完了した idle のタスクを `completed` として、ほかの状態と分けた。
- `apps/web/src/components/task-bits.tsx` の `StatusLabel` が `statusTone` で色を選ぶようにした（一覧・詳細・子タスクの一覧で同じ色）。
- 完了の色は、ライト・ダークとも既存の `--ok` の色（ライト #1b6b3f／ダーク #7fd3a0）を使う。中止はいまの灰色のまま。

## 確かめたこと

- `apps/web/src/lib/labels.test.ts`：完了・中止・終わっていない idle・ほかの状態の色の種類を確かめた。判定を戻すと失敗することを確かめた。
