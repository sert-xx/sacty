# 要求要件・設計の PR の本文に「確認したいこと」の件数・中身・答え方を出す

- 日付: 2026-11-21（UTC）
- タスク: PBI-439
- PR: なし
- ブランチ: sacty/task-pbi-439
- 関係する ADR: なし

## 目的

要求要件・設計の PR を開いた人が、本文だけで、答えるべき問いがあること・その中身・答え方・答えずにマージしたときの扱い（推奨の答えで進む）を分かるようにする。
振る舞い（答えずにマージすると推奨の答えで進む）は変えない。

## したこと

- `apps/daemon/src/step-questions.ts` を足し、成果物の「確認したいこと」の節の読み取りと、本文の節の組み立てを置いた。
- `buildStepPullRequestBodyText`・`buildStepPullRequestBodyParts` が、節（件数・must の意味・答え方の2行・中身）を本文に出す。「確かめる所」の直後に、出典の確かめであることの1行を足す。
- 件数と答え方の行は `keep` に入れ、長さの上限でも残す。`fillTemplate` が `BodyParts.keep` を足す。
- 秘密の値は、写す前に伏せるため、`publishStepPullRequest` が 2 つの関数に渡す。
- 仕様書（`docs/spec/approval(.en).md`）と利用者向けの文書（`docs/user/tasks(.en).md`）を直した。

## 確かめたこと

- `step-questions.test.ts`（形 A・B・C・D、節なし、空、取り違え、書き方の小さな違い、CRLF、長い 1 行、2つの本文の形、切り方、省けない行、メンション・閉じるキーワード・文字参照・秘密の値、コード内外の生の HTML、閉じていないコードブロック）と、`daemon-step-pull-requests.test.ts` の結合のテスト（PR を作ったとき、答えを取り込んだ再提出）。
- 実行したコマンドと結果（直しの後のコードで実行）
  - `npm run format`：変更なし。

  - `npx vitest run --no-file-parallelism`：5981 件が通り、14 件がスキップ（失敗なし）。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 「確認しないと決めたこと：本文」・字下げした「なし」・`**must**：なし` で読み取りが外れる | 行の先頭の空白・記号・太字を除いた文で、打ち切り・「なし」・札を判定するようにした |
| 閉じ処理がコード内の `<!--`・`<details>` を数え、属性付きを数えない | 数え上げをやめ、コードの外の生の HTML の `<` を `&lt;` にして無効にした。閉じるのはコードブロックだけにした |
| TV-11・TV-12 のテストが場面を作っていない | 切れ目にまたがる秘密と、keep が無ければ消える上限のテストにした |
| 長い 1 行での遅さ・CRLF・文字参照・URL 形式の閉じるキーワード | 長い行は読まない・先頭で改行をそろえる・文字参照と URL 形式を無効にする |
| 使われない引数と export、複製元の注記、文書の細部 | 削った・注記を足した・文書を直した |

## 残したこと

- must が残るときにマージを止める・ドラフトにすること、問いの構造の記録・MCP は、範囲外。
