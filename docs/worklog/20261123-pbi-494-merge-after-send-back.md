# 前の工程へ戻した後の実装 PR のマージで進める

- 日付: 2026-11-23（UTC）
- タスク: PBI-494
- PR: #599
- ブランチ: main
- 関係する ADR: [前の工程へ戻した後も実装 PR のマージを承認にする](../adr/20261123-0038-implementation-merge-after-send-back.md)

## 目的

前の工程へ戻したタスクでも、人が実装 PR をマージしたら承認として進める。

## 原因

PR #590 では 2026-11-22 21:53:27 UTC に指摘を設計へ戻し、同日 21:53:59 UTC に実装 PR がマージされた。
実行対象が設計のため、従来の実装 PR の見守り対象には入らなかった。
工程 PR の公開は削除されたタスクブランチの取得に失敗し、エラーで一時停止した。
設計の変更の申し出自体は工程を戻さず、指摘による差し戻しが設計を実行対象にする。

## したこと

前の工程に戻したタスクの実装 PR を見守り、マージを承認として進める。
承認の基準を記録し、工程 PR と同時にマージ済みなら一時停止する。
残った工程 PR の片付けと、中止時の PR の対象を GitHub の状態に合わせる。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npx vitest run tests/docs` | 97 件成功、参照とリンクの走査 2 件が時間切れ（再実行でも同じ） |
| `npx vitest run --no-file-parallelism` | Git 2.46.4 で 7,242 件成功、実 AI を使う 1 件をスキップ |
| `npm run build` | 成功 |

前の工程の PR の見守りを一時的に無効にすると、設計への差し戻しと要求要件の変更の両方の再現テストが失敗することを確認した。
全件テストは公式ソースからビルドした Git 2.46.4 を検証用ディレクトリに置いて実行した。
標準の Git では同じ範囲を確認していない。
実際の GitHub PR を操作する検証は、外部の PR を変更するため行っていない。

## レビューの指摘と対応

### 設計の PR #594

両 PR のマージが同じ確認で見えた場合の一時停止と、後からマージされた工程 PR の状態の記録を実装する。

### この PR のレビュー 1 回目

| 指摘 | 対応 |
| --- | --- |
| 複数の工程 PR の一部を見逃す | すべての工程 PR を確認する |
| GitHub の通信が期限なく待つ | 状態取得とクローズに期限を設ける |
| 旧版への切り戻しの説明が不足 | 状態同期と停止記録の互換性を明記する |
| 停止を確認できない実行が残る | 一時停止中も実行を記録する |
| 予算停止の理由が上書きされる | 予算停止を維持する |
| 中止確認の説明が実際の対象と異なる | 日英の仕様を更新する |

### この PR のレビュー 2 回目

| 指摘 | 対応 |
| --- | --- |
| 再開済み以外のマージを見逃す | 未判断の工程 PR があれば停止する |
| 予算停止中に PR 番号が見えない | 停止理由に番号と再開後の扱いを表示する |
| テストの整形違反 | フォーマッターで直す |
| 認証情報の取得に期限がない | 取得を含めて期限を設ける |
| 期限切れでも通信が残る | 通信を中断する |
| 旧版の投影の説明が一律 | 組情報の消失と投影停止を区別する |

### この PR のレビュー 3 回目

| 指摘 | 対応 |
| --- | --- |
| 複数の工程 PR の番号が表示から漏れる | すべての番号と再開後の扱いを表示する |
| GitHub の応答本文を読めないと open と誤認する | 失敗を伝えて次の確認で再試行する |
| 複数の停止記録を旧版で投影できない | 日英の仕様と ADR に制約を明記する |

### この PR のレビュー 4 回目

| 指摘 | 対応 |
| --- | --- |
| 履歴がマージ済みの工程 PR をクローズのみと表示する | マージ済みとクローズ済みの表示を分ける |
| 作業履歴に PR 番号と検証・レビューの詳細が不足 | PR 番号と検証結果、レビューごとの対応を記録する |
| 対応版 Git での全件検証と修正を戻す確認 | 全件テストと二つの再現テストの確認を実行する |

## 残したこと

両 PR の包含関係を一般に保証することは対象外とする。
古い記録に実装 PR のリポジトリが無い場合は、両 PR を照合できず、工程 PR の公開と承認を保留する。
