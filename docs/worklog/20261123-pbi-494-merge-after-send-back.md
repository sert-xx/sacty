# 前の工程へ戻した後の実装 PR のマージで進める

- 日付: 2026-11-23（UTC）
- タスク: PBI-494
- PR: なし
- ブランチ: main
- 関係する ADR: [前の工程へ戻した後も実装 PR のマージを承認にする](../adr/20261123-0038-implementation-merge-after-send-back.md)

## 目的

前の工程へ戻したタスクでも、人が実装 PR をマージしたら承認として進める。

## 原因

PR #590 では 2026-11-22 21:53:27 UTC に指摘を設計へ戻し、同日 21:53:59 UTC に実装 PR がマージされた。
実行対象が設計のため、従来の実装 PR の見守り対象には入らなかった。
工程 PR の公開は削除されたタスクブランチの取得に失敗し、エラーで一時停止した。
設計の変更の申し出自体は工程を戻さず、指摘による差し戻しが設計を実行対象にする。

## したこと

前の工程に戻したタスクの実装 PR を見守り、マージを承認として進める。
承認の基準を記録し、工程 PR と同時にマージ済みなら一時停止する。
残った工程 PR の片付けと、中止時の PR の対象を GitHub の状態に合わせる。

## 確かめたこと

| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm run build` | 成功 |
| `npx vitest run --no-file-parallelism` | Git 2.46.4 で 7,184 件成功、実 AI を使う評価 1 件をスキップ |
| `npx vitest run tests/conventions/wait-for.test.ts` | 全件実行中に時間切れとなった規約テストを単独で再実行し、3 件成功 |

| `npx vitest run apps/daemon/src/daemon-step-pull-requests.test.ts -t '予算停止中に両 PR|クローズが期限切れ'` | 予算上限の確認とクローズの中断後の再試行 2 件が成功 |

前の工程での実装 PR の見守りを一時的に無効にすると、設計への差し戻しと要求要件の変更の申し出の再現テストはいずれも消えたブランチの取得による停止で失敗した。
認証情報と Docker を隔離したローカル環境でビルド済みデーモンを起動し、タスク詳細 API の応答を確認した。
GitHub の実 PR を操作する検証は外部の PR を変更するため行っていない。

## レビューの指摘と対応

### 設計の PR #594

両 PR のマージが同じ確認で見えた場合の一時停止と、後からマージされた工程 PR の状態の記録を実装する。

### この PR の最初の提出

まだ無い（最初の提出）

## 残したこと

両 PR の包含関係を一般に保証することは対象外とする。
古い記録に実装 PR のリポジトリが無い場合は、両 PR を照合できず、工程 PR の公開と承認を保留する。
