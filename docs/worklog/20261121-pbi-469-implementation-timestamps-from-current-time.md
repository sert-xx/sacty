# 実装・直しの指示に今の UTC の時刻を入れる

- 日付: 2026-11-21（UTC）
- タスク: PBI-469
- PR: なし
- ブランチ: main
- 関係する ADR: [実装・直しの指示に指示を作った UTC の時刻を入れ、記録の日時が今より後なら直させる](../adr/20261121-2040-implementation-timestamps-from-current-time.md)

## 目的

担当が時刻を推測して、ADR のファイル名の日時が未来になるのを防ぐ。

## したこと

- 実装・直しの指示の全部の枝に、指示を作った UTC の時刻と、日時を推測せず確かめて書く決まりを入れた。service が時計の時刻を渡す。
- 提出の前に確かめる基準 `FUTURE_TIMESTAMP` と、レビューの観点 X-1 に、未来の記録の日時を直させる項目を足した。
- 既定の規則に、日時を書くときは今の時刻を確かめる決まりを汎用の形で足した。
- 仕様書（日英）を合わせた。

## 確かめたこと

- 指示・基準・service・既定のコンテキストを確かめるテストを足し、tests/docs と全テストを実行した。

## 残したこと

- すでに main にある未来の日時の ADR の名前は、直さない。
