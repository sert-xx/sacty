# 以前の版の最終レビューの仕組み（依存 `finalReview`）のコードを消す

- 日付: 2026-11-12（UTC）
- タスク: PBI-336
- PR: #355
- ブランチ: feat/issue-334-remove-final-review（PBI の番号が PR #354 と重なったので 336 にした。開いている PR のブランチなので名前は変えていない）
- 関係する ADR: [以前の版の最終レビューの仕組み（依存 `finalReview`）のコードを消す](../adr/20261112-1420-remove-legacy-final-review-code.md)

## 目的

PBI-331 で依存 `finalReview` を有効にしたときだけ動く形で残した最終レビューの仕組みを消し、今の流れ（実装 → ドラフトの PR →
レビューの子タスク → 指摘なしでドラフトを外す）だけを保守する。

## したこと

- デーモン：
  - 依存 `finalReview` を外した。最終レビュー（`verify`）・テストのコンテナ・実装の PR の CI の待ち（`checkVerificationCi`）・
    失敗した CI の再実行・CI が無いときの判定・不安定なテストの台帳への記録・検証の前のベースブランチの取り込み・再開のときの
    工程の選び直しを消した。テストのコマンドが決まらないときの一時停止（最終レビューのときだけ止めていた）も消した。
  - 最終レビューの指示と出力の読み取り（`prompts.ts`）、PR の本文の検証中・最終レビューの段、使われなくなった定数を消した。
  - 残したもの：最終レビュー・CI の待ちの途中だった古いタスクを `FinalReviewSkipped` で今の流れに乗せる移行、古い台帳の型・投影・
    画面の表示・費用・メッセージのコード、不安定なテストの台帳を読む API と台帳からタスクを作る口、利用者の設定を読めるように
    役割 `final-review`（時間の上限・スタブ）、競合の目印が残ったときの数え（`pauseIfVerificationKeepsFailing`）。
- テスト：最終レビュー・CI の待ち・不安定なテストの記録にだけ関わるテストを消し、工程の流れを確かめるテストは今の流れで同じ意図を
  確かめる形に書き換えた（最終レビューの出力の helper を外し、止める・再開する所を実装の工程に移した）。最終レビューのテストの
  ファイルのうち、統合レビューを確かめるものは `integration-review-*.test.ts` に名前を変えた。
- docs：仕様書（タスクと工程・承認・コンテキスト・監査・分割と統合・エージェントの実行。日英）から、`finalReview` を有効にした
  ときだけ動く仕組みの記述を消し、以前の版のタスクの扱いを1つの節にまとめた。最終レビューの図を消した。ADR を足した。
  消した見出しを指していた ADR 2件のリンクを直した。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：エラーなし。
- `npx vitest run`：全体が通った。
- `npx vitest run tests/docs`：通った。
- 新しいテスト：以前の版の最終レビューで止まったタスクは、再開すると今の流れに乗る。

## レビューの指摘と対応（1回目・2回目）

判定は、どちらも「修正が必要」（2回目は直す前のコミットのレビュー）。

- [要修正] 消した最終レビューを、今も動くように説明している文書が残っていた（サービスの起動・テストの実行・compose・トラブルシューティング）。
  → 仕様書・ユーザードキュメント（日英）を洗い、今の振る舞いに直した。ユーザードキュメントのタスクのページから、以前の版の最終レビューの動きの節（テストのコマンド・実装の PR と CI・判定を読み取れないとき・続けて通らないとき・範囲外の変更・人が確かめること・ツールがイメージに無いとき・テストなしで進めずに止まったとき）を消し、以前の版のタスクの扱いを短い節にまとめた。消した見出しを指していた ADR のリンクを直した。
  あわせて、今も読まれる文言を直した：再開の画面のテストのコマンドの説明（sacty は実行せず、実装の工程の指示に渡す）など画面の文言（日英）、工程のエージェントとオーケストレーターへの指示の最終レビューへの言及、既定のスキル・規則の「最終レビューの不合格」（「検証の不合格」に）、PR の本文の表の「最終レビュー」の列とテストの行（以前の版の記録があるときだけ出す）。
- [提案] `copyWorkingTree` の `include` 引数と成果物の差し替えは、本番の呼び出し元が無い。
  → 引数と分岐、専用のテストを消した。
- [提案] 仕様書の「テストが決まらずに止まったタスクの再開」が、テストなしの判断を使えないときに止まると書いていた（今は判断を捨てて進む）。
  → 日英で、今の動き（止まらずに進む）と、以前の版で止まったタスクの再開のときのテストの扱いに書き直した。
- [提案] 英語版の仕様書が、実装に変更が無いときは PR があっても `NoChangesFound` を記録するように読めた。
  → 日本語版と同じく、まだ PR が無いときに限ると書いた。

確かめたこと：

- `npm run lint`・`npm run typecheck`：エラーなし。
- `npx vitest run apps/daemon apps/web packages tests/docs`：通った。

範囲の外として残したこと：再開の画面のテストの扱いの選択が、止まった理由を見ずに出ること（`testsUndecided`。この PR より前からの振る舞い）。
