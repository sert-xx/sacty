# 実装の残りから取り込み済みの変更と工程外の作業を分ける

- 日付: 2026-11-22（UTC）
- タスク: PBI-491
- PR: なし
- ブランチ: main
- 関係する ADR: [実装の残りから取り込み済みの変更と工程外の作業を分ける](../adr/20261122-2201-implementation-remaining-boundaries.md)

## 目的

取り込み済みの変更や人が行うと決まった作業によって、実装が不要に一時停止することを防ぐ。

## したこと

実装の完了申告の指示に、取り込んだ変更、工程外の作業、人への問いと推奨の扱いを加えた。
仕様書の日英版とテストを合わせた。

追加した取り込みの指示と工程外の作業の指示をそれぞれ取り除き、対応するテストが失敗することを確かめた。
