# Node.js を 22.x から 26.x の LTS（26.12.1）に上げる

- 日付: 2026-10-28（UTC）
- タスク: なし
- PR: なし
- ブランチ: ccr-edc66277-0gkkqv
- 関係する ADR: [Node.js を 26.x の LTS に上げる](../adr/20261028-1158-node-26-lts.md)

## 目的

2026-10-28 に LTS になる Node.js 26.x に、開発・実行・既定のイメージの前提を揃える。

## したこと

- `package.json`（`engines.node` を `>=26.12.1`、`@types/node` を `^26.6.5`）・`apps/web/package.json`（`@types/node` を `^26.6.5`）を直し、Node v26.12.1 の `npm install` で `package-lock.json` を作り直した。
- `.node-version`・`mise.toml` を `26.12.1` にした。
- 既定の元のイメージを `node:26-bookworm-slim` にした（`packages/cli/docker/Dockerfile`・`packages/cli/src/index.ts`・`apps/daemon/src/image.ts`・`apps/daemon/src/config.ts` のコメントと設定の例）。テストの期待と例の値も合わせた。
- `README.md`・`README.en.md`・`CONTRIBUTING.md`・`docs/user/getting-started(.en).md`・`docs/user/images(.en).md`・`docs/spec/agent-execution(.en).md` の版とイメージの名前を直した。
- テストで `--experimental-strip-types` を付ける理由のコメントを、新しい `engines` に合わせた（コードは変えていない）。
- ADR を足し、22.23.4 の下限の ADR を置き換え済みにした。

## 確かめたこと

- Node.js の配布の一覧（`https://nodejs.org/dist/index.json`）で、26.x の最新が v26.12.1（2026-10-21・セキュリティリリース）であること、Node.js のリリースの予定（`schedule.json`）で 26.x の LTS の開始が 2026-10-28 であることを確かめた。
- Docker Hub の API で、`node:26-bookworm-slim` と `node:26.12.1-bookworm-slim` の digest が同じであることを確かめた。
- Node v26.12.1 で：
  - `npm run typecheck`：エラーなし。
  - `npm run lint`：指摘なし。
  - `npm test`：2925 件が通り、8 件が落ち、1 ファイル（ブラウザのテスト）が読み込めなかった。落ちた 8 件（`agent-sessions`・`context-mcp`・`host-mcp-processes` のテスト）は、変更前の状態を Node v22.22.0 で動かしても同じく落ちる。この作業用の環境（root で動く・Playwright のブラウザの版が合わない）によるもので、この変更とは関係ない。
  - `npx vitest run tests/docs`：通った。

## 残したこと

- 元のイメージの条件（Node.js 18 以上）は変えていない（ADR の理由のとおり）。
- この作業用の環境では Docker が使えないので、`node:26-bookworm-slim` からのイメージの作成は試していない。
