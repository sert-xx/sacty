# テストの待ちの期限と全件テストの手順をそろえる

- 日付: 2026-11-22（UTC）
- タスク: PBI-482
- PR: #573
- ブランチ: main
- 関係する ADR: なし

## 目的

遅い実行機での待ちの時間切れを減らし、全件テストの手順を CI にそろえる。

## したこと

アサーションの待ちをテストの残り時間に合わせ、直接呼び出しを検査する。プロセスの回収を待つ期限を広げ、ドラフトの上限を実時間に依存せず確かめる。
CI で残った PID の状態は記録されておらず、動作中だったかゾンビだったかは不明である。

## 確かめたこと

提出時の検証結果は PR の説明に記載する。

## レビューの指摘と対応

### 設計のレビュー

ゾンビもプロセスの残存として数える。

### この PR のレビュー

改行やコメントを挟む直接呼び出しも検出するよう構文解析に変え、コメントや文字列内の例と区別するテストを追加した。

## 残したこと

変更前の CI の全件テストの Duration は 332〜339 秒だった。
この PR の CI では同じ Duration が 421.94 秒で、約 83〜90 秒長かった。
直前の成功した実行は同じ 346 ファイル・7085 件で 300.26 秒だった。
421.94 秒の実行では、直接呼び出しの検査が 57ms から 2983ms に増えたほか、既存の多数のテストでも時間が増えた（例：daemon-implement は 15.8 秒から 22.0 秒）。
Duration の内訳もテストと import の双方が増えており、検査の構文解析だけでは延長を説明できない。
実行環境の負荷を含む原因はログから特定できない。
今回の変更後の CI の所要時間は未確認である。
