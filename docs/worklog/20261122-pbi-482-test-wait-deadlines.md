# テストの待ちの期限と全件テストの手順をそろえる

- 日付: 2026-11-22（UTC）
- タスク: PBI-482
- PR: #573
- ブランチ: main
- 関係する ADR: なし

## 目的

遅い実行機での待ちの時間切れを減らし、全件テストの手順を CI にそろえる。

## したこと

アサーションの待ちをテストの残り時間に合わせ、直接呼び出しを検査する。プロセスの回収を待つ期限を広げ、ドラフトの上限を実時間に依存せず確かめる。
CI で残った PID の状態は記録されておらず、動作中だったかゾンビだったかは不明である。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm test` | 成功（346 ファイル、7072 件成功、14 件スキップ） |
| `npm run build` | 成功 |

CPU を使うプロセスを5つ動かし、プロセスの3経路とドラフトのテストを30回実行して通った。
プロセスグループの停止を外すと3経路とも残った PID と状態を示して失敗した。
ドラフト要求の計数を早く終える変更と、上限のタイマーを外す変更でも、それぞれテストが失敗した。

## レビューの指摘と対応

### 設計のレビュー

ゾンビもプロセスの残存として数える。

### この PR のレビュー

改行やコメントを挟む直接呼び出しも検出するよう構文解析に変え、コメントや文字列内の例と区別するテストを追加した。

## 残したこと

変更前の CI の全件テストの Duration は 332〜339 秒だった。前回の PR の CI ではテスト手順が約 300 秒で成功した。計測単位が異なるため厳密には比較できない。今回の修正後の CI の時間は未確認である。
