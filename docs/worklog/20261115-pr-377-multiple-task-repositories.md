# タスクの作成時に複数のリポジトリを指定する

- 日付: 2026-11-15（UTC）

- 関係する ADR: [タスクの作成時に複数のリポジトリを指定し、候補を絞る](../adr/20261115-2352-limit-task-repository-candidates.md)

## 目的

複数のリポジトリにまたがるタスクで、作成時に候補を指定した範囲に絞る。

## したこと

作成 API と作業履歴に一覧を追加し、候補の照合、情報収集、分割と統合レビューに反映した。
仕様書と API の利用例を日英で更新した。

## 確かめたこと

偽の GitHub とエージェントを使い、入力、候補、分割、情報収集と再開をテストした。
前の実装では `npm run lint`・`npm run typecheck`・`npm run build`・`npx vitest run tests/docs` が成功した。
`npx vitest run` は 4,366 件成功、14 件スキップ、デスクトップ移行の1件が時間切れで、単独実行は成功した。
追加した分割、選択後の統合レビュー、旧形式の履歴、情報収集と対象の再照合のテストも、各テストを指定して実行し成功した。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 作成入力と候補制限、仕様書と作業履歴が不足 | 一覧の記録と候補の照合を追加し、文書を更新した |
| 候補照合の繰り返しと取得失敗の理由 | プロジェクト一覧を一度読み、対象外以外の例外と Org の取得失敗の理由を伝える |
| 情報収集と再照合時点の文書 | 件数と照合する工程を明記した |
| 選択後の情報収集と定義の読み取り例外 | 指定先の照合を先に行い、選択後も全件を読むよう指示し、停止と再開をテストした |
| 指定先の一部に複数の子を作る | 同一リポジトリに2つの子を作るテストを追加した |
| イメージ待ちやリポジトリ準備が候補照合より先に定義を読む | 複数指定タスクは準備前にも候補を照合し、読み取り失敗で停止して復旧後に再開することをテストした |
| 候補照合の後に定義の読み取りが失敗する場合 | イメージ待ち・設定とリポジトリ準備の失敗を停止に変換し、復旧後に再開できることをテストした |
| CI の並行実行テストが失敗 | PR の先頭の check は失敗のままで、再実行の結果は無かった |

## 残したこと

要求要件・設計・分割へのコードの写しと、画面の複数選択は別の子タスクで扱う。
