# 複数リポジトリのコードを親の工程に渡す

- ブランチ: sacty/task-27e7b6b3

## 目的

複数のリポジトリを指定したタスクの要求要件・設計・分割で、各リポジトリのコードを読めるようにする。

## したこと

指定したリポジトリの写しを工程に渡し、選択した後は残りを読み取り専用でマウントする。
指示に場所とブランチとコミットを示し、リポジトリごとの要求と設計を求める。

## 確かめたこと

偽のリポジトリとエージェントを使い、選択前後の工程と、失敗からの再開を確認した。
`npm run lint`・`npm run typecheck`・`npm run build` が通過した。
`npx vitest run` は 4,503 件通過、14 件スキップした。
`npx vitest run tests/docs` は 93 件通過した。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 既定ブランチの変更と有効な名前を扱えない | 実行ごとにリモートの HEAD を確認し、Git で参照名を検査する。 |
| 中断した写しが残る | 起動時の整理に追加し、マウント中の写しを保護する。 |
| 写しの内容とマウントの検証が不足 | 更新後の内容と Input との同時マウントを確認する。 |
| 準備失敗時に工程見直しが消える | 失敗を記録しても保留中の見直しを保持する。 |
| 複数指定の入力エラーが 409 になる | 対象外・上限超過・同時指定に HTTP 400 を返す。 |
| 写しの失敗で代替エージェントに切り替わる | 準備の失敗は停止し、再開後にやり直す。 |
| 不完全な clone を再利用する | 準備完了の印がない場合は作り直す。 |
| 写しの取り違えと2件目の失敗を確認できない | 内容を分け、2件目の途中失敗と再開を試す。 |
| 過去の作業履歴が変わっている | PR #377 のマージ時の内容に戻す。 |
| 選択済みの再準備でも不完全な写しが残り、失敗にリポジトリ名がない | 両方の準備経路で途中の写しを判定して作り直し、失敗したリポジトリと理由を記録する。 |
| 選択済みの再準備で有効なブランチ名を拒否する | 取得と再準備で Git の参照名検査を共有し、記録済みの起点を再現するテストを追加する。 |
| 選択済みの起点の内容を確認していない | 選択した起点と他のリポジトリに異なる内容を用意し、それぞれを確認する。 |

| 準備失敗後に時間切れのセッションを続けられない | 実行前の準備失敗を区別し、継続の判定で除く。 |
| 準備中の印が残る | タスクの片付けと起動時整理で印を消す。 |
| 作業領域の一覧に写しの場所がない | 日英の構成一覧に追加する。 |
