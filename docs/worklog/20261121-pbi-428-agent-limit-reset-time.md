# 利用上限の明ける時刻まで、代わりのエージェントに切り替えたままにする

- 日付: 2026-11-21（UTC）
- タスク: PBI-428
- PR: なし
- ブランチ: なし
- 関係する ADR: [利用上限で失敗したエージェントは、失敗の文から明ける時刻を確かに読み取れたとき、その時刻まで使わない](../adr/20261121-0200-agent-limit-reset-from-failure-message.md)

## 目的

週の上限に達したエージェントを 60 分ごとに試し直して失敗するのをなくす。

## したこと

- 失敗の文から明ける時刻を読む `parseLimitReset` を足した。読むのは、時間帯の名前つきの Claude Code の形と古いエポックの形。
- `markLimited` が、読めた時刻を期限にした（読めなければ `cooldown_minutes`）。`AgentFellBack` の `until` は、この期限から出る。
- 仕様書・利用者向け文書（日英）と設定の雛形のコメントを直し、ADR を足した。

## 確かめたこと

- 読み取り（各形・境界・不正・遠すぎる・すぐ前）と、切り替え（長い例・短い例・読めないとき・一時的な混雑）を、テストで確かめた。

## 残したこと

- 時間帯の名前の無い形（Claude Code の `resets 3:45pm`、Codex の `try again at …`）は読めない。時間帯を知る手段が要る。
