## 検証

- 整形・lint、型検査、アプリ本体のビルド：成功。
- 追加のランタイムテスト7件と docs を含む100件：成功。
- macOS arm64 のアプリを作成し、独立した一時設定・限定した PATH で起動。Node.js の別途導入なしで画面を表示できることを確認。
- 同梱したアーカイブの実際の読み込みを確認。既存イメージを削除せず、検査の最初の1回だけ不足を返すテスト用ラッパーを使用した。
- 画面の IPC 分離、外部遷移の拒否、アプリ終了後の画面プロセス停止を確認。
- API キーの保存はプロセスを差し替えたテストで確認し、実際のキーチェーンを上書きしていない。
- 既存のセキュリティツール導入テスト2件は、macOS のテスト用 PATH に sha256sum が無く失敗。未変更の元コードでも再現したため、この変更では修正しない。
- 全体テストのブラウザー終了処理が同時のパッケージ作成中に10秒で時間切れ。単独実行は成功し、30秒に延ばしても全体同時実行では時間切れになった。最終確認はブラウザーテストを別の実行に分けた。
- 一時リポジトリを作る既存テストは実行時だけ Git の署名を無効にした。作業リポジトリの Git 設定は変更していない。
- 最終の分割実行：ブラウザー以外160ファイル2962件と、ブラウザー1ファイル2件の合計2964件が成功。
- 署名・公証、自動更新、別の Mac、Intel Mac、実際の AI タスクの実行は未検証。
- コミット・push・Issue・PR の作成は行っていない。

## 独立レビューへの対応

- 最初の起動確認はソースリポジトリ内で実行したため、親ディレクトリの依存にフォールバックし、配布物の問題を検出できていなかった。
- P1（依存リンク切れ）：完成品の全リンクを同梱範囲内の相対パスに直し、範囲外への解決を拒否する処理を追加。一時フォルダを削除して別フォルダへ移してもモジュールを解決できる回帰テストを追加した。
- P1（定義ファイル不足）：既定エージェント定義を同梱し、完成品で存在を検査する。ユーザーの設定ファイルは同梱しない。
- P2（外部リンク）：メイン画面の HTTP/HTTPS リンクを検査して既定ブラウザーへ渡す。認証情報付き URL、アプリ内部の URL、ほかのスキームは渡さない。外部リダイレクトではブラウザーを起動しない。
- パッケージ後のテストは、完成品をソースツリー外へコピーして実行する。モジュールの解決先と既定エージェント定義が同梱範囲内であることも検査する。
- 新規の回帰テスト12件を追加し、デスクトップと文書の合計112件が成功。
- リポジトリ外の完成品で、新規設定の作成、同梱 Node.js による画面起動、PR リンクの受け渡し、IPC 分離、アプリ終了後の画面停止を確認した。リンク先はテスト用のブラウザー受け取り処理で確認し、実際のブラウザータブは開いていない。
- コミット・push・Issue・PR は引き続き作成していない。
- 修正後の全体検証：ブラウザー以外162ファイル2974件と、ブラウザー1ファイル2件の合計2976件が成功。既知の2件は前回と同じ理由で除外した。アプリ本体のビルド・型検査・lintも成功。
- 独立レビュー担当が完成品から同梱モジュールの解決と設定の読み込みを再確認し、3件の指摘の解消を確認した。

## PR適合レビューの3指摘への対応

- P1：過去の標準イメージからの移行確認を追加。イメージを確認してから設定を権限600でバックアップし、コメントと他の設定を残して名前だけを切り替える。独自タグ・将来の版・取り消し・取得失敗・確認後の編集では上書きしない。
- P2：通知だけを信頼するメイン画面・同じオリジン・メインフレームに限定して許可。既存の通知設定はオフのまま、利用者がオンにできるようにした。他の権限は拒否する。
- P2：準備画面・進行状態・エラー・確認ダイアログを日英辞書へ移し、製品名、長さ、補足の規則を検査。言語は既存のcookieでメイン画面と共有する。
- desktopの45件と文書の93件、計138件が成功。全体は分割実行で3002件成功。既知の環境依存2件は前回どおり除外した。
- ビルド・lint・型検査が成功。型検査は古い生成物に重複があったため、ビルド後に再実行した。
- 旧版イメージの設定を持つ一時データで実アプリを起動し、英語表示への切り替え、更新の確認、バックアップと設定移行、英語のメイン画面、日本語への切り替えを確認した。
- テスト用のローカルプロジェクトを作り、デスクトップ通知のチェック項目が操作可能でオフであることを確認。OSの権限変更・通知送信は行っていない。バックアップの権限と他の設定の保持、終了後の両ポート停止も確認した。
- 別エージェントの再レビューでは、追加の重大な指摘はなかった。コミット・push・PRは作成していない。

## 再レビュー後の実用確認（2026-10-31）

- カスタムイメージ不足時に標準アーカイブを読み込むP2を修正。同梱manifestの名前とCPUが一致する場合だけ読み込む。
- 標準タグが存在し、言語用の独自イメージだけ不足する回帰ケースを追加。修正を一時的に戻すと新しい2件が失敗することも確認。
- Docker・GitHub認証の失敗後の再試行と設定保持を検査。言語cookieは1年間保存。
- 日英の起動失敗時の復旧手順を追加。
- ネットワークなしで実コンテナを起動し、Node.js・Git・Codex・ghの存在を確認。

- 実GUIで既存のHttpOnly言語cookieの上書きが拒否されるケースを検出し、同じ属性で書き込んでディスクへ保存するよう修正。実GUIで英語への切り替え・完全終了・再起動後の保持を確認。
- 最終コードの関連テスト145件、全体テスト3,007件、別実行ブラウザーテスト2件、lint・型検査・本体ビルドが成功。全体実行では既知の環境依存2件を除外。
- 新規設定で実アプリを起動し、ローカルプロジェクトを作成。完全終了後の再起動で日本語とプロジェクトの保持を確認。終了後の4700/4710ポート停止を確認。
- 最終同梱アーカイブをDockerへ実読込し、約12秒で成功。読込前後のイメージIDが同じことを確認。AIへの実接続は利用者の指定により実行しない。
- 実GUIで動かしたコードと最終パッケージがソースに一致することを検査。署名・公証・自動更新は未実施で、一般公開版としての保証はしない。
