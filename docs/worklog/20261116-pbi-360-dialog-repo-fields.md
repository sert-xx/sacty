# 作成のダイアログの複数のリポジトリの欄の操作と、一覧・詳細・絞り込みの表示を直す

- 日付: 2026-11-16（UTC）
- タスク: PBI-360
- PR: なし
- ブランチ: feat/issue-360-dialog-repo-fields
- 関係する ADR: なし

## 目的

複数のリポジトリを指定できるようにした作成のダイアログと、その表示で見つかった操作の問題を直す。

- 初期値の入った欄を削除すると、残った欄に初期値が入り直る。
- 欄を追加・削除した後、フォーカスが次に操作する欄に移らない。
- 上限の 10 件で「リポジトリを追加」が押せなくなる理由が出ない。
- テンプレートを選ぶと、増やした欄の値が捨てられる。
- 一覧・詳細で、複数を指定したときだけ URL の全体が並ぶ。
- 同じリポジトリを 2 つの欄に入れても、何も知らせない。
- 一覧のリポジトリの絞り込みで、複数を指定したタスクが、指定したリポジトリで探せない。

## したこと

- `apps/web/src/components/new-task-dialog.tsx`（`TaskFields`）
  - 初期値は、候補が届いたとき・変わったときにだけ、人が触っていない先頭の欄に入れる。欄の増減では入れ直さない。
  - 追加した欄、削除なら消した位置に上がってきた欄（最後の欄を消したら前の欄）にフォーカスを移す。
  - 上限に達したら、押せない理由をボタンの横に出し、ボタンの説明（`aria-describedby`）にもする。
  - テンプレートを選んでも、増やした欄と値を捨てない。選んでいる間は先頭の欄だけを出す（送るのも先頭だけ）。
  - 同じリポジトリの欄を、欄の番号で知らせる。
- `apps/web/src/lib/repository-fields.ts`：上限の定数、削除の後のフォーカスの先、重複の欄の検出。
- `apps/web/src/lib/repo-label.ts`：指定したリポジトリの短い名前。
  一覧（`task-list.tsx`）はリポジトリの名前、詳細（`task-detail.tsx`）は `owner/name` で、どちらも単数の表示と同じ。
  同じ名前があるものだけ長くする。URL の全体は、一覧ではツールチップ、詳細ではリンク先とツールチップ。
- `apps/web/src/lib/task-filter.ts`：複数を指定したタスクを、指定したどのリポジトリの名前でも合うようにし、選択肢にも出す。
- 文言（`apps/web/src/i18n/messages/forms.ts`）：上限の理由と、重複の知らせ（日英）。
- 仕様書（`tasks-and-steps`・`architecture`）とユーザードキュメント（`tasks`）を、日英で直した。

決めたこと：

- 重複は、送る前に除かず、画面で知らせる。
  デーモンは名前を正規化して重複を除き、1 件なら単数の指定と同じに扱う（[タスクと工程](../spec/tasks-and-steps.md)）。
  画面が黙って除くと、入れた欄の数と作られるタスクの指定の数が合わない理由が分からないため。比べ方はデーモンと同じ `repoKey`。
- 一覧の短い名前はリンクにしない（1 行に最大 10 個のリンクが並び、キーボードの移動が増えるため）。詳細ではリンクにする。
- 絞り込みの「未定・リポジトリ無し」には、複数を指定したタスクを入れない（一覧でも「リポジトリ無し」の印を出していない）。
- スクリーンショットは撮り直していない（撮っている場面のダイアログ・一覧の見た目は変わらない）。

## 確かめたこと

- `npm run lint`：リポジトリのファイルに指摘なし（サイズの上限を超える既存の `apps/daemon/src/daemon.test.ts` は、警告付きで検査から外れる）。
- `npm run typecheck`：成功。
- `npx vitest run --no-file-parallelism`：成功（228 ファイル、4,615 件成功、1 件スキップ）。
- `npx vitest run tests/docs`：成功（93 件）。
- `npm run build`：成功。
- 足したテストは、画面と絞り込みの修正だけを戻すと失敗することを確かめた（39 件が失敗）。
- 実際のブラウザー（Playwright の Chromium）で、このブランチのビルドを、架空のデータを入れた一時の `SACTY_HOME` と別のポートで起動して、日英の両方で確かめた。
  - 候補が 1 件のプロジェクトで、初期値の入った 1 欄目を削除しても、残った欄は空のまま（1.5 秒待っても戻らない）。
  - 追加した欄、消した位置の欄（最後の欄を消したら前の欄）にフォーカスが移る。
  - 10 欄で「リポジトリを追加」が押せなくなり、理由が出る。減らすと消える。
  - 大文字・末尾の `/` だけが違う URL を 3 欄目に入れると、欄 3 の重複を知らせる。
  - 3 欄に値を入れてテンプレートを選ぶと 1 欄になり、「なし」に戻すと 3 欄と値が戻る。
  - 2 つを指定して作ると、詳細は `acme/payments-api, acme/billing-web`（リンク先とツールチップが URL の全体）、一覧は `payments-api, billing-web`（ツールチップが URL の全体）。
  - 一覧の絞り込みで、`billing-web`・`payments-api` のどちらを選んでも、作ったタスクが出る。
