# 同じ原因の要修正が続くときに人の判断を求める

- 日付: 2026-11-23（UTC）
- タスク: PBI-492
- PR: #598
- ブランチ: main
- 関係する ADR: [同じ原因の要修正が続く場合に人の判断を求める](../adr/20261123-0007-repeated-cause-decision.md)

## 目的

同じ原因の要修正が繰り返されるとき、範囲を絞る案を示し、人が判断できるようにする。

## したこと

レビューの指示に案と受け入れ条件の照合を追加した。
3回目以降の PR レビューは既存の印で停止し、セルフレビューでは判断事項を報告と画面に出す。
人の指摘が同じ回にあっても停止する。
判断後に同じ先頭の新しいレビュー回で同じ原因が続いた場合も、根拠の文の書き出しで区別して再び停止する。

## 確かめたこと

| コマンド・確認 | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm test` | 346ファイル、7,137件成功、14件スキップ（Git の機能が無い13件と AI 評価1件） |
| `npm run build` | 成功 |
| 変更を戻した検査 | 作業用コピーで指示、停止処理、報告の型、画面、既定スキルの各変更を戻すと対応する既存テストが失敗 |

画面の見た目は実画面で確認していない。
判断事項を含む API 応答は、認証経路を隔離した実データの用意ができず、実行していない。

## レビューの指摘と対応

### 設計のレビュー

セルフレビューと利用者向け文書にも判断を求める規則を適用し、人の指摘が混在する回と判断後に続く回を扱った。
承認済み文書の誤りにも3回目以降の例外を適用した。

### この PR の最初の提出

| 指摘 | 対応 |
| --- | --- |
| 同じ指摘が残る場合に案と判断事項が欠ける | 別の現れに限らず案と判断事項を求めた |
| 既定スキルの追加規則の検査が不足 | 既存の規則の検査を補った |
| 利用者向け文書の絞った再レビューで指示が矛盾 | 方針の観点を起動しない例外を指示と日英の仕様に反映した |
| 停止理由に日本語の固定文が混ざる | 識別用の印を表示理由から分けた |
| 停止理由の説明が解消不能の場合に限られる | 両方の停止条件に合う説明に日英の仕様と利用者向け文書を直した |

### この PR の再レビュー

| 指摘 | 対応 |
| --- | --- |
| 追加規則の検査が断片的 | 指示文書の文字列だけを検査するテストは追加しないとの依頼に従い、差分で確認する |
| 同じ指摘にも方針の見直しを求めている | 方針の見直しを別の現れに限った |
| 作業履歴に指摘ごとの対応と PR 番号がない | 対応を個別に記録し PR 番号を追記した |

## 残したこと

なし。
