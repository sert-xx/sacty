# タスク詳細の工程の設定を折りたたみ、費用の「概算」の印を見出しの補足にまとめる

- 日付: 2026-10-19（UTC）
- タスク: PBI-138
- PR: #150
- ブランチ: feat/issue-138-collapse-step-settings
- 関係する ADR: なし

## 目的

タスク詳細の「工程のイメージ」「工程のエージェント」は、基本的に変えないのに工程の数だけ行と変更のフォームが並び、場所を取っていた。
「工程ごとの費用」は、換算した費用のセルごとに「概算」の印（補足付き）が付き、表が読みにくかった（ステークホルダーの要望）。

## したこと

- 画面：「工程のイメージ」「工程のエージェント」を、見出し（補足の印を含む）だけの折りたたみにし、既定で閉じた（`StepSettings`）。
  候補を確かめられない・設定から消えた名前を使っているときは、見落とさないよう開いて出す。
- 画面：「工程ごとの費用」のセル（工程の行・合計・各回の内訳）から「概算」の印と補足を除き、換算値で実際の請求ではないことを見出しの
  補足に書いた。
- docs：仕様書（工程とタスク・作業履歴）と利用者向けの説明（タスク）。

## 確かめたこと

- `npx biome check`・`npm run typecheck`・`npx vitest run`・`npm run build` が通った。
- 既定で閉じること、候補を確かめられない・設定に無い名前（イメージ・エージェントそれぞれ）のときは開くこと、使えるエージェントを人が選んだ
  だけなら閉じたままのこと、費用のセルに「概算」が出ず見出しの補足に説明があることをテストにした。
- 次の修正を戻すと、テストが落ちることを確かめた：常に開く、イメージ・エージェントそれぞれで消えた名前を見ない・候補なしで開かない、
  セルに概算を戻す、見出しの補足から説明を消す。
- デモの環境で、見出しの補足の印を押しても開閉しないことを確かめた。
- デーモンのポーリング間隔は、実行待ちタスクの起動がすでに2秒ごとのため、ステークホルダーの判断で変えていない。
