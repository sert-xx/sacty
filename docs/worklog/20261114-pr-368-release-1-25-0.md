# 版を 1.25.0 に上げる

- 日付: 2026-11-14（UTC）
- タスク: なし
- PR: #368
- ブランチ: feat/release-1-25-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.24.1 の後に入った変更（PR #362〜#367）をリリースする。レビューの観点と指示（PR #366・#367）、要求要件・設計と `writing` の変更（PR #363）、タスク一覧のレビューの子タスクの並び（PR #365）は機能の追加なので MINOR を上げる。

## 1.24.1 からの変更

- 仕様書・ユーザードキュメント・図と、残っていた古いコードの文言を今の実装に合わせた（PR #362）。
- 要求要件・設計はスコープを最初に置き、人への確認に懸念を添え、`writing` に書き出し先ごとの改行と語の選び方を足した（PR #363）。
- PR のレビューの子タスクを、タスク一覧で親の下に並べた（PR #365）。
- 既定のレビューで直し方の方針を確かめ、同じ原因の指摘を1回で出し切る（PR #366）。
- PR のレビューで文書の照合を差分の範囲に絞り、観点を見きれなくても要修正があれば判定を出す（PR #367）。

## 互換性の判断

- 設定ファイル：差分は `config init` の雛形のコメントだけで、形は変わっていない。
- 台帳：新しい種類のイベントは足していない（`git diff v1.24.1` で `events.ts` の差分はコメントだけ）。投影でタスクに足した `earlierReviews` は、読み込みのときに作る値なので、1.24.1 に戻しても作業履歴は読める。
- 既定のコンテキストのスキルと工程の指示が変わることを、リリースの説明の注意に書く。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.25.0` にし、`package-lock.json` の版の行を直した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.25.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.24.1 の版上げ（PR #361）と同じ範囲。置き換えは前後に数字・`.` が無い `1.24.1` だけにし、ADR・作業履歴は対象から外した。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` は、`Dockerfile` に固定したもの（`sha256:5df79989…`）と同じだったので変えていない。1.24.1 の後に `packages/cli/docker` の変更は無い。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通過。
- `npx vitest run --no-file-parallelism`（`tests/docs` を含む）：1 件のほかは通過（件数は PR の本文に書く）。落ちた画面のテスト（`menus.browser.test.ts`）は、そのファイルだけを3回流すと3回とも通った。
- 消した行と足した行を比べ、版の違いのほかに差分が無いことを確かめた。
