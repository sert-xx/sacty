# 版を 1.22.1 に上げる

- 日付: 2026-11-10（UTC）
- タスク: なし
- PR: #337
- ブランチ: feat/release-1-22-1
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.22.0 の後に入った修正（PR #336）をリリースする。機能の追加は無いので PATCH を上げる。

## 1.22.0 からの変更

- npm のグローバルの場所のパスに UUID の形の文字列があっても、`npm run cli:install` が誤って失敗しないようにした（PR #336）。

## 互換性の判断

- 設定ファイルの形・コマンドの引数・作業履歴・HTTP API に、互換性の無い変更は無い。新しい種類のイベントは無いので、1.22.0 に戻しても作業履歴は読める。

## したこと

- 5 つのパッケージとワークスペースの依存の版を `1.22.1` にし、`package-lock.json` を `npm install --package-lock-only` で作り直した（差分は版の行だけ）。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.22.1` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.22.0 の版上げ（PR #335）と同じ範囲。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` が `Dockerfile` の値（`sha256:add5c17c…`）と同じだったので、変えていない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：通過。
- `npx vitest run --no-file-parallelism`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- `git grep -F 1.22.0` で、ADR・作業履歴のほかに `1.22.0` が残っていないことを確かめた。
- `Dockerfile`・`agent-cli` は変えていないので、イメージのビルドはやり直していない。

## レビューの指摘と対応

- なし。

## 残したこと

- PR をマージした後の、タグ `v1.22.1` と GitHub Release の作成。
