# 版を 1.18.0 に上げる

- 日付: 2026-11-04（UTC）
- タスク: なし
- PR: #308
- ブランチ: feat/release-1-18-0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.17.0 の後に、既定の review スキルの段階を変える変更が入った（PR #307）。設定ファイルの形・台帳・コマンドの引数を壊す変更は無い。修正だけではなく既定の振る舞いが変わるので MINOR を上げ、1.18.0 をリリースする。

## 1.17.0 からの変更

- 横断の観点 X-1 の段階を `ultimate` から `expert` にした（PR #307）。既定の観点・工程のどれも `ultimate` を使わなくなる。
  X-1 のモデルは gpt-6-astra・claude-fable-5-1 の low から、gpt-6.1-sol・claude-opus-5-5 の high に変わる。
- `ultimate` の段階と `codex_ultimate`・`claude_ultimate` は残る。`step_agents` やタスクの工程のエージェントで人が選べば使える。
- 互換性：イベント・依存の変更は無い。1.17.0 の作業履歴はそのまま読める。
- 更新の後にすること：`npm ci` で依存を入れ直し、既定のイメージの名前が `sacty-agent:1.18.0` に変わったので、`npx sacty image build` で作り直す。

## したこと

- 5 つのパッケージ（`@sacty/core`・`@sacty/daemon`・`@sacty/web`・`@sacty/cli`・`apps/desktop`）とワークスペースの依存の版を `1.18.0` にし、
  `package-lock.json` の版の行も同じにした。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.18.0` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.17.0 の版上げ（PR #306）と同じ範囲。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest`（インデックス）が、`packages/cli/docker/Dockerfile` の
  `BASE_IMAGE`・`NODE_IMAGE` のダイジェストと同じだった（`sha256:bc0a2afd…`）ので、更新していない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は上げていない。

## 確かめたこと

- `npm ci`・`npm run lint`・`npm run typecheck`：通過（`npm ci` の後の `package-lock.json` の差分は版の行だけ）。
- `npx vitest run`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- `git grep -F 1.17.0` で、ADR・作業履歴のほかに `1.17.0` が残っていないことを確かめた。
