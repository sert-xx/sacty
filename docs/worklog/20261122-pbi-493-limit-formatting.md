# 実装の整形対象を変更したファイルに限る

- 日付: 2026-11-22（UTC）
- タスク: PBI-493
- PR: なし
- ブランチ: main
- 関係する ADR: [実装の整形対象を変更したファイルに限る](../adr/20261122-2259-limit-implementation-formatting.md)

## 目的

依頼と関係ない整形だけの差分を減らす。

## したこと

実装と直しの指示に整形の範囲を加え、日英の仕様書を合わせた。

## 原因の調査

対象 PR の担当のセッションログは得られず、実際に使ったコマンドは特定できなかった。
PR #539 では行幅 100 に収まる型が複数行に展開されている。
以前の調査では、リポジトリの設定が見つからない場所で同じ入力を整形すると、既定の設定で折り返されることを再現している。
設定を読まない整形、別のツールや版、またはリポジトリ全体への整形が原因の候補だが、いずれも確定していない。
このリポジトリの `npm run format` は全体を対象にする。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm test` | 成功。追加した整形の指示のテストは 3 件 |
| `npm run build` | 成功 |

指示を取り除くと追加した 3 件が失敗することを確かめた。
文書検査を別のテストと同時に実行した際、2 件が時間切れになった。
