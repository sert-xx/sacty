# リスク評価の判断材料と人間への確認依頼を見分けやすくする

- 日付: 2026-11-21（UTC）
- タスク: なし

- 関係する ADR: [リスクの判断材料と人間への確認依頼を独立した Alert に分ける](../adr/20261121-0345-risk-assessment-alerts.md)

## 目的

人がレビューの深さと確認すべき点を判断しやすいよう、共通レンダラーの Markdown を整理する。

## したこと

- 段階別 Alert、重点確認の TIP、枠外の検証情報と注記を描画する。
- 評価記録のコミット・対象ホストを保つリンクを生成し、特殊文字をエンコードする。不正な位置情報はテキストにする。
- 過去の記録の改行を含むすべての枠内行を引用する。
- 生成指示の why に理由と人間への確認依頼を求め、日英の仕様書・利用者向け説明を更新する。
- 最新実装では通常・テンプレート PR 本文への掲載が廃止されているため、その仕様を維持する。現在の2つのコメント経路へ適用し、PR 本文が評価を出さない既存テストも維持する。

## 確かめたこと

- 主要な回帰テスト8件は、変更前の描画処理を入れた一時コピーでは8件とも失敗した。作業中のソースは戻していない。
- Node.js 26.13.1 で npm ci・npm run lint・npm run typecheck・npm run build は成功。
- 関連5テストファイルと tests/docs を --maxWorkers=2 で実行し、8ファイル・580件が成功。
- 全テストは --maxWorkers=2 で実行し、311ファイル・6,225件成功、既存ブラウザーテスト2件がタイムアウト、1件スキップ。そのブラウザーテストは単独再実行で2件とも成功。
- テストプロセスだけ GIT_CONFIG_COUNT=1・GIT_CONFIG_KEY_0=commit.gpgsign・GIT_CONFIG_VALUE_0=false を設定し、テストが作る一時コミットの署名を無効化した。初回は署名用ソケットへの接続に失敗し、無制限の並列実行では時間制限のある既存テストも失敗したため、並列数を制限して再検証した。
- Next.js ビルドと localhost・ブラウザーを使う全テストは、制限環境の外でこの作業用 clone を使って実行した。起動中のデーモンの生成物・設定は更新していない。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 不正な Unicode を含むパスでリンク生成が失敗し、投稿を止める | リンクにせず、記録の位置情報をテキストで出す。対になったサロゲートはエンコードする。 |
| 総評を短くしてから評価枠を足すと、投稿する本文全体が上限を超える | 評価枠と末尾の案内を確保し、総評を残りに収める。評価の詳細だけで収まらない場合はタスク画面へ案内する。 |

追加修正前の描画で、不正な Unicode の2ケースと長いレビュー本文の上限チェックが失敗することを確認した。修正後は関連8ファイル・583件、lint・型検査・ビルドが成功した。上限を超えていた長いレビュー例は、リンク5件と末尾の案内を保ちながら本文全体が60,000文字に収まった。

追加修正後の全テストは `npx vitest run --no-file-parallelism` で6,229件成功、1件スキップ、既存のタスク一覧ブラウザーテストの日本語1件がタイムアウト。`npx vitest run apps/web/src/components/task-list.browser.test.ts` を単独で実行しても日本語はタイムアウトし、英語は成功した。

## 残したこと

実際のエージェントの評価実行と GitHub によるコメント投稿は未確認。Web カードの表示は変更しない。
