# SECURITY.md の対象のバージョンを、リリースの運用に合わせる

## 目的

`SECURITY.md` の「対象のバージョン」に「まだリリースのバージョンを切っていません」と残っていた。1.0.0 から GitHub Releases で版を公開しているので、今の運用に合わせる。1.23.1 のリリースの確認で見つけた。

## したこと

- 「対象のバージョン」を、GitHub Releases で版を公開していること、修正は `main` に入れて次のリリースに含めること、対象は最新のリリースと `main` の最新だけでバックポートはしないこと、に直した。バックポートをしない方針は前の記述と同じ。
- 報告に書いてほしいことの「確かめた sacty のコミット」を「確かめた sacty の版（またはコミット）」にした。
- `SECURITY.md` には英語の版が無い（README の英語の版も「in Japanese」と案内している）ので、日本語だけを直した。
