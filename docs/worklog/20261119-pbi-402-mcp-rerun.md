# sacty mcp に、中止したタスクの再実行のツールを足す

- 日付: 2026-11-19（UTC）
- タスク: PBI-402
- PR: なし
- ブランチ: sacty/task-8a8a4bcb
- 関係する ADR: [sacty mcp の再実行は、画面の既定値のまま補足だけを足す最小の版にし、画面の既定値で送れないものは MCP の層で断る](../adr/20261119-1000-mcp-rerun-minimal-screen-defaults.md)

## 目的

手元の AI が、MCP だけで、中止したタスクを最初からやり直せるようにする。機能を1つずつ足す流れの8回目の前半（8a）。
ツール `rerun_task` を足す（15個から16個）。デーモンのサービス・API の入口・`@sacty/core`・画面は変えず、既存の `POST /api/tasks/:id/rerun` だけを呼ぶ。

## したこと

- `apps/daemon/src/task-mcp.ts`：`rerun_task` を足した（`cancel_task` の後ろ）。`SactyApi` に `rerun` を足した。
  再実行できるかの判定（`rerunBlock`）と、画面の既定値（`rerunDefaults`）を、要約の `canRerun`・`get_task` の `rerunBlocked`・ツールで共有した。要約に `canRerun`・`rerunBy`・`rerunOf` を足した。
  説明と `INSTRUCTIONS` に、新しいタスクが作られること・元のタスクは二度と再実行できないこと・引き継がないもの・頼まれたときだけ呼ぶこと・画面で行うことを書いた。`cancel_task` の説明・`CANCEL_IRREVERSIBLE`・使い方の文・差し戻せないときの文に、再実行への案内を足した。
- `packages/cli/src/mcp.ts`：`rerun`（`writeTask`）を足した。結果を受け取れなかったときの案内（`RERUN_UNCERTAIN`）と、リポジトリが原因の断りに画面で選び直せることを添える書き換えを足した。
- `packages/cli/src/index.ts` の使い方の表示、仕様書・ユーザードキュメント・`cli.md`・各 README の行（日英）、ADR、この作業履歴、`CONTRIBUTING.md` のテストの表。
- 新しいテスト：`packages/cli/src/mcp-rerun.test.ts`（本物のサービスと `createApp`・本物の `daemonApi` をつなぐ）。既存のテストは、ツール一覧を16個にした。

## 確かめたこと

- `npx vitest run packages/cli/src/mcp-rerun.test.ts apps/daemon/src/task-mcp`：作られるタスクの題・説明・リポジトリ（`source.repo` の優先・`repository.url` への代替・チケット由来でもリポジトリが決まっていれば再実行できること）、元の作業履歴、要約の欄、2回目の断り、送らずに断るもの、デーモンの断り（`task.repositoryUnknown` は選び直しを添え、`task.repositoryMissing` はデーモンの文のまま）、補足の長さ（CRLF を含む）、中止の歯止めの文、結果を受け取れないとき、説明の文を確かめた。`mcp-rerun.test.ts` は24件が通った。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 補足の長さを自前で数え、デーモンと食い違う | `RerunTaskInput.safeParse` に任せた。仕様書（日英）を直し、CRLF のテストを足した |
| `task.repositoryMissing` に選び直しの案内が付く | `task.repositoryUnknown` だけに付けた。説明・仕様書・ユーザードキュメントを合わせた |
| やり直しの断りから中止へ進む歯止めが無い | 断りの理由・説明・使い方の文に足し、テストで確かめた |
| 既存のテストの偽の API に `rerun` が無い | 足した |
| 英語版の数・`INSTRUCTIONS` の記述・前の試行の記録の読み・「気をつけること」 | 直した。使い方の文に再実行の段落を足した |
| `source.repo` などのテストが無い | 足した |
| 作業履歴にコマンドと結果が無い | 上に書いた |
| 中止したタスクへの `resume_task` の断りが再実行を案内しない | 中止したタスクは `rerun_task` への案内に分け、それ以外は元の文に戻した。テストを足した |
| 2回目を断る層・`rerunBlocked` の範囲の記述が実装と違う | 仕様書（日英）・ADR・ユーザードキュメント（日英）・ツールの説明・使い方の文・コメントを合わせた |
| 仕様書の日英の列挙がそろわない | 日本語版に、やり直しを頼まれただけでは中止しないことを足した |
| ブランチ欄が雛形のまま | 実際のブランチ名を書いた |

## 残したこと

- 題・説明を直しての再実行、作業するリポジトリ・イメージを変えての再実行。
- チケットから取り込み、リポジトリが決まっていないタスクの再実行。
- 完了したタスクからの続きの作成（派生）、エラーの分析・エラーレポート。
