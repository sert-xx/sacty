# 依頼外の整形だけの変更を提出前に検出する

- 日付: 2026-11-22（UTC）
- タスク: PBI-484
- PR: なし
- ブランチ: main
- 関係する ADR: なし

## 目的

依頼と関係のない整形だけのファイルが実装の PR に混ざり、差分の確認を膨らませることを防ぐ。

## したこと

提出前に起点と作業領域の構文を比較し、未申告の整形だけのファイルは担当に戻させる。
申告された整形と上限後に残った件数は、PR の本文とタスクの詳細に示す。

## 原因の調査

次のコマンドで、同じ Biome と同じ入力でも、リポジトリの設定を見つけられない場所では既定の設定で折り返されることを再現した。
最初の出力は1行のまま、次の出力は複数行に展開された。

```sh
biome_binary="$PWD/node_modules/.bin/biome"; sample='export type GitHubRepo = { url: string; host: string; owner: string; name: string; path: string };'; printf '%s\n' "$sample" | "$biome_binary" format --stdin-file-path example.ts; (cd "$(mktemp -d)" && printf '%s\n' "$sample" | "$biome_binary" format --stdin-file-path example.ts)
```

設定を見つけられない場所での整形は、観察された折り返しの原因になりうる。
対象の PR のエージェントのセッションログは得られず、実際に実行したコマンドは特定できなかった。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm test`（Git 2.51.2） | 7,164 件成功、1 件スキップ |
| `npm run build` | 成功 |

スキップは AI の評価テスト。
検出処理を一時的に外すと、実際の Git 作業領域を使うテストが、出し直しの記録を検出できず失敗した。
ビルドしたデーモンを空のホームとダミーの認証情報で起動し、`GET /api/tasks` が空の一覧と 200 を返すことを確認した。

## レビューの指摘と対応

### 設計の PR #580

差分の本文を作る処理は設けず、パスと戻す指示だけを担当に渡す。
受け付ける形でないパスとモードが変わったファイルは検査から外す。

### この PR のレビュー

申告理由を秘密値の伏せの後に切り詰め、実行前の準備失敗の後も起点を引き継ぐ。
連続するコメントの比較を線形にし、取り込み後の内容が提出時に残ることを確かめる。
利用者文書に検査の対象外を追記した。

## 残したこと

取り込みで変わったファイルや、対象外の言語の整形は検出しない。
