# 実装の最終レビュー（テストの実行）と CI の待ちをやめ、レビューの子タスクの指摘なしで承認待ちにする

- 日付: 2026-11-12（UTC）
- タスク: PBI-331
- PR: #348
- ブランチ: feat/issue-331-drop-final-review-and-ci-wait
- 関係する ADR: [実装の最終レビュー（テストの実行）と PR の CI の待ちをやめ、PR のレビューの子タスクの指摘なしでドラフトを外す](../adr/20261112-0714-review-child-task-replaces-final-review-and-ci-wait.md)

## 目的

実装の PR が、sacty によるテストの実行や CI の待ちの失敗で止まらず、PR のレビューの子タスクの指摘と修正を通って、指摘なしで人の承認（マージ）に回るようにする。

## したこと

- 台帳：`FinalReviewSkipped`（最終レビューと CI の待ちをせずに PR の作成へ進める）と `PullRequestMarkedReady`（子タスクの指摘なしでドラフトを外した）を足し、`PullRequestPublished` に `awaitingReview` を足した。
  `reviewedPullRequest`（依存のある子タスクが重ねられる PR）は、指摘なしを待つ PR を除く。
- デーモン：依存 `finalReview`（main.ts で false）を足した。false のときは次のとおり。
  - 実装の工程の後に `FinalReviewSkipped` を記録し、実装の PR をドラフトで作って承認待ちにし、レビューの子タスクを作る（ドラフトのまま）。直して更新したらドラフトに戻す。
  - PR の確認で、子タスクが今のコミットを指摘なしにしたらドラフトを外す（`markReady`）。CI は待たない・再実行しない。
  - 子タスクのレビューの準備で、先頭のコミットの CI の状態を読み、指示に渡す（`reviewCiOf`・`reviewCiLines`）。変更による失敗を要修正に、関係の無い失敗を人が確かめることにさせる。
  - 重ねた PR は、付け替えでドラフトを外さず、付け替えの後にレビューの子タスクを作る。
  - テストのコマンドが決まらなくても止めない。
  - PR の本文の結論は、最終レビューの行の代わりに「sacty のレビュー」の行にする。
  - 最終レビューの仕組みは、`finalReview` を有効にしたとき（既存のテスト）だけ動く形で残した（ゴールガーディアンの撤去と一緒に消す）。
- 画面：「レビューへ進める」の操作と、不安定なテストの台帳のカードを外した。関連するタスクの子タスクのリンクに、何回目と判定を添えた。作業履歴の文言を日英で足した。
- docs：仕様書（タスクと工程・承認・分割・監査）・ユーザードキュメント（タスク・取り込み・監査）を日英で直し、ADR を足して、最終レビュー・CI の待ち・不安定なテストを決めた ADR 5件を置き換え済みにした。台帳のスクリーンショットを外し、監査の画面を撮り直した。

## 確かめたこと

- `npm run lint`・`npm run typecheck`：エラーなし。
- `npx vitest run`：全体が通った。
- `npx vitest run tests/docs`：通った。
- 新しいテスト（`finalReview: false`）：
  - 実装の後に最終レビュー・テスト・CI の待ちをせず、ドラフトの PR と子タスクを作る。PR の確認で CI を読まない・再実行しない。
  - 子タスクが CI の結果（失敗・実行中）を指示で受け取り、指摘ありでは外さず、親が直して更新したら再レビューし、指摘なしでドラフトを外す。繰り返さない。再起動しても同じ状態。
  - ドラフトを外せなければ記録せず、次の確認でやり直す。
  - 最終レビュー・CI の待ちの途中だった古いタスクが、新しい流れに乗る。
  - テストのコマンドが決まらなくても止めない。
  - 依存先の PR のレビューが指摘なしになってから重ねて始め、重ねた PR は付け替えの後にレビューし、指摘なしで外す。
  - 画面：関連するタスクのリンクの回と判定（日英）。
- 修正を戻すと落ちることを確かめた：重ねられる PR の判定・付け替えでドラフトを外さないこと・指摘なしでドラフトを外すこと・テストのコマンドが無くても止めないこと。
