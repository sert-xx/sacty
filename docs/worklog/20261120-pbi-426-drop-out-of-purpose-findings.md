# PR のレビューの集約は、PR の目的の範囲の外の指摘を投稿しない

- 日付: 2026-11-20（UTC）
- タスク: PBI-426
- PR: なし
- ブランチ: なし
- 関係する ADR: [20261121-0100-drop-out-of-purpose-findings-in-pr-review.md](../adr/20261121-0100-drop-out-of-purpose-findings-in-pr-review.md)

## 目的

目的の外の求めが `[提案]` として投稿され、直しと再レビューの往復が増えていた。

## したこと

- 既定のスキルの `aggregation.md` に「PR の目的の範囲の外」の節と不採用の理由を足し、`pr-review.md` の総評に件数の1行と取り下げの書き方を足した。
- 仕様書（日英）・ユーザードキュメント（日英）・ADR を直した。自己レビューには当てない（理由は仕様書）。
- 重みを見直した前回の指摘は、元が `must` なので、この規則で落とさず今の規則で残す、と決めた。

## 確かめたこと

- `default-skills.test.ts` で、4つの決まりが配られることを確かめた。

## 残したこと

- デーモンの指示（`prompts.ts`）には要点を重ねていない（デーモンのコードの変更は範囲外）。スキルを差し替えたプロジェクトでは、この決まりは効かない。
