# 版を 1.18.1 に上げる

- 日付: 2026-11-06（UTC）
- タスク: なし
- PR: #313
- ブランチ: feat/release-1-18-1
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.18.0 の後に入った修正（PR #311）と、既定のイメージのエージェントの CLI の更新（PR #312）をリリースする。機能の追加は無いので PATCH を上げる。

PR #311 には、git で取得した層の `extends` の書き方を狭める変更がある。互換性の無い変更は MAJOR の決まりだが、セキュリティの修正で影響の範囲が狭いので、ステークホルダーの判断で PATCH のままにし、リリースの説明の互換性の節に書く。

## 1.18.0 からの変更

- セキュリティチェックの指摘のうち、今の main で再現するものの修正（PR #311）。
- 既定のイメージの Claude Code を 2.1.318、Codex を 0.167.0 に更新（PR #312）。
- 互換性：git で取得した層の `extends` で、`file://`・`./`・`../` で始まらない相対パス・`host:path`（ユーザー名の無い形）が止まる（PR #311）。
- 更新の後にすること：`npm ci` で依存を入れ直し、既定のイメージの名前が `sacty-agent:1.18.1` に変わったので、`npx sacty image build` で作り直す。

## したこと

- 5 つのパッケージ（`@sacty/core`・`@sacty/daemon`・`@sacty/web`・`@sacty/cli`・`apps/desktop`）とワークスペースの依存の版を `1.18.1` にし、
  `package-lock.json` の版の行も同じにした。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.18.1` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.17.1 の版上げ（PR #308）と同じ範囲。
- 元のイメージのダイジェスト：`docker buildx imagetools inspect node:26-bookworm-slim` の `Digest` が `Dockerfile` の値（`sha256:add5c17c…`）と同じだったので、変えていない。
- エージェントの CLI の版（`packages/cli/docker/agent-cli`）は、PR #312 で上げたので、この PR では変えていない。

## 確かめたこと

- `npm ci`・`npm run lint`・`npm run typecheck`：通過（`npm ci` の後の `package-lock.json` の差分は版の行だけ）。
- `npx vitest run`（`tests/docs` を含む）：通過（件数は PR の本文に書く）。
- `git grep -F 1.18.0` で、ADR・作業履歴のほかに `1.18.0` が残っていないことを確かめた。
- `Dockerfile`・`agent-cli` は PR #312 から変えていないので、イメージのビルドはやり直していない。
