# 版を 1.1.0 に上げ、GitHub Release を作る

- 日付: 2026-10-20（UTC）
- タスク: なし
- PR: なし
- ブランチ: chore/release-1.1.0
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.0.0 の後に、更新の知らせを GitHub Releases の最新の版で判断する変更（PR #164、PBI-147）が入った。新しい仕組みは 1.0.0 より新しいリリースが出て
初めて働くので、機能の変更として MINOR を上げ、1.1.0 をリリースする。

## したこと

- 4 つのパッケージとワークスペースの依存の版を `1.1.0` にし、`package-lock.json` を `npm install --package-lock-only` で更新した。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.1.0` にし、仕様書（`agent-execution`・`configuration`）・ユーザードキュメント（`config`・`images`）の日英と、
  イメージの名前を書いているテストを同じ版にした。ゲートウェイの MCP クライアントの版の文字列も `1.1.0` にした。
- 更新の知らせのテスト（`update-check.test.ts`・画面のテスト）の版は、比べ方を確かめるための値なので変えていない。

## 確かめたこと

- `npm run lint`・`npm run typecheck`・`npm run build`：通過（`apps/daemon/dist/config.js` の `DEFAULT_IMAGE` が `sacty-agent:1.1.0`）。
- `npx vitest run`：119 ファイル・2332 件が通過。
- 実際のイメージの作り直しと、1.0.0 の画面に 1.1.0 の知らせが出ることは、リリースの後に運用の環境で確かめる。
