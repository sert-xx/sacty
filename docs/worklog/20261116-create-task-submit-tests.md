## 目的

欄の追加と削除が、作成時にデーモンへ送る入力に反映されることを確かめる。

## したこと

日英のフォーム操作から実際の作成アクションを呼び、リポジトリの件数とテンプレートの空欄を確かめるテストを追加した。

## 確かめたこと

`npm run lint`、`npm run typecheck`、`npx vitest run`、`npm run build` を実行した。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 削除後の送信が画面操作から検証されていない | 欄の増減と送信をつなげたテストを追加した |
