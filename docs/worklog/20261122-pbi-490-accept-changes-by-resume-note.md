# 再開の補足で許した申し出を受け入れる

- 日付: 2026-11-22（UTC）
- タスク: PBI-490
- PR: なし
- ブランチ: main
- 関係する ADR: [再開の補足で許した申し出を受け入れる](../adr/20261122-2239-accept-changes-by-resume-note.md)

## 目的

再開の補足で人が許可した成果物の変更を、人の再判断を待たずに反映する。

## したこと

再開時の許可、補足に基づく申し出の受け入れ、設計とテスト観点の合わせ直し、履歴と申し出の一覧への表示を追加した。
MCP と画面に許可の指定を追加し、旧版のデーモンには許可付きの再開を送らない。

## 確かめたこと

| コマンド | 結果 |
| --- | --- |
| `npm run lint` | 成功 |
| `npm run typecheck` | 成功 |
| `npm test` | 7,163 件成功、14 件スキップ |
| `npm run build` | 成功 |
| 自動受け入れの条件を一時的に無効にして対象テストを実行 | 設計が置き換わらず、対象テストが失敗した |
| ビルド済みの `sacty mcp` から `resume_task` を呼び出す | 認証情報と接続先の無い環境で、デーモンが見つからないため再開せずに断られた |

スキップの内訳は、Git の `merge-tree --merge-base` に対応しない環境での 13 件と、明示的に有効化する AI 評価 1 件。

実際の工程を使う画面確認は、この環境に Docker がないため実行していない。

## レビューの指摘と対応

要求要件を変更するとき、承認済みの設計とテスト観点も必要な範囲で合わせ直す。
旧版のデーモンには許可を失って再開しないようにする。
読めない申し出と不完全な観点を検出し、実装履歴と設計の検証記録の扱いを修正する。
