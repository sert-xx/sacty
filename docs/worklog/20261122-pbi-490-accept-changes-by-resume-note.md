# 再開の補足で許した申し出を受け入れる

- 日付: 2026-11-22（UTC）
- タスク: PBI-490
- PR: #596
- ブランチ: main
- 関係する ADR: [再開の補足で許した申し出を受け入れる](../adr/20261122-2239-accept-changes-by-resume-note.md)

## 目的

再開の補足で人が許可した成果物の変更を、人の再判断を待たずに反映する。

## したこと

再開時の許可、補足に基づく申し出の受け入れ、設計とテスト観点の合わせ直し、履歴と申し出の一覧への表示を追加した。
MCP と画面に許可の指定を追加し、旧版のデーモンには許可付きの再開を送らない。

## 確かめたこと

| コマンド・方法 | 結果 |
| --- | --- |
| `npx vitest run apps/daemon/src/daemon-steps.test.ts -t '許可中に\|複数の却下\|許可した補足に沿う\|不正な申し出'` | 対象の 9 件が成功 |
| 自動受け入れの条件を一時的に無効にして対象テストを実行 | 要求要件が置き換わらず、対象テストが失敗した |
| ビルド済みの `sacty mcp` から許可付きの `resume_task` を呼ぶ | 認証情報と接続先の無い環境で、デーモンが見つからないため再開せず断られた |

実画面での確かめと動画の記録は、マージ前に承認の代理が人として行う。

## レビューの指摘と対応

### 要求要件・設計

要求要件を変更するとき、承認済みの設計とテスト観点も必要な範囲で合わせ直す。
旧版のデーモンには許可を失って再開しないようにする。

### 実装のレビュー 1 回目

読めない申し出と不完全な観点を検出し、実装履歴と設計の検証記録の扱いを修正した。

### 実装のレビュー 2 回目

申し出の必須項目と付属情報を検証し、不正な申し出を自動反映・提出しない。
許可中の申し出を却下したら成果を作り直し、一時停止や再起動後も却下の判断を引き継ぐ。
設計を自動更新したときは、今回の実装のテスト対応だけを残す。
日英の文書には、設計とテスト観点の差分を表示する条件を明記した。

### 実装のレビュー 3 回目

許可中の申し出の有無の申告を検証し、申告を読めない場合や申し出と食い違う場合は提出せず停止する。
却下した変更を成果の確定まで保持し、後続の実行に渡す。

## 残したこと

実画面での一連の操作と動画の記録は、マージ前に承認の代理が人として行う。
MCP の対応確認後、再開要求の前にデーモンが旧版へ切り替わる競合は今回の範囲外とする。
