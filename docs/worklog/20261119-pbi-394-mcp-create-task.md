# sacty mcp にタスクの作成を足す

- 日付: 2026-11-19（UTC）
- タスク: PBI-394
- PR: #434
- ブランチ: sacty/task-643d19c2
- 関係する ADR: [sacty mcp のタスクの作成は、画面の既定（対象リポジトリ空欄・進め方「自動」）と同じ要求を送り、結果を受け取れなかったときは作られた可能性を返す](../adr/20261119-0100-mcp-create-task-like-screen-with-uncertain-result.md)

## 目的

手元の AI から、プロジェクトを指定して、題と説明でタスクを作れるようにする。画面の「タスクを作成」（テンプレートなし・対象リポジトリ空欄・進め方「自動」）と同じ結果にする。
`sacty mcp` に機能を1つずつ足す流れの1回目。承認・成果物とログの取得などと、作成のときのテンプレート・対象リポジトリ・進め方の指定は、後で決める。

## したこと

- `apps/daemon/src/task-mcp.ts`：ツール `list_projects`（読み取りだけ。id・名前・対象）と `create_task`（`project_id`・`title`・`body`）を `TOOLS` に足した。`SactyApi` に `listProjects`・`createTask` を足した。
  サーバーの使い方の説明にも作成の流れを足した。
- `packages/cli/src/mcp.ts`：`GET /api/projects`・`POST /api/tasks`（`repo: null`）を呼ぶ。結果を受け取れなかったときは、作られた可能性（`CREATE_UNCERTAIN`）を添える。
  デーモンの `invalid_input`（400）の理由も文にする。
  題・説明の長さの検査は、前後の空白を除いてから `CreateTaskInput` の1か所で行う（引数の形は、`title`・`project_id` が空でないことだけ）。
  「作られている可能性」の案内は、時間切れ・切断・読めない本文・5xx に付け、401・接続拒否・5xx 以外の断り・送る前の失敗は理由だけを返す。
- `packages/cli/src/index.ts`：`sacty mcp` の使い方の表示に、プロジェクトの一覧とタスクの作成を足した。
- 仕様書・ユーザードキュメント（日英）・ADR。

## 確かめたこと

- `apps/daemon/src/task-mcp.test.ts`：本物のサービスと API に対して、作る（画面と同じ要求で作ったタスクと同じ項目・同じ記録、返った ID での `get_task`）、
  プロジェクトの一覧（消したプロジェクトが出ない）、断られる（無い・消したプロジェクト、空の題、長すぎる題・説明で、何も作らない）、結果を受け取れない（標準エラーに題・説明を出さない）。
- `packages/cli/src/mcp.test.ts`：送る要求（`repo: null`）、断られた理由、時間切れ・切断・読めない本文のときの作られた可能性、送る前の失敗。401・接続拒否（理由だけ）と 5xx（案内を付ける）。失敗の扱いのテストに `list_projects`・`create_task` を足した。上限ちょうどと、前後の空白で生の長さが上限を超える題・説明。
- 実機の確認（`sacty up` と `sacty mcp`）と、Claude Code・Codex の実物での確認はしていない。

## レビューの指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 題・説明の上限を空白を除く前の長さで断っている | `max` を外し、長さの検査を `CreateTaskInput` の1か所にした。上限ちょうどと空白付きのテストを足した |
| 401・接続拒否にも「作られている可能性」を付けている | 案内を時間切れ・切断・読めない本文・5xx に絞り、401・接続拒否は理由だけにした。テストを足した |
| 失敗系のテストに新しい2ツールが無い | `list_projects`・`create_task` を足した |
| 5xx の扱いが、仕様書・ADR・ユーザー文書とコードで食い違う | `rereview_task` の節から追記を戻し、`create_task` の節・ADR・ユーザー文書（日英）をそろえた |
| `sacty` の使い方の表示が古い | `sacty mcp` の説明に2ツールを足した |
| 仕様書の「関係する ADR」に今回の ADR が無い・長さの検査の記述が実際と違う | ADR へのリンクを足し、引数の形の検査の記述を実際に合わせた（日英） |

## 残したこと

- 承認・成果物とログの取得など、MCP の後続の機能。
