# タスクの作成のダイアログで、書きかけを失わないようにする

- 日付: 2026-11-21（UTC）
- タスク: PBI-427
- PR: なし
- ブランチ: なし
- 関係する ADR: なし

## 目的

「タスクを作成」のダイアログを閉じても、書きかけの題と内容を失わないようにし、内容の欄を広げる。

## したこと

- 書きかけの題・内容を、`NewTaskDialog` の状態に持つ（閉じると欄は外れるが、この部品は残る）。開き直すと、欄の初期値に戻す。確認のダイアログは足していない。
- 部品は、提案から開くものとふつうのものが別で、プロジェクトごとに `key` で作り直すので、書きかけは混ざらない。提案から開くものは、最初に提案の題・内容が入る。
- 作成に成功したら空に戻す（`redirect` の例外と、戻り値に理由が無いとき）。失敗したときは残す。
- 内容の欄は、12 行分の高さ以上で縦に広げられるようにし、ダイアログの幅は広い画面で 768px にした。スケジュールタスクの欄は変えていない（`bodyClassName` で分けた）。
- 下書きは、ブラウザーのメモリーにだけ持つ。再読み込みの後は残さない（秘密を含みうる依頼文を、保存の場所に置かないため）。
- 仕様書・利用者向け文書（日英）と、スクリーンショット（`new-task`・`new-task-steps` の日英）を直した。

## 確かめたこと

- 4つの閉じ方のそれぞれ、空のとき、成功の後、失敗の後、提案とふつうの混ざり、プロジェクトごとの分けを、`new-task-draft.test.ts` で確かめた。
