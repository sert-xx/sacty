# フォーム本文によるメソッド上書きを拒否する

- 日付: 2026-11-13（UTC）
- タスク: なし
- PR: なし
- ブランチ: main
- 関係する ADR: なし

## 目的

フォーム本文のメソッド上書きによって、組織内 PF の許可リストを越える操作を防ぐ。

## したこと

URL エンコード形式と multipart 形式のフォームを検査し、メソッド上書きの名前があれば転送せずに拒否する。
`identity` 以外の `Content-Encoding` を指定したフォームと解析できない multipart と名前にバックスラッシュ、本文に `name*=`、または同じパートに重複した名前属性や Content-Disposition を含む multipart も拒否する。
仕様書とユーザードキュメントを日英とも更新した。

## 確かめたこと

`npx vitest run apps/daemon/src/gateway.test.ts tests/docs` で回帰テストと文書の検査が通った。
回帰テストは修正前のコードで `_method=DELETE` が転送されて失敗することを確かめた。

## レビューの指摘と対応

通常の multipart の転送テストを足し、名前の解釈差と多数のフォーム項目によるメモリー使用に対処した。

## 残したこと

なし。
