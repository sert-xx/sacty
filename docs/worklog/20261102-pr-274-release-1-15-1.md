# 版を 1.15.1 に上げる

- 日付: 2026-11-02（UTC）
- タスク: なし
- PR: #274
- ブランチ: feat/release-1-15-1
- 関係する ADR: [版は 1.0.0 から semver で付け、タグと GitHub Releases でリリースする](../adr/20261019-2345-semver-releases.md)

## 目的

1.15.0 の後に、セキュリティチェックの指摘の修正が入った（PR #273）。機能の追加や、設定ファイルの形・台帳・コマンドの引数を変える変更は無いので
PATCH を上げ、1.15.1 をリリースする。

## 1.15.0 からの変更

- 依存の脆弱性（PR #273）：デスクトップアプリのパッケージ作成が使う `@electron/asar` の下の `glob`（GHSA-3g3m-2fjr-6pw4）と
  `minimatch`（GHSA-g3hv-75wg-m249）を、npm の overrides で修正版（14 系・11 系）にした。
- 既定のイメージの入力の固定（PR #273）。
  - 元のイメージ（`node:26-bookworm-slim`）をダイジェストで固定した。
  - エージェントの CLI（claude・codex）を、専用の lockfile のとおりに入れる。
  - osv-scanner・gitleaks のハッシュを、スクリプトの中に固定した。
- 仕様書の構成の説明を、デスクトップアプリを含む 5 つのパッケージにした（PR #273）。
- 更新の後にすること：`npm ci` で依存を入れ直し、既定のイメージの名前が `sacty-agent:1.15.1` に変わったので、`npx sacty image build` で作り直す。
  元のイメージは固定したダイジェストのものになり、`docker pull` では変わらない（[イメージ](../user/images.md)）。

## したこと

- 5 つのパッケージ（`@sacty/core`・`@sacty/daemon`・`@sacty/web`・`@sacty/cli`・`apps/desktop`）とワークスペースの依存の版を `1.15.1` にし、
  `package-lock.json` の版の行も同じにした。
- 既定のイメージの名前（`DEFAULT_IMAGE`）を `sacty-agent:1.15.1` にした。
  同じ版にしたもの：仕様書（`agent-execution`・`configuration`）とユーザードキュメント（`config`・`images`）の日英、イメージの名前を書いているテスト・コメント、ゲートウェイの MCP クライアントの版の文字列。
  直したファイルは、1.15.0 の版上げ（PR #272）と同じ範囲。

## 確かめたこと

- `npm ci`・`npm run lint`・`npm run typecheck`・`npm run build`：通過（`npm ci` の後の `package-lock.json` の差分は版の行だけ）。
- `npx vitest run`（`tests/docs` を含む）：181 ファイル（3383 件）がすべて通過。
- `git grep -F 1.15.0` で、ADR・作業履歴のほかに `1.15.0` が残っていないことを確かめた。
