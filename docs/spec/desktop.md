# デスクトップ版

macOS 向けの提案用アプリ。既存の CLI を別プロセスで動かし、既存の画面を Electron で表示する。

## 起動と終了

アプリは二重起動を防ぎ、準備画面で Docker と GitHub CLI の接続を確認する。設定が無ければ CLI で雛形を作る。既存の設定を読み、必要なイメージを調べる。不足時は同梱manifestの名前とCPUが一致するイメージだけアーカイブを読み込み、再確認する。独自イメージだけが不足していても標準イメージを読み込まない。カスタムイメージが不足していれば理由を出す。

CLI の起動後、認証 URL を取得し、画面の HTTP 応答を最大60秒待ってから専用ウィンドウを開く。起動に失敗したら起動した CLI を停止し、再試行できる。終了時は既存 CLI の停止処理を呼び、最大35秒待つ。画面の認証を無効にした設定は受け付けない。停止中の終了要求はすべて保留し、停止完了後の終了だけを許可する。停止に失敗した場合は案内を出し、再試行できる。

コード: `apps/desktop/main.cjs`、`apps/desktop/runtime.cjs`

## イメージの更新

設定の `image` が過去の標準イメージなら、切り替え先を表示して利用者に確認する。標準のリポジトリ名と3要素の数値の版が一致する形だけを対象とし、独自の名前・レジストリ・タグや将来の版は変更しない。

確認後、現在のイメージの存在を確認し、不足時は同梱版を読み込む。それから元の設定を権限600のバックアップに保存し、YAMLのコメントと他の項目を保って名前だけを変更する。取り消し・イメージ読み込み失敗では設定を変更しない。確認後に設定が編集された場合も上書きしない。更新前後のYAMLの値を比較し、最上位の `image` 以外が変わる場合はバックアップや一時ファイルを作る前に拒否する。YAMLアンカーの共有参照先が変わる場合も、この検査で拒否する。

コード: `apps/desktop/config-tool.mjs`、`apps/desktop/runtime.cjs`

## 言語と文言

準備画面はOSの言語に従い、選択済みの `sacty-lang` があればそちらを使う。日本語と英語を選択でき、既存Webと同じHttpOnly cookieで1年間保存し、ディスクへ書き出してメイン画面にも引き継ぐ。文言は日英の辞書で持ち、製品名・本文と補足・長さを検査する。補足は印にマウスを乗せるかフォーカスすると表示し、Escや外側の操作で閉じる。

コード: `apps/desktop/messages.cjs`、`apps/desktop/preferences.cjs`、`apps/desktop/setup.js`、`tests/desktop/messages.test.ts`

## 認証と権限

準備画面だけに限定した IPC を公開し、送信元を検査する。API キーは固定のキーチェーンサービスに保存する。キーをプロセスの引数に渡さず、入力を検査して標準入力で渡す。キーは画面から消し、ログに残さない。保存処理の標準エラー出力を最大64KiBまで蓄積し、標準入出力が閉じる `close` イベントで終了コードと全文のエラー表記を確認する。終了通知後の出力やチャンクをまたぐ表記も対象にする。出力が上限を超えた場合は、判定に必要な出力が欠けるため失敗として扱う。

画面のウィンドウには preload を付けない。両方のウィンドウで Node.js 統合を無効にし、コンテキスト分離とサンドボックスを有効にする。メイン画面の同じオリジン・メインフレームからの通知だけを許可する。通知のオン・オフは既存の設定画面を使い、OSの通知許可は別途必要になる場合がある。その他の権限要求、別ウィンドウ、外部への画面遷移を拒否する。メイン画面の外部リンクは、認証情報を含まない HTTP/HTTPS URL だけを既定ブラウザーへ渡す。リダイレクトでは外部ブラウザーを開かない。ヘルプは選択した言語の固定 URL を開く。

コード: `apps/desktop/main.cjs`、`apps/desktop/preload.cjs`、`apps/desktop/runtime.cjs`、`apps/desktop/links.cjs`、`apps/desktop/permissions.cjs`

## パッケージ

同じ CPU 向けの Electron、作成時の Node.js とライセンス、ビルド済みコード、実行用の依存、既定イメージの圧縮アーカイブを同梱する。既定エージェント定義の `config/agents.yaml` も含める。完成品のリンクは同梱範囲内の相対リンクに直し、作成時の一時フォルダに依存させない。リンクが同梱範囲外に解決される場合や定義ファイルが無い場合は作成を失敗させる。イメージは作成済みのローカルイメージから取り出す。ビルド時にホストの設定・キー・作業履歴はコピーしない。署名・公証・自動更新・イメージの公開は行わない。

コード: `apps/desktop/scripts/package.mjs`、`apps/desktop/scripts/start.mjs`、`apps/desktop/packaging.cjs`

完成品から DMG を作成できる。アプリの相対リンクを保ったままコピーし、Applications フォルダへのリンクとともに圧縮ディスクイメージへ格納する。署名・公証は追加しない。

コード: `apps/desktop/scripts/dmg.mjs`
