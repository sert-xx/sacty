# スケジュールタスク

決めた内容のタスクを、決めた予定（毎日・毎週・毎月）で自動で作れます。
依存関係の定期的な更新や、毎週の確認など、繰り返す作業に使います。
タスクの作り方は [タスクを進める](tasks.md) を先に読んでください。

## スケジュールタスクを作る

1. サイドメニューの「スケジュール」を開きます。
   表示しているプロジェクトのスケジュールタスクの一覧が出ます。
2. 「スケジュールタスクを作成」を押します。
3. 次の項目を入力し、「作成する」を押します。

| 項目 | 内容 |
| --- | --- |
| 名前 | 一覧に出す名前（100 文字まで） |
| 有効にする | 外すと、止めた状態で作ります |
| 繰り返し | 毎日・毎週・毎月 |
| 時刻 | タスクを作る時刻（Sacty を動かしている PC の時刻） |
| 曜日 | 毎週のときに、1つ以上選びます |
| 日 | 毎月のときの日（1〜31）。その月に無い日（31 日など）は、月の最後の日に作ります |
| 作るタスク | 「タスクを作成」と同じ項目です（テンプレート・対象リポジトリ・進め方・タイトル・内容） |

作るタスクの内容は、保存するときに「タスクを作成」と同じように確かめます。
対象リポジトリがプロジェクトの対象に無いなど、作れない内容なら、理由が出て保存されません。

## PC が止まっていたとき

Sacty は PC の上で動くので、予定の時刻に PC が止まっていたり、スリープしていたり、ネットにつながらなかったりすることがあります。
その場合は、次のように動きます。

- Sacty が動いていて、ネットにつながるようになったとき（起動した後と、その後は1分ごとに確かめます）に、まだ作っていない直前の予定の分のタスクを作ります。
- 予定を何回逃していても、作るのは直前の1回分だけです。
  逃した回の数だけタスクを作ることはありません。
- 同じ予定の回のタスクを、二重に作ることはありません。
- スケジュールタスクを作る前・止めていた間の予定の分は、さかのぼって作りません。

## 編集・停止・削除

一覧の名前を押すと、詳細が開きます。

- 「編集」で、名前・予定・作るタスクの内容・有効かどうかを変えられます。
  予定を変えたときと、止めていたものを有効に戻したときは、そのときより後の予定から数えます。
- 「削除」で消せます。
  作ったタスクは残ります。
- プロジェクトを削除すると、そのプロジェクトのスケジュールタスクも消えます。

## 作ったタスクを見る

詳細の「作ったタスク」に、このスケジュールタスクが作ったタスクが新しい順に出ます。
予定の時刻・工程・状態がわかり、題を押すとタスクの詳細が開きます。
タスクの一覧では、開始地点が「スケジュールタスク」と出ます。

前回の予定でタスクを作れなかった（プロジェクトの対象を変えたなど）ときは、詳細に理由が出ます。
内容を直して保存すると、次の予定から作ります。
