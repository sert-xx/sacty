# 語と言い回し

日本語の文章で使う語と言い回しの選び方。
例の「悪い例」は、決まりを破った形をわざと書いている。

## 英語を単純に置き換えない

英語の語を、辞書の訳語に1対1で置き換えない。
その分野の日本語の文章で一般に使われている語を使う。

- カタカナで定着している語は、そのまま使う
- 日本語の語が定着しているなら、日本語の語を使う
- どちらが一般的か迷ったら、対象のリポジトリやその分野の日本語の文書で使われている方に合わせる

| 英語 | 悪い例 | 直した例 |
| --- | --- | --- |
| entry point | 入口 | エントリーポイント |
| endpoint | 終点 | エンドポイント |
| deploy | 配備する | デプロイする |
| cache | 一時保存 | キャッシュ |
| repository | 保管庫 | リポジトリ |
| trade-off | 交換条件 | トレードオフ |
| test case | 試験事例 | テストケース |

## 一般的な言い回しを使う

英語の構文をなぞった言い回しや、その文章の中だけで通じる言い回しを使わない。
読む人がふだん目にする言い回しにする。

| 悪い例 | 直した例 |
| --- | --- |
| PR を開く（open a PR） | PR を作成する |
| テストが壊れる（tests break） | テストが失敗する |
| コメントに対処する（address the comment） | 指摘に対応する |
| 意味を成す（make sense） | 筋が通る、妥当だ |
| 箱から出してすぐ使える（out of the box） | 設定なしで使える |
| 〜することができる（can） | 〜できる |

悪い例

```text
この PR は、新しい入口を導入します。
変更は、既存のテストを壊しません。
```

直した例

```text
新しいエントリーポイントを追加しました。
既存のテストはすべて成功します。
```

対象のリポジトリが用語を決めている（用語集、既存の文書でそろえている）ときは、その用語を使う。
