# 読みやすく簡潔な文章を書く

人が読む文章を書くときの決まり。
読む人が、確かめる手間をかけずに中身をつかめる文章を目指す。
主な対象は日本語の文章で、英語の扱いは下の「英語の文章」に書く。

## 何より先に従うもの

次の順に従う。
上のものと食い違ったら、このスキルの決まりは使わない。

1. 依頼した人の指示
2. 対象のリポジトリの文章の決まり
   - AGENTS.md・CLAUDE.md、CONTRIBUTING、docs の方針、PR・Issue のテンプレート、文章のリンターの設定
   - 決まりが無ければ、同じ種類の既存の文章（直近の PR の本文、同じディレクトリの文書）の書き方に合わせる
3. このスキル

文体（です・ます調か常体か）も、決まりと既存の文章に合わせる。
1つの文章の中では文体をそろえる。

## 決まりの要点

- 日本語では「。」の後で必ず改行する
  - 話題が変わるところは、空行で段落を分ける
  - 改行のせいで表示が崩れる所は例外にする（[改行・段落・箇条書き・表](references/layout.md)）
- 構造のある情報は、箇条書きと表にする
  - 並ぶ項目・手順・条件は箇条書きにする。
    項目に細目があれば 2〜3 階層にする
  - 複数のものを同じ観点で比べるときは表にする
  - 理由・経緯・判断は地の文で書く
- 簡潔に書く
  - 結論を先に書く
  - 前置き、同じことの繰り返し、最後のまとめの言い直しを削る
- 文を組み直す（[文の組み立て](references/sentences.md)）
  - 行為者を主語にする
  - 比喩の動詞を、具体的な事実に直す
  - 名詞が続く文を、動詞の述語のある文に戻す
  - 不要な否定の対比（「A ではなく B」）、装飾、文末のコロン、絵文字を外す
  - 避けたい語を見つけたら、同じ意味の別の語に言い換えるのではなく、文を組み直す

## 書く手順

1. 読む人と、読んだ後にしてほしいこと（承認する・直す・判断する）を決める
2. 結論と、それを支える事実を書き出す
3. 構造のある情報は箇条書きと表に、理由は地の文にする
4. 書いたら、下の「見直し」で確かめて直す

例と細かい決まりは、必要なときに資料を読む。

| 知りたいこと | 資料 |
| --- | --- |
| 改行・段落、箇条書きの階層、表、地の文の使い分け、改行で表示が崩れる所 | [改行・段落・箇条書き・表](references/layout.md) |
| 簡潔さ、行為者の主語、比喩の動詞、名詞の連続、否定の対比、コロン、絵文字 | [文の組み立て](references/sentences.md) |

## 見直し

出す前に、次を確かめる。

- 最初の数行で、結論か、読む人にしてほしいことがわかる
- 日本語の「。」の後が改行になっている（例外の所を除く）
- 1つの段落が1つの話題になっている
- 箇条書きが 4 階層以上になっていない。
  比べる情報が地の文や箇条書きに埋もれていない
- 理由や因果が、箇条書きで切れ切れになっていない
- 削っても意味が変わらない文が無い（前置き・繰り返し・まとめの言い直し）
- 主語の無い受け身、比喩の動詞、名詞の連続、不要な否定の対比が無い
- 文末がコロンで終わっていない。
  絵文字と飾りの記号が無い
- リポジトリの決まりと食い違っていない

## 英語の文章

英語で書くときも、日本語と同じ考え方で書く。

- 「。」の後の改行は日本語だけの決まりにする。
  英語ではピリオドの後で改行しない
  - 英語の文は短いので、1文ごとの改行は読みにくくなる
  - 代わりに、1つの段落を 2〜3 文にし、話題が変わったら空行で分ける
  - リポジトリが1文1行（semantic line breaks）を決めていれば、それに従う
- 箇条書きと表、簡潔さの決まりは、日本語と同じ
- 文の組み立ても同じ。
  能動態で行為者を主語にし、比喩の動詞（leverage・streamline・empower など）を具体的な事実に直す
- 日本語と英語の両方の版を書くときは、それぞれの言語の決まりで書く。
  訳すときに日本語の改行を英語に持ち込まない
